HTML 审美工作台覆盖

Style Group 怎样建设和审查

来源 PPT 提供关系与审美起点；HTML 是设计与 State 审查工作台；审美确认后固化 Native Builder，再生成原生可编辑 PPT。点击任意资产，在详情中查看这三段证据。

HTML 审美工作台
1 · 来源页从 PPT源/ 读取真实文件与页码，理解关系、拓扑和视觉中心。
2 · HTML 组件内容、图标、媒体和数量参数化，组件只占 Content Frame。
3 · 审美优化直接在 HTML 中调颜色、比例、间距、层级和响应布局。
4 · State 检查用同一份代码切换该 Style Group 声明支持的数量状态。
5 · Builder 固化HTML 审美通过后，生成或整理资产专属 Native Builder，并检查原生 PPTX。

正式生成时，Skill 怎样被自动触发

模型负责理解与选择；程序只把已登记能力变成合法候选。任何候选资产都不会因为“有文件”就自动进入正式生成。

1 · PageIntent视觉导演给出关系、目的、数量、文字密度与媒体需求。
2 · Skill 过滤匹配 baseRelation、purpose、itemCount 和媒体契约。
3 · Style Group在同一 Skill 下选择适合整套节奏和容量的样式组。
4 · 参数绑定Mapper 把 PageContent 确定性映射到组件字段。
5 · State 求解数量和内容触发已经登记的响应状态与边界。
6 · 页面生成调用入库时已定稿的 Native Builder；正式生成不运行 HTML。
7 · 受控兜底没有合法结构资产时用已登记简单排版，不现场造图。
