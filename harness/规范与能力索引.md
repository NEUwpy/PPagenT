# 规范与能力索引

Harness 按当前任务需要选择读取，不能把此索引当成全库一次性注入清单。

| 内容 | 唯一来源及用途 |
| --- | --- |
| 共享规则与角色协议 | [rules](../rules/README.md)：规范正文、profile 和 Skin 加载方式 |
| 技能及选择方法 | [skills](../skills/README.md)、[选择顺序](../skills/references/selection.md)：能力发现、依赖与选择 |
| 结构能力 | [结构 Skill](../.codex/skills/ppagent-structure/SKILL.md)：检索、适配、构建和检查；实际结构仍引用现有资产 |
| 结构边界 | [结构库变与不变](../docs/架构/结构库-变与不变.md)：已验证适配面，不因目录集中扩大能力 |
| 现行执行入口 | [正式生成工作流](../docs/工作流/正式生成/工作流.md)：旧 CLI 与当前独立 Agent 实验的区别 |
| Provider 配置 | [运行配置](../docs/契约/运行配置信息.md)：配置入口；密钥不写入运行资料包 |

当前无需迁移或复制结构库。集中的是可发现的运行入口与维护责任；实体资产可后续统一整理，须保留现有执行与引用关系。可编辑性、无非预期重叠、均衡分布、事实和关系忠实是产物要求，规范存在或工具调用成功不等于产物通过。
