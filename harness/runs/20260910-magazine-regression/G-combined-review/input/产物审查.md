# 产物审查与返工

审查是独立工作步骤，先保存证据，再编辑产物。输入为原稿、当前 PPT 和实际渲染，旧策划与已有通过声明不能代替证据。审查完成后仍由执行者自主返工，不需要用户提供逐页修法。

## 先读产物，再核对来源

逐页把读者实际看到的标题、表头、单位、关系和条件还原成简短命题，再逐项找原稿支持。不要先写“本页忠实”再挑支持句。

审查记录为主要主张和关系附原稿位置及必要的短引文，分别标明直接支持、忠实归纳和无依据的具体化。运行协议与制作规则说明“怎样做这份PPT”，不是稿件所介绍产品的事实来源；不能因某机制符合当前项目方向，就把它写成原稿已有内容。来源不足时由制作者自主重组，不要求用户逐页提供答案。

逐字核对统计标签，而非仅核对数字；明确每个值描述谁、哪个时间段和什么聚合层级。每条连接说明它主张的是顺序、因果、条件还是归属，并核查该关系本身是否有来源。贯穿过程的约束不能仅因方便布局而成为事后步骤。无法支持的关系应重新表达，不以旁注抵消主图。

## 看有效内容，而非容器面积

分别看整页缩略图和文字细节。暂时忽略背景块，判断实际文字、数据和图形分布；为主要空区说明它的阅读作用。缩短背景后仍留下同一大空区不算解决。依据实际内容重新分配面积、组合或分页，不预设原页数与骨架必须保留。

## 审查记录与停止条件

每页简记：实际命题、来源依据、发现的差异、有效内容分布、遮挡/换行问题、通过或返工及理由。发现共享问题时检查全套受影响页。审查记录也需接受反证：不能把对象边界或工具零告警写成语义和视觉全面通过。

返工后对新文件重新导出并复核，证据绑定文件名或哈希。连续两轮只做表面调整且同类问题仍在时，记录当前策略无效，重新审查上游内容/媒介/组合假设；不要无限追加相同续行提示或把问题转交用户逐页解决。

可机器判定的样式约束应对实际 PPTX 取值，期望来自本轮冻结的规范，不能只与制作脚本自行登记的样式比较。数值通过仍须判断角色用途、排字和整页效果。独立审查也会漏检；复审覆盖新版本全稿和新增问题，不能仅勾销上一轮问题清单。字体族、对象边界或包完整性检查只报告自身覆盖的范围。
