# 运行记录约定

每次任务使用唯一子目录。至少保存以下内容，文件格式可按实际工具调整，不预建复杂 Schema：

- `状态.md`：本次目标、输入引用、当前验证问题、最新产物、未解决项、已试策略、下一步以及中断情况。
- `输入/`：原稿或来源引用、任务要求与本轮实际读取资料的版本记录。
- `工作/`：本次脚本、中间数据、工具反馈。
- `产物/`：首版、各自主修订版、最终候选 PPTX 与逐页渲染。
- `验收.md`：实际检查、证据文件、失败诊断、修订结果与外部干预。

阶段结束和中断前更新状态；下一次对话先读状态再检查实际文件。原始输入、失败版本和外部反馈不得被覆盖为成功。临时文件默认不进入 Git，交付及必要证据由维护任务按明确路径保存。
