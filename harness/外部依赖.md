# 外部依赖与运行边界

2026-09-30 当前口径：建设阶段可在 Codex 环境中使用现有工作台、PPT 引擎、字体和渲染工具进行开发与看图；投入使用阶段必须由产品可部署的语义模型、JEV 和可替换的确定性程序完成，不能把 Codex 运行时或其视觉能力当成产品依赖。

## MVP 依赖

| 依赖 | 当前边界 |
| --- | --- |
| 语义理解模型 | 用户当前选型 DeepSeek v4.1 Flash；当前配置尚未完成迁移，以实际配置为准 |
| 判断选择模型 | JEV，经 OpenRouter Decisions API 接入 gray 布局有限选择 |
| 程序与规则 | 负责页面表达契约、来源、容量、参数、几何、原生构建和检查；复用现有仓库能力 |
| Skin、风格、布局、结构资产 | 建设期沉淀后由程序按契约调用；缺能力必须返回缺口 |
| PPT 引擎、字体、渲染 | 当前建设验证仍依赖 Codex 工作区及其内置运行时；独立、可部署替代尚未完成 |

当前工作台、资产看板和预览服务是建设工具，不等于产品已具备独立部署能力。许可证、版本和路径以实际运行记录为准；不把镜像文档、测试通过或历史产物写成可交付能力。

旧依赖清单及当时 M1–M5 口径已保留在[纠偏前归档](../docs/archive/20260930纠偏前/harness-外部依赖.md)。
