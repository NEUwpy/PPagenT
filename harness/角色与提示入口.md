# 角色与提示入口

## 产品运行角色

产品运行只定义两类模型：

- **语义理解模型：**稿件理解、分页、页面目的、内容归属、必要关系和内容填充。
- **判断选择模型（JEV）：**只从程序给出的合法版式/结构候选中判断和选择，不写自由坐标、不生成制作代码。

程序负责契约校验、来源、候选合法性、容量、槽位绑定、参数、几何、原生构建、检查和日志。产品不调用视觉模型或 Codex。

## 建设角色

用户与 Codex coworker 是建设协作者。main 建设稿件到灰稿，home 建设灰稿到成品；可分支开发并阶段性合并。home 可用模拟灰稿探索后段美化，模拟来源必须记录。

建设角色不等于产品运行角色。协作协议见[ppagent-coworker](../.agents/skills/ppagent-coworker/SKILL.md)；planner/reviewer 与 executor 是协作协议角色，前段/后段是任务范围，不能混称为模型角色。

## 当前代码边界

工作台 gray 的规划使用语义模型，布局选择使用 JEV，日志由运行事件与 trace 编译。旧视觉导演、视觉表单和自由局部排版仅作兼容或建设证据，不是新产品目标。规则和提示正文以实际消费点为准。
