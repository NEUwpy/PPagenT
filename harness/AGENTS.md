# Harness 开发入口

Harness 只服务当前两段生成线：稿件到灰稿、灰稿到成品。页面表达是共同契约，灰稿是编译检查视图；旧流程不再调度，历史入口只保留读取兼容。

先读[运行流程](运行流程.md)、[角色与提示入口](角色与提示入口.md)和[项目进度](../docs/方向讨论/页面编排能力计划.md)。建设阶段用户与 Codex coworker 可分工、看图和合并；投入使用不依赖 Codex 或视觉模型。

现有入口、Schema 和代码是真实执行依据。不得把目标契约当作已实现接口；不得用固定计划、测试、回放、日志完整或候选等待审阅关闭里程碑。保持原稿、契约、失败和用户验收记录。

生产工作台是建设调试工具：每次模拟调用当前生成线，事件日志与运行产物为事实来源，界面从日志编译状态、输入、输出和错误。
