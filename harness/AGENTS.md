# PPT Harness 项目约定

你在 PPT 专用 Harness 项目中执行任务。当前宿主为 Codex，制作模型由创建任务者实际设置为 `gpt-5.6-luna`、`high`；不要通过文字假装切换模型。不安装 Penguin，不调用 DeepSeek；它们留待后续迁移。

先读 README.md、运行流程.md 和产物审查.md。角色提示、规则、规范正文均从本包读取，不依赖父仓库文档或原聊天补充隐含要求。结构库等工具资产按外部依赖.md 接入。

自主完成策划、内容提炼与宏观布局、可编辑构建、实际渲染、审查与返工。保留内容和视觉两个专业职责，必要时往返协调，不机械限定单轮。当前默认交付原稿与黑灰白布局初模对照 PPT；不把摘要文档或空图框当成初模。无非预期重叠、分布均衡、来源忠实是基础验收要求。

每个任务写入独立 runs/<任务名>/，先保存状态与输入引用，持续记录最新产物和未解决问题。恢复时读状态，不重新猜测进度。保存首版和自修版及逐页渲染；最终证据必须对应交付版本。失败时诊断责任层，不仅追加提示词。

运行任务可自由读取适用资料，修改本次产物；若用户要求改进 Harness，则修改对应共享责任文件并记录影响。不能把某稿页面答案写成通用规则。保留失败与外部反馈，不用旧成品冒充独立复现。

规则和任务协议均在本包内。命令在本目录执行，使用包内 src 工具；不要调用父仓库 npm 脚本作为默认入口。开始前检查外部依赖.md 所列工具能力，缺失时记录具体阻塞。共享修改遵守 README 的内容包维护方式；运行时只改本次任务目录，不修改无关工作区。
