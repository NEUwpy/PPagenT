# PPT Harness 使用入口

2026-09-30 当前口径：生成线只有两段——稿件到灰稿、灰稿到成品。页面表达是共同契约，灰稿是编译视图。Harness 负责状态、调用、检查、有限返工、日志和产物留存；它是建设手段，不是产品定位。

建设阶段由用户与 Codex coworker 使用，Codex 可看图。投入使用阶段只调用语义理解模型、JEV 和确定性程序，Codex 与视觉模型不进入产品。

当前工作台 gray 入口为 `src/runner/gray-agent.mjs`：规划使用语义模型，布局选择使用 JEV，日志由 `events.jsonl` 与 `trace/*.json` 编译；灰稿到成品仍按最小资产逐步接通。旧 runner/legacy 入口保留兼容，不代表 MVP 目标。

```powershell
npm run production:workbench
```
