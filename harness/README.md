**当前阶段：讨论、盘点和必要的方案探索，路线明确后才进入正式实现。** 优先复用既有资源，参考其他领域的成熟实践。

## 既有资源

`assets/` 保存结构图、主题等设计资产；`src/`、`rules/`、`schemas/`、`tests/` 保存既有实现与规则；`稿件/`、`experiments/`、`outputs/` 等保存输入和验证证据。`harness/` 是既有执行包及生成镜像，是否继续采用由本轮讨论决定。

其他技术说明用于核查已有资源，不增加新的路线或计划入口。历史说明与修订前快照见[归档](docs/archive/README.md)。
