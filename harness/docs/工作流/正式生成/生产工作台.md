# 生产工作台

工作台是建设阶段的生成线调试入口，不是产品角色。它只把日志编译成可读的状态、输入、输出和产物视图。

当前建设阶段主要用于提交稿件或固定页面表达、编译灰稿、查看真实 PPT/PNG、让 Codex 检查内容与视觉，并保存契约、程序、失败和审阅证据。

未来投入使用时，生产线只调用语义理解模型和 JEV；Codex 与视觉模型不进入产品。当前 gray 入口由 src/runner/gray-agent.mjs 提供，页面选择通过 OpenRouter Decisions API 调用 JEV。

pipeline=gray 的运行记录保存输入、提示/规则、state、计划、候选、PPTX、PNG 和事件；工作台从 events.jsonl 与 trace/*.json 编译阶段视图。awaiting-user-review 只是候选等待审阅，不代表里程碑通过。旧 legacy 双导演和视觉表单只作兼容/历史，不作为 MVP 目标。

启动：

    npm run production:workbench

具体状态和当前实现以运行目录与代码为准。
