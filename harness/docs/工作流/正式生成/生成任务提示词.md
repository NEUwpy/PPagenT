# 生成任务协议

当前 MVP 只描述两大阶段：稿件到灰稿、灰稿到成品。页面表达是共同契约，灰稿是编译和检查视图。

建设任务可由 Codex coworker 执行：明确是前段契约/灰稿，还是后段模拟灰稿/成品预览；保留输入、代码/规则、PPT/PNG、问题和验收状态。home 的模拟灰稿不证明自动规划。

使用任务只允许两类模型职责：语义理解模型负责稿件理解、分页、关系和内容填充；JEV 负责从合法候选中判断选择。程序负责来源、Schema、容量、参数、几何、原生构建与检查。不得让模型写自由坐标、制作代码或虚构能力；产品不调用视觉模型或高级模型兜底。

输入和交付按当前实际入口；默认保留原稿、同源页面表达、灰稿/成品、逐页预览和运行记录。没有合适能力时返回缺口。现有运行器/schema 未完成上述迁移，任务记录实际配置，不能按本协议宣称已实现。
