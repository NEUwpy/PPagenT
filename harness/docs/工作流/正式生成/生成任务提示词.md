# 生成任务协议

当前 MVP 只描述两大阶段：稿件到灰稿、灰稿到成品。页面表达是共同契约，灰稿是编译和建设检查视图。

建设任务由用户与 Codex coworker 执行：main 负责前段契约/灰稿，home 负责后段模拟灰稿/成品；保留输入、契约、规则/代码、PPT/PNG、日志、问题和验收状态。模拟成品只证明后段。

投入使用只允许两类模型职责：语义理解模型负责稿件理解、分页、关系和内容填充；JEV 负责从合法版式/结构候选中判断选择。程序负责来源、Schema、候选合法性、槽位绑定、容量、参数、几何、原生构建、检查与日志。不得让模型写自由坐标、制作代码或虚构能力；产品不调用视觉模型或 Codex。

输入和交付按当前实际入口；默认保留原稿、同源页面表达、灰稿/成品、逐页预览和运行记录。没有合适能力时返回缺口。当前 gray 入口已接入 JEV 布局选择，完整成品链和独立运行仍按项目台账验收。
