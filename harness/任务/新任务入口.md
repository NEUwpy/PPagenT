# 新任务入口

创建者在 Codex 的 harness 项目中开新对话，实际选择 `gpt-5.6-luna` 和 `high`，在保存的项目目录直接运行。初次使用须核对项目 cwd 为 C:/PPagenT/harness；这里不建立嵌套 Git 仓库。

以下模板只填输入和必要约束，执行流程来自项目资料，不复制长提示词：

> 阅读项目 AGENTS.md、README.md 和运行流程.md，按项目 Harness 流程自主完成本次任务。
> 原稿：<文件路径或本条消息正文>。
> 演示要求：<受众、用途及用户明确约束；无要求则按原稿判断>。
> 视觉组合：<中性 Skin＋杂志风／东北大学 Skin＋麦肯锡式；初模阶段仅记录，暂不套品牌美化>。
> 输出目录：runs/<唯一任务名>/。
> 当前交付：完整原稿与内容布局初模对照的可编辑 PPT，以及逐页预览。内容提炼和宏观布局一起完成，暂不美化。
> 先明确每页真实内容、宏观区域和阅读关系，再判断是否需要私有结构库、技术图示或数据图表。按需调用并回看整页，不为使用能力倒推页面。
> 按需读取项目资料与能力，持续执行工具、渲染、审查和返工；保存状态、首版、自修版和未解决问题，不停在文字计划。

已有任务继续时只需说明任务目录和新要求，执行者读取该目录状态与最新产物后继续。是否需要新稿、换模式或修改共享资料由本次用户任务决定。
