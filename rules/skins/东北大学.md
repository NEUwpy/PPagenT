# 东北大学 Skin

适用 Skin：`northeastern-university-001`，由索引绑定「麦肯锡式」排版。独立制作与中性 Skin 使用同一规则加载入口；此绑定不替换正式 Native renderer 的页面壳和候选选择流程。

字体与颜色直接读取已有运行时 Skin 契约及其主题，加载器附带实际配置，不另建字体或色值副本。

<!-- runtime-skin: northeastern-university-001 -->

`fonts.display` 用于判断标题，`fonts.body` 用于正文、图题、标签和辅助文字。颜色用途对应 `theme.background / surface / dark / body / muted / primaryColor`；细线、浅分区及系列色阶从这些角色派生，文字保持可读。同一配置用于文字、结构与图表；组件的默认装饰不覆盖本次排版。`theme.typography` 是既有组件字号，整页文字角色由绑定排版指定。

学校身份素材复用已有封面、目录、正文及结束页资产，不另造 Logo；素材和原生图表的固定语义颜色按内容保留。整页构图与文字编排读取绑定体系，局部结构、技术图示和数据图表按共享技能选择规则使用。
