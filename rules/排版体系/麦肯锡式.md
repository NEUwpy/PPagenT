# 麦肯锡式

本体系可供不同 Skin 共享；绑定由 `rules/index.json` 决定。Skin 提供身份、字体、主题色和固定外观，本文件负责分析内容怎样组织成页。学校名称、蓝色、校徽及模板坐标不属于本体系。以下规则参照杂志风的执行粒度完善，审美取向是克制、精确、证据突出；修订后的跨稿稳定性仍须实测，不以规则接入宣称效果通过。

## 内容原则与视觉气质

**先给结论、一页一事、标题即观点。** 每页先确定读者需要理解或决定什么，再用一句有依据的判断统领正文。原稿只有建议或待验证条件时，保留相应语气；不能把目标写成成果，把后续能力写成准入资格。封面、目录等导航页不强造观点。

分析感来自可检查的对应关系：读者能沿同一行找到对象及其依据，沿共同尺度看出差异，从证据旁找到解释或行动。主体首先展示这种关系，再安排装饰与局部结构。精英感不靠高密度、小字或满页英文，留白也不等于把短标签放进巨大图形。

视觉上采用稳定的对齐轴、清楚的主辅面积、简洁的图表和少量有依据的强调。分析对象形成主体，解释作为相邻的第二层；全页像一个连贯的论证，而不是多个互不关联的模块。

## 画布与固定文字角色

- 基准为 1280×720 设计像素；转换到 13.333×7.5 英寸页面的 PowerPoint pt 时乘 0.75，接口已使用设计像素则直接传入。
- 字体名称读取 Skin 的 `fonts.display` 与 `fonts.body`；颜色读取其语义角色或由主题色统一派生，不另建排版专用色板。
- 无固定模板时，页边距从 56 起，观点标题左齐，按完整语意断行，以细线或留白与主体分开；页码、来源靠边轻置。有固定模板时，页眉、标题带、页脚和正文安全区以 Skin 为准，不用本文件重画外壳。

| 角色 | 字体字段 | 设计字号／字重 |
| --- | --- | --- |
| 正文页观点标题 | `fonts.display` | 32／同类一致；固定模板沿用其角色 |
| 局部分析标题、图题 | `fonts.body` | 21／bold |
| 正文、图内标签、行列内容、关键条件 | `fonts.body` | 18／regular；确需辨识的短标签可 bold，同类一致 |
| 来源、单位、非关键范围注释 | `fonts.body` | 14／regular |

先建立唯一文字角色映射，再创建文字。封面及目录使用 Skin 约定；若没有固定模板，沿用以上标题与正文角色组织。普通解释、页底结论和例外处置不另造字号；风险边界、决策条件和分歧处理必须保持正文角色，不能以辅助字号塞到页脚。

实际创建正文对象时引用角色映射，不在每个对象上另写 16、19 等近似字号。依据说明与条件本身同属正文，不能把标签写大、把决定判断的说明降成辅助档。短中文标签横向完整阅读；窄栏容不下时换行列组织或拓宽，不能将四字标签压成四行来维持既定图形。

正文左齐、常规字重，短标签紧邻对应内容。段落按意思分组，行距与组间距形成阅读层次；同组比组间紧凑。字数增加先调区域、自然行高和表达方式，不自动缩小字号。局部标题只有确实帮助定位时才设置，不能把每个首句升级成第二大标题。

## 从关系确定主表达

编排前简记：本页判断、支持依据、依据之间的关系、最直接的表达。按本稿关系选择，不按页型清单凑数量：

| 内容关系 | 排列方法 | 读者应直接看到 |
| --- | --- | --- |
| 对象比较 | 相同字段共享列、基线、单位或坐标尺度；标签紧凑、依据充分展开 | 同口径差异及其意义 |
| 条件与决策 | 条件与所需依据逐项对应，动作放在相邻位置；共用动作可合并但归属明确 | 满足与不满足分别怎样处理 |
| 责任与处置 | 角色与负责动作就近；发生分歧或失败的处置紧邻关口 | 谁确认、谁复核、例外怎么办 |
| 能力或阶段递进 | 阶段配本阶段特征及进入下一阶段所需凭据 | 阶段变化与推进条件，不只是三个名称 |
| 并列类别 | 用共同起线、自然行高组织类别及说明；数量多时采用行列 | 各项各自作用及相同地位 |
| 定量证据 | 根据比较、趋势、构成或分布选择数值编码，标明单位、口径及来源 | 支持观点的差异、变化或异常 |

一个问题可由多个互相支持的视图回答，相关视图共享对象名称、尺度和颜色意义。先把主要依据放到连续、足够大的区域，再安排背景与解释。来源类别、背景介绍通常只需紧凑文字，不能比真正决定行动的条件占据更多视觉注意。

## 文字、结构与图表共同成页

- 先分配整页主辅关系与可用区域，再选择局部表达。图外解释和图内标签共同预算空间；结构占用确定后，剩余区域仍按完整排版方法组织文字，不围着结构空隙补注释。
- 结构库按共享技能选择规则调用。保留源设计辨识度，在已支持范围内适应可用区域和 Skin；若只承载少量标签，适当缩小其面积，给依据留下空间。不能靠扩大结构填补缺少内容，也不把并列条件改造成漏斗以获得造型。
- 原生文字、对齐行列或表格能清楚表达时直接使用。项目库缺少适合的技术图示时用 diagrams；有数据及口径时用 charts。技能没有调用配额，也不为生成数据图虚构数字。
- 解释贴近它支持的对象，写出意义、条件或下一步。若只是复述图内标签，应删去重复表达或补回原稿中真正有用的依据。全局边界可单独呈现，但不能把所有条件统一堆在页底长条中。

## 色彩、线条与容器

以 Skin 的背景和深文字构成清楚底层，用主题色强调关键对象、发现或决策。普通文字保持深色，不把全部小标题、正文和线条都染成同样浓重的主题色。弱化的是辅助视觉分量，不能弱化可读性。

并列项保持等权，同一对象跨图文保持同色。末项不会因为在末尾自动变深；若需要突出，必须对应原稿里的意义。结构已有深浅与透明度由统一主题规则保留，不因本体系偏好平面表达就把源设计改成线框或重新配色。

对勾、完成色、进度填充及“已通过”等标识属于事实表达。原稿只有拟议条件时，用条件文字表达，不能让装饰性状态标识暗示条件已经成立。

优先用共同起线、留白和细分隔线形成阅读组。表格使用必要的表头和行分隔，不默认每格加厚边；浅底用于确有意义的分区或重点行。框线应帮助辨认归属，不能每段文字一张圆角卡片。自绘分析区采用简洁平面处理，不增加无意义阴影、渐变、胶囊或大圆圈编号；Skin 固定外观及结构源设计不受该装饰限制改写。

## 整稿节奏与实际复核

全稿统一字体角色、颜色含义、边距和对齐习惯；面积与密度根据证据变化。宽比较表、主图配短解释、阶段配依据、紧凑决策页可以形成节奏，但不要求逐一出现。连续页都变成左右两个等大视图或上图下总结时，核对是否源于内容，不能只换标签沿用骨架。

按共享质量规则查看真实渲染。每页记录实际观点、主体依据与下列判断，出现问题自行重排并复核：

- 第一眼的重点是否是本页分析；标题能否由主体支持。
- 对象与依据、条件与动作、角色与处置是否能就近匹配；并列项是否被错误强调。
- 正文是否给关键内容足够面积；有无短标签占大图、解释挤窄栏、页底补满条件。
- 文字是否遵守角色、自然断行；线条净距、内容组高度和纵向重心是否合理。
- 结构是否增加了关系信息；全稿是否有内容驱动的节奏。

保留首版和修正后文件，避免覆盖首版记录。包检查、字体角色及几何检查与视觉判断分别报告；未查看实际图片、或仍有缺陷时，不以“已自检”宣布通过。单稿成功只说明这次适配，不代表所有 Skin 或所有稿件已验证。

执行检查时核对其实际覆盖对象和判定口径：最低字号检查不等于文字角色检查，页边界检查不等于图形内部排字和相交检查。标签、说明、线段及承载面均须纳入对应检查；覆盖为零或对象未登记时，先补齐覆盖，不能引用工具的通过字样替代逐页核对。
