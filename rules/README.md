# 现行规则

2026-09-30 当前规则只服务两大阶段：稿件到灰稿负责内容结构、分页、关系、来源与页面表达；灰稿到成品负责 Skin、风格、布局、结构和原生制作。

规则是共同契约的约束和资产执行依据，不替代程序实现。生产模型只理解、填充和有限选择；Codex、视觉审阅和临场自由绘图只用于建设，不进入产品。

当前规则正文仍按 index.json 及实际入口加载。修改规则前核对消费点；共享正文只维护一份，Harness 镜像由脚本同步。未实现的目标字段不能写成已接入能力。现行资产契约见[页面构成与布局规范](../docs/架构/页面构成与布局规范.md)，建设流程见[资产入库工作流](../docs/工作流/资产积累与入库/工作流.md)。

建设任务按关系、输入、容量、参数、执行和证据入库；生产缺能力时返回缺口。保留历史规则和实验，不能把旧角色或旧五段流程当作当前任务入口。
