# PPagenT

**把稿件可靠地转成表达清楚、风格合适、原生可编辑的 PPT。**

2026-09-30 现行生成线只有两段：**稿件到灰稿 → 灰稿到成品**。页面表达是共同契约，灰稿是契约的编译视图；表单是契约的编辑/检查投影，成品消费同一内容来源。

当前是建设阶段：用户与 Codex coworker 建资产、规则、程序并看图验收。main 建设前段，home 建设后段，阶段性合并。投入使用时只调用语义理解模型（当前 DeepSeek v4.1 Flash）、JEV 和确定性程序；Codex、视觉模型、自由绘图不进入产品。

当前目标是 MVP，两个大里程碑都未通过。模拟灰稿、固定计划、测试和历史成品只证明局部能力，不能代替真实稿件、语义质量或用户视觉验收。

## 本地建设工具

```powershell
npm ci
npm run setup:workspace
npm run production:workbench
```

工作台 gray 入口为 `src/runner/gray-agent.mjs`，当前复用 `gray-plan-3`、JEV 布局选择、来源绑定、测量和渲染；工作台从日志编译状态、输入、输出和产物。看板和工作台用于建设调试，不等于正式能力验收。

运行配置见[配置说明](docs/契约/运行配置信息.md)。当前 PPT 引擎仍依赖 Codex 工作区运行时，投入使用前须满足独立运行及依赖条件，见[外部依赖](harness/外部依赖.md)。

`rules/` 维护规则，`assets/` 维护资产，`src/` 维护程序，`稿件/` 保存输入。旧说明已[归档](docs/archive/20260930纠偏前/README.md)，历史实验与失败保留但不再调度。
