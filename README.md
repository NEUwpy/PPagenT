# PPagenT

PPagenT 是一个按照学校视觉规范生成原生可编辑 PowerPoint 的项目。

系统使用 AI 理解和整理稿件，并从已有组件中进行选择；具体的页面绘制由确定性的程序完成。项目强调有限的自由，不让 AI 随意改变学校模板或自行创造未经定义的视觉形式。

## 当前阶段

项目目前处于定义与技术可行性验证阶段。

## 核心工程取舍

PPagenT 采用“AI 理解与选择、参数化代码确定性绘制”的生成方式，以减少重复生成消耗并提高结果可靠性。核心库原则上为每个细分功能保留一个首选版式家族，并通过家族内部变体适应内容数量和排版变化。具体规则见[产品定义](docs/产品定义.md)。

## 已确定的基本原则

- 第一阶段从一所学校开始，形成成熟流程后再复制到其他学校。
- 学校模板负责固定视觉规范，正文内容可以在规则内采用不同布局。
- 组件采用参数化程序实现，并保持统一的视觉风格。
- AI 负责内容理解、结构整理和组件选择，程序负责绘制。
- 最终输出必须是原生可编辑的 `.pptx` 文件。
- 第一阶段优先支持 Markdown，其他输入形式以后逐步扩展。

## 主要目录

- `assets/`：核心资产库，只放已经确认的首选版式家族。
- `结构样本池/`：保存所有值得继续观察的单页来源样本，允许重复和暂未归类。
- `备选资产/`：新蒸馏、重复版式和待比较方案的审核区。
- `src/asset-runtime/`：核心资产与备选资产共用的绘制代码。
- `workbench/`：原始模板归档和临时处理区，不作为资产浏览入口。

## 公开仓库范围

公开仓库保存项目代码、文档、资产元数据和可由代码生成的候选示例。第三方原始模板、从原模板提取的单页 PPT 与预览图，以及本地实验输出只保存在本地工作区，不提交到 Git。

## 本地验证

安装公开依赖后可执行：

```bash
npm install
npm test
```

`npm test` 会校验规则层契约、版式合法性筛选和公开仓库资产结构。包含原始模板和样本文件的本地工作区可额外执行 `npm run audit:local`。

当前页面生成器依赖 Codex 工作区内置、尚未公开发布的 `@oai/artifact-tool`，因此不把它写入公共 npm 依赖；规则层、元数据审计和选择测试可以通过公开依赖独立运行。
