# PPagenT

**把稿件可靠地转成表达清楚、风格合适、原生可编辑的 PPT。**

2026-09-30 对齐：**稿件到灰稿 → 灰稿到成品**。页面表达与灰稿是一体两面：表达数据是共同契约，灰稿是程序编译出的检查视图；美化消费同一契约。

当前是建设阶段：用户与 Codex coworker 一起建设和审阅，可按前后段分角色推进、阶段性合并。投入使用时，仅由语义理解模型（当前选型 DeepSeek v4.1 Flash）和判断选择模型（JEV）调用已有规则、资产与程序；Codex 和视觉模型不进入产品。

当前目标是 MVP，两大里程碑都未通过。模拟灰稿可先验证美化；固定计划、测试或历史成品不证明自动规划与整稿质量。现有代码、模型配置和 PPT 引擎尚未完成目标迁移。

## 本地建设工具

```powershell
npm ci
npm run setup:workspace
npm run production:workbench
```

工作台默认灰稿入口为 `src/runner/gray-agent.mjs`，输出候选 PPTX 和预览；当前模型规划与布局选择共用 provider，JEV 未接入。看板通过 `npm run assets:dashboard` 启动，用于建设和查看资产，不等于正式能力验收。

运行配置见[配置说明](docs/契约/运行配置信息.md)。当前 PPT 引擎仍依赖 Codex 工作区运行时，投入使用前须满足独立运行及依赖条件，见[外部依赖](harness/外部依赖.md)。

`rules/` 维护规则，`assets/` 维护资产，`src/` 维护程序，`稿件/` 保存输入。旧说明已[归档](docs/archive/20260930纠偏前/README.md)，历史实验与失败保留。
