# 运行配置契约

2026-09-30 当前口径：

- 建设阶段由用户与 Codex coworker 协作；Codex 可看图、检查 PPT 和辅助建设，但 Codex 不进入产品运行。
- 投入使用阶段只有语义理解模型和判断选择模型。前者负责稿件理解、分页、关系和内容填充；后者 JEV 只在程序提供的合法候选中选择。
- 当前选型为 DeepSeek v4.1 Flash + JEV；gray 线已接入 JEV 的布局有限选择，完整入口迁移仍按实际运行记录验收。
- 视觉模型不属于生产模型。建设阶段需要看图时使用 Codex 的视觉能力；现有视觉模型字段和旧入口只作兼容/历史。

使用阶段必须记录实际返回的模型标识、输入、契约/规则版本、候选与结果。模型输出不能绕过来源、容量、参数和原生可编辑检查。

真实密钥只保存在本地忽略配置或部署 Secret，不进入日志、提交或运行产物。当前运行器从 `config/deepseek.local.json` 读取 DeepSeek 兼容配置；OpenRouter/JEV 可从环境变量读取，也可从被忽略的 `config/credentials.local.md` 读取。该 Markdown 是给用户复制到另一台电脑后自行修改的本地凭证模板，不能提交。

JEV 使用 OpenRouter Decisions API（`https://openrouter.ai/api/alpha/decisions`），默认模型为 `~typesafe/jev-latest`。它只负责有限候选判断，返回的 choice/score/noul 仍须由程序校验和绑定。

PPT 引擎当前依赖 Codex 工作区运行时，只能作为建设和内部验证条件；投入使用前须替换或明确独立许可与部署条件。详见[外部依赖](../../harness/外部依赖.md)。
