# 产品目标与实现路径

2026-09-16 按用户确认更新。产品定义见[产品定义](产品定义.md)，阶段验收和状态唯一见[项目进度](方向讨论/页面编排能力计划.md)；本文只维护实现取舍与稳定性口径。

## 实现取舍

- 多次 API 调用与 Harness 不互斥。Harness 负责组织上下文、规则、状态、Skills、工具与检查返工，只建设制作闭环所需能力。
- 先复用现有运行器；稳定工作流形成后，再判断哪些通用能力值得交给成熟框架。Agents SDK、LangGraph 等尚未选定，自研框架不是产品目标。
- 规则按内容、页面规划、风格、结构选择、Skill 调用、制作约束与检查职责分层，按阶段和任务加载所需内容；维护入口见 [rules](../rules/README.md)。不把拆文件等同于已实现按需加载。
- 现有规则、Skin、结构库与外部 Skill 按需复用。新能力服务于内容表达，不以调用数量、资产数量或接口数量作为质量证明。
- 当前灰稿沿用已有 `groups/blocks/role/kind`、表达绑定及 `resolveLayoutTree`，不新增逐句关系图、角色配对白名单或强制页型。内容规划负责信息提炼和归属，表达阶段负责共同阅读与局部媒介，几何阶段只测量和分配空间。灰稿蓝区保留制作说明，块内节点留给后续正式制作。
- 独立部署、正式框架、商用依赖、并发、隔离、恢复与成本纳入 M5；当前私有 PPT 引擎仍是产品化阻塞，不能把计划延后解释为限制消失。

## 稳定性与规划口径

**稳定指语义和质量稳定，不要求每次重新规划都选择相同结构。** 已确认方案的重建是另一项工程能力；保存与回放成功不能证明方案本身合格。

**规划是制作的基准，不是不可修改的合同。** 先确定页面目的、内容归属、关系和主次；制作发现容量或表达问题时，记录原因，返回修订规划并更新受影响产物，不能偷偷改事实或缩字硬塞。

产品进度以实际制作能力的改善衡量。受监督样本、独立首轮、自主返工与跨稿结果分别记账；文档、工具循环和测试通过不替代相应的规划或成品验收。

对当前灰稿，验收同时看标题与正文职责、分支及其条目归属、必要条件与关系、区域对齐和疏密。原稿允许压缩与重组，不能删掉重要事实来满足容量；区域面积不按条目数量机械换算。主 Agent 编写计划再由共用引擎重排，可以验证渲染与几何修正，不能计作外部模型独立规划成功。

#### 历史：一、目标（已确认）

**用最少的设计，让任意内容都能得到逻辑完整、原生可编辑的 PPT。**

| 维度 | 判据 |
| --- | --- |
| 可靠 | 三关依次全过：① 单稿跑通 → ② **同稿重复，每页结构选择一致** → ③ 新稿冷启动通过 |
| 覆盖 | 结构库相对**生成器能发出的逻辑**完备即可；不要求每页调用结构 |
| 设计前移 | 决策提前：区域、结构、主次、阅读顺序在动手前定下，后续阶段只执行、不重选 |
| 复用 | 四层全要：① Skin 换标换色 ② 结构一份源设计多 Skin 共用 ③ 整页版式复用 ④ 跨稿复用内容结构 |

#### 历史：二、实测现状（2026-09-12）

| 层 | 实际状态 |
| --- | --- |
| 逻辑覆盖 | 生成器可发 **18 类**结构类逻辑，**18/18 有结构可用**；5 类只有单点；`logic-map` 的 journey/spatial 是生成器发不出的僵尸条目 |

#### 历史：三、路径（由目标反推）

**0. 清障（已授权）。** 修 2 个真缺陷与审计工具的 kind 守卫；12 项过期断言对齐真源。测试不可信则后续改动无保险。

**1. 决策固化 —— 兑现「设计前移」与「结构选择一致」。**
blueprint 显式记录每页选中的结构 assetId 与版式 id；构建阶段只消费、不重选。这是"同稿重复一致"唯一可行的机制，不依赖模型自觉。

**2. R1 实跑 —— 兑现「单稿跑通」。**
一份短稿走完全部生产阶段，同时**记录缺口**：内容里出现、却没有合适结构可用的逻辑关系。

**3. 版式统一 —— 兑现「整页版式复用」。**
把 35 个结构从单槽位扩到多版式槽位，结构页与文字页共用一套 skin-normalized 坐标系。同时把 32 个只有裸声明的资产补成已登记的 `planned` 契约（`enabled:false` 起步，与已有 3 个一致）——否则「一份源设计多 Skin 共用」没有可核实的承载物。

补契约不是只改清单：这 32 个 `runtime.mjs` 都还没导出 `resolveSpatialRequirement`，而清单登记了 `spatialResolverExport` 就必须真的导出（否则 `loadCoreAssetPackage()` 运行期抛错）。`src/tools/migrate-structure-adaptation-contracts.mjs` 现在带写入前闸门，会把这 32 个全部拦下并逐条报告——入口模块要和清单一起改。

**4. 按真实缺口补库 —— 兑现「库完备」。**
补什么由第 2 步的缺口记录决定，不预先补。

#### 历史：四、暂不做

- 不扩结构库、不验证 19 类分类法 —— 等真实缺口暴露
- 不建全面 Schema、不增加审查 Agent、不做自动路由
- 不搬迁旧 API 生产线，不动 A–H 历史实验
