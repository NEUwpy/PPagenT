# 结构库：变与不变

当前实现入口见[结构源设计与 Skin](../产品定义.md#结构源设计与-skin-的共享方式2026-09-08)。一个结构的源设计供各 Skin 共享；修改它会更新该结构的各 Skin 表现，修改公共规则才影响全库。35 个已审批结构已统一中性换色，三个样板已支持保真尺寸适配；下文逐项可变边界不等于全部已实现。

以现有 35 个结构为基础，保留设计和绘制方法，放宽区域、尺寸和内容适配。本文是逐项拆解，尚不代表执行器已经实现这些变化。

## 建设目标（2026-09-07 用户确认）

**让结构在实际排版时容易被正确调用，并在当前 Skin 和页面布局中稳定、协调地适配。自由度只服务于这个目标，不追求参数越多、变化越多。**

- 继承现有结构的漂亮造型和表达特点。以原实现为基础，按“不变项”保真，不让模型每次自由重画。
- 对外主要输入内容、可用区域和 Skin。调用者负责选择结构和安排区域，不逐一决定卷角、图标、编号圆、描边等几何细节。
- 对内使用少量受约束、确定性的调整规则。先做好原朝向和原排布内的适配；只有真实排版需求证明有价值时，才增加另一种排列方式或新的可调项。
- 文字、图标、编号圆与其他小配件按可读性和视觉比例联动，不能随主体机械等比缩放。具体规则需由样本验证，不把讨论中的方案写成已实现能力。
- 空间不足时返回可处理的原因和调整方向，让 Layout 能扩大区域、调整页面组织或选择其他结构；不能靠反复猜参数、降到允许字号以下、删稿或扭曲造型完成调用。

建设验收围绕实际使用：

2026-09-08 用户再次明确：验收单位是“需要结构的完整页面”。Agent 必须选对并调用结构，同时完成整页内容分工与排版；不能把成功调用次数或仅不重叠、放得下当成完成。对应实验协议见 [整页任务验收](../../experiments/structure-wholepage-luna-20260908/PROTOCOL.md)。

1. **调用是否容易**：只给稿件、Skin、排版约束和 Skill 入口，执行者能否找到并调用合适结构；记录重试和人工补参数的情况。
2. **适配是否协调**：在实际页面区域和指定 Skin 下，主体、文字、图标、小配件及留白是否协调，而非只检查独立结构画布。
3. **设计与内容是否保留**：对照原样例检查不变项，稿件事实、成员和关系完整，最终 PPTX 文字与图形可编辑到约定粒度。
4. **行为是否稳定**：相同输入可复现；相近区域的调整可预测；不能出现微小尺寸变化就大幅跳版的情况。
5. **失败是否好处理**：超出当前能力时清楚拒绝，并给出 Layout 可执行的调整信息。

缩放样例、代码测试和成功调用日志是建设证据，不单独构成上述目标完成。首批三个结构的原造型缩放试验见 [试验记录](../../experiments/structure-preserved-pilot/README.md)；三个试点已增加受限字号和小配件联动，见[大中小样例](../../experiments/structure-size-pilot/README.md)；实际整页 Skin／Layout 使用验证仍需继续。此处确认建设方向，不自动扩大实施范围。

## 尺寸与字号路径（2026-09-08）

先用原尺寸、85%、70% 三个代表样例验证，保留一份原造型绘制方法；中间占区仍可适配。字号只从既有基础文字组件或当前 Skin 允许档位选择，同角色统一。显式 Skin 字号优先，不能为了通过测量任意降低。Agent 正常调用内容、区域和 Skin，特殊需求在任务副本中局部修改原实现并重新验证，不自动改写结构库。

## 共通边界

- **不变**：原结构的关系语法、识别造型、层次、连接和空间体系。不是固定像素坐标，也不是只保留一个名称。
- **可变**：稿件内容、结构所占区域及下表逐项列出的布局参数。优先保留原排布和朝向；换朝向、多行、超出原样例数量的扩展不默认已支持。
- **联动**：缩放或改数量时，主体、附属面、锚点和连接由同一几何方法重算，不能各自拉伸。圆、卷页和透视不随意横纵不等比拉扁。
- **文字与 Skin**：字体、语义字号和配色按当前 Skin；保留对比、色阶、等权或强调的角色。文字重新换行和测量，不机械跟随图形缩小；线宽、圆角、阴影与细节按可辨识程度调整。空间不足时先调整占区和间距，再另验布局，不删事实凑图。
- **数量边界**：旧样例上下限是现有实现的支持范围，不是设计永远不可突破的边界；突破前先检查实现，再做视觉验证。此处没有宣称任意数量都能容纳。
- **来源**：逐项核对资产 visual-intent.md 与 review.mjs 的构图函数；新拆解进入 structure-skill.json 的 designBoundary。未修改原绘制实现。
