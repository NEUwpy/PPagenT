# 当前阶段

PPagenT 已跑通 `原稿 → 内容导演 → 视觉导演 → 核心资产 → Native PPT` 的正式生成线，并建立了与之分离的资产积累与入库线。当前代码基线以远端 `main` 为准；本文只记录已经进入该基线的能力，不把本地试验或计划写成已完成功能。

## 远端基线已具备

- `PPT源/` 中的原始参考模板；
- 东北大学主题的封面、目录、正文和尾页；
- 内容导演、视觉导演、确定性候选筛选、Native PPT 生成和渲染质量门禁；
- HTML 组件、TextRegion／Text Layout、通用 Native 编译器、资产看板和生产工作台；
- 两轮资产审批、Slot Contract、正式可达性见证和统一入库收尾入口。

## 当前资产状态

- 登记资产共 92 个：`core` 39 个、`pending-review` 31 个、`superseded` 15 个、`withdrawn` 7 个；
- 39 个正式资产由 4 个东北大学页面模板和 35 个 Structure Group 组成；
- 20 类 Logic 中已有 18 类具备正式资产；“旅程与生命周期”和“地域与分布”仍为空缺；
- 35 个正式 Structure Group 全部与 `catalog/logic-map.json` 一一对应。逐项清单见[资产覆盖清单](工作流/资产积累与入库/资产覆盖清单.md)。

正式生成线缺少合适 Structure Group 时，使用已登记的简单 Composition 继续交付，并在运行记录中保留 `asset-gap`；内容容量问题继续单独处理，不伪装成资产覆盖缺口。
