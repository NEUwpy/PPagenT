# 科研／咨询式论证排版 v5

候选指南，尚待独立试做。它与单独的 Theme 组合使用，不包含学校身份或固定主题色。参考方向来自已归档样板中的整页分析：判断明确，证据可比较，解释与对象相邻，主次通过空间和字重显露。不得叠加旧大学模板或旧指南。

## 让页面成为清楚的论证

用一句短判断作为标题，让读者知道这一页最值得理解什么。主体展示支撑这个判断的依据；解释进一步交代意义、机制、条件或行动。每个区域增加信息：标题概括，图表显露比较，旁注解释差异。把已经出现在图中的数值原样读一遍，不会成为新的分析。

数字材料用相同尺度、清楚单位和直接标签呈现关键差异。为标题所强调的对象赋予主题色重点，其他对象保持可读的较低权重。关系材料用位置与连接呈现真实的先后、归属、条件或对照；解释沿着对应对象排列，使读者能在同一视线附近找到“是什么”和“意味着什么”。不为非数值材料伪造图表。

普通文字也有分析结构。将一个发现及其依据聚成紧凑阅读组，短判断用字重区分，必要说明自然成段。比较对象共享维度与行位；过程的职责、推进条件与步骤相对齐；贯穿全局的要求有独立清楚的位置。内容不同的区域可以有不同大小，视觉分量与信息贡献相称。

## 先组织整页，再形成局部图形

先为判断、主要依据、解释与重要条件共同预算空间。依据是主体，解释贴近所解释的对象；各区域通过共同外边线、行位或连接形成一个完整分析。图形与解释相互配合，不需要把每组信息圈成卡片。细线用于分区、比较或关联，浅底用于层级与归属。

一个问题可以由主分析和辅助分析共同回答。例如总体与分解、现象与机制、过程与职责。这些内容共享对象名称、色彩含义或对齐轴，各自回答不同问题；不重复画相同数据来占空间。

按本页内容选择横向、纵向或混合编排。主要关系图可以只占局部，文字可以沿其节点外置；让图形承担关系，让说明承担信息。先保证说明的自然行宽，再确定图的尺寸。组内紧凑、组间有停顿，留白位于边界与阅读转换处；不要为了撑满均匀拉开段落，也不要把解释压成窄碎列。

使用 ppagent-structure Skill 查找合适参考。本次允许参考重组：吸收其关系表达、连接方法与层次，按自己的页面区域重新布局原生元素。源实现的满幅尺寸、固定坐标及内部造型不限制新表达。取用其方法，不必把整个隐喻图原样搬来。直接执行原组件时才遵守原组件的尺寸与参数契约。两种路径如实记录，不能混称。

## 视觉配置与边界

分析页采用报告式层次：顶部完整判断，下面用细分隔线建立稳定标题边界；主体局部标题与证据从共同起点展开，来源与页码低权重收尾。相邻页沿用外侧轴线、字体角色和主题重点，内部组合由问题决定。页面第一层是判断，第二层是分析，章节标签不能抢在判断前成为视觉入口。

- 1280×720；版心左右55，顶部36；主体下沿658，来源与页码位于672–696。标题可一至两行，按实际高度为下方内容留下空间。
- 使用 Theme 的字体和色阶。标题32加粗，组判断22加粗，正文与节点解释20，图表刻度/数据标签16，来源/页码14；单位均为设计 px。普通计划数字不自动放成超大字号。
- 标题、正文与节点句子左对齐；独立数值、符号与图表标注按数据归属排列。段落行高1.25，同组净距8、独立组24、主区域32。对齐以实际可见文字为准。
- 强调集中在能支撑标题的对象；中性文字用近黑，次要标注用灰，主题深浅表达必要层次。禁止渐变、投影、3D和无信息装饰。
- 不改变事实、因果强度、计划状态与权限边界。限制结论的重要条件使用正文，在所限定的内容附近出现。制作术语不进入上屏文案。

## 完成检查

沿“判断→依据→含义”阅读实际文字：主体是否支撑标题，解释是否增加信息，遗漏的条件是否会改变理解。核对实际导出的字号、颜色、文字行与边界；数值及单位自然成组，避免孤立符号和碎行。空间不足时调整内容分组与区域尺寸，使用规定的角色字号，不以连续缩字试错。

生成者不需要图片输入，使用文字与几何反馈；预览留给审阅者。原生结构参考重组保存来源和本次变化；几何通过与审美通过分别报告。此指南不会因为一次样品生成就自动成为已验证 Skin。
