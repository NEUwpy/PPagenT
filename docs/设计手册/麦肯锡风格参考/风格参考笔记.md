# 麦肯锡式排版：离线风格参考笔记

更新：2026-09-06。五个用户链接与三张用户本地图集中在这里。共28张：24张网页原图、1张网页截图、3张用户原图，均已实际查看。本文图片使用本地路径，后续阅读不需要登录小红书。原链接用于追溯；临时图片地址与文件校验见[下载清单](download-manifest.json)。

## 我们要学习什么

目标是让较强模型从样板中提炼文字指导，再让没有图片输入的 Luna/high 独立做出逻辑清楚、证据突出、整页连贯的原生可编辑 PPT。已有结构库服务局部关系表达；风格指南负责判断、证据、解释怎样共同成页。

参考有不同职责：**极简指南提供设计方向；本地 McKinsey 总览和最新 AI 样板提供主要整页视觉对照；精英感图集补充复杂材料的组合方式；思维模型与 MECE 图集帮助理解局部关系。** BCG、Bain 图保留作差异对照。这是项目的使用分工，不把第三方样板当成三家公司的官方规范。

### 能转成正向提示词的共同方法

| 观察到的设计动作 | 给执行模型的方向 | 判断它有没有做到 |
| --- | --- | --- |
| 标题先说出值得注意的变化或判断 | 用一句准确判断统领整页，正文给出依据与条件 | 读完主体能解释标题为什么成立 |
| 证据占连续的主体空间 | 把主要差异变成能直接比较的证据表达 | 读者不用逐格读表才找到重点 |
| 图旁有意义层或行动层 | 解释这个差异意味着什么，贴近对应证据 | 解释没有复述标题或朗读图内标签 |
| 同类信息沿共同尺度排列 | 比较共享维度、行位、基线、单位与颜色含义 | 位置能帮助匹配，视觉待遇不会误导比较 |
| 主证据与辅助证据有层次 | 一个分析问题可有多个相互支撑的视图，形成一个证据组 | 页面整体讲一件事，视图各有独有贡献 |
| 色彩只强调有意义的差异 | 让重点对象更清楚，其余证据退后但仍可读 | 第一眼看到的是关键发现，不是装饰 |
| 解释靠近对象、空白位于组间 | 图文共同预算空间；同组紧凑、组间清楚 | 不在大图完成后找空洞塞字 |

### 边界要防止哪些偏离

- 不把一个巨大的结构隐喻当成整页分析；其视觉分量应与信息贡献相称。
- 不把模型名、分类标签或“图外解释”当成有内容的判断。
- 不为调用结构或凑三个要点扭曲材料；先有论证，再选表达。
- 不把关键条件降成小字，也不把所有条件挤成标题清单。
- 不照搬参考中的业务数字、倍率、调查结论或模型故事。这里研究编排，未核验这些材料的事实。
- 不从样板图片推断它能原生编辑，也不把几何检查通过等同于风格通过。

## A｜用户本地三张图：整页视觉对照

原文件由用户提供，文件名保持不变。三张均为四页总览；来源机构标记是图片自身的标签，未验证原作者与制作过程。

### A1｜McKinsey style overview

四页分别呈现市场变化、需求驱动、技术迁移和竞争位置。每页上方是完整判断与细分隔；主体是一个宽证据区，右边是相对窄的解释区。技术迁移页把上方阶段关系与下方变化图共同组织，右侧讨论买方影响。这最直接体现了“结构＋数据＋解释”共同成页。标题的衬线字是该样板的表现之一；应先学信息架构，中文字体再单独配置。

![本地 McKinsey 总览](微信图片_20260906004635_183_5.png)

### A2｜BCG style overview

同一主题更强调多个分析模块的并置：三图共用顶部判断、指标表与证据列按行对应、底部放局部含义。绿色与紧凑分区形成另一种分析气质。可学共同维度与局部发现的组织，不把它的高密度或每页三图当成我们的强制规则。

![本地 BCG 总览](微信图片_20260906004644_184_5.png)

### A3｜Bain style overview

红色突出标题中的关键命题及少量数据，其余证据保持黑灰。结构与数据共同说明价值如何变化；右侧战略问题使读者知道需要判断什么。可学有选择的强调和行动含义，不把红色、图标或底部重述直接混入 McKinsey 候选 Skin。

![本地 Bain 总览](微信图片_20260906004653_185_5.png)

## B｜主要文字指南：麦肯锡 PPT 极简视觉设计指南

[原笔记](https://www.xiaohongshu.com/explore/68031002000000001c012584)，麦家PPT。六张已离线保存并重新逐图读取。

设计方向是减少阅读负担、建立层次、统一视觉语言。图集中的正文规范与嵌入样板需要分开：嵌入样板本身出现了组合图，所以不能把“一图”机械解释成禁止共同支持一个判断的辅助视图。图4写的是**内容占比不超过60%**，不是留白不超过60%；未给出测量口径，本项目不将该比例做机械验收。

### B1｜封面

用于识别来源，封面曲线与大字不转成分析页装饰要求。

![极简指南01](images/01-minimal/01.webp)

### B2｜为什么要简洁

嵌入样板将多类别变化按同一尺度排开，唯一逆向变化使用强调色；学习让异常清楚可见。

![极简指南02](images/01-minimal/02.webp)

### B3｜聚焦、结构与统一

对比条形共享标签和行位；即使项目多，读者仍能直接比较。

![极简指南03](images/01-minimal/03.webp)

### B4｜图表与空间

图内直接标注数值与类别，减少来回查找；单位、口径仍保留。

![极简指南04](images/01-minimal/04.webp)

### B5｜组合证据

上方排序与下方构成共同展开一个判断，框选只强调一个相关对象。

![极简指南05](images/01-minimal/05.webp)

### B6｜检查与比较

横条的分段颜色、连接与标签展示两组构成差异；统一图形语法即可形成专业感。

![极简指南06](images/01-minimal/06.webp)

## C｜精英感图集：复杂材料怎样组成整页

[原笔记](https://www.xiaohongshu.com/explore/6a6e91540000000022030d8d)，Co PPT。六张均已保存并逐张读取。学习其关系组织，图集的厚阴影、3D承载面与大号装饰不作为当前风格要求。

### C1｜主辅与转译

宽分析区配短解释；发现与目标信息分区对应。应学分工，而非右侧厚重卡片外形。

![精英感01](images/02-elite/01.webp)

### C2｜对照与支持

双图共用比较逻辑，文字主张与指标表相邻，解释与分组图相配。

![精英感02](images/02-elite/02.webp)

### C3｜标准、计算与说明

选择标准对接分析，计算表保留共享列，建议回应与原问题逐行对应。

![精英感03](images/02-elite/03.webp)

### C4｜纯文字也能显露论证

上页用逐行主张与展开说明指向共同结果。无需为了专业感强造图表。

![精英感04](images/02-elite/04.webp)

### C5｜假设与证据的不同宽度

资源页以窄区承载假设、宽区展开估算与依赖，区域尺寸跟随信息职责。

![精英感05](images/02-elite/05.webp)

### C6｜从局部发现到整页判断

局部标题统领证据，注释指向具体位置；阶段与类别以行列组织。

![精英感06](images/02-elite/06.webp)

## D｜less is more：结构与局部解释

[原笔记](https://www.xiaohongshu.com/explore/6a20cce1000000002202b9f0)，Co.PPT。五张现已完整保存与查看。其图片主要是思维模型教学图集，与正文的汇报建议不是同一种内容。使用其结构—说明对应方法，不把它的每个模型故事当作事实或把模型名当分析页结论。

### D1｜中心关系与侧边解释

SWOT、曲线、鱼骨分别把解释贴近所描述的区域或结果。

![less is more01](images/03-less-is-more/01.webp)

### D2｜双侧对应与环绕说明

双塔、环形、漏斗的外文各自对应结构中的具体位置。

![less is more02](images/03-less-is-more/02.webp)

### D3｜结构与公式、例子共同解释

图与公式、过程与说明共同承担教学；不是孤立结构占满页面。

![less is more03](images/03-less-is-more/03.webp)

### D4｜相邻信息的职责差异

图解与明细表、版面示意与步骤说明并置，解释层有自己的内容。

![less is more04](images/03-less-is-more/04.webp)

### D5｜结果、维度和应用

过程之外有结果解释，分类维度下有判断依据，概念旁有应用案例。

![less is more05](images/03-less-is-more/05.webp)

## E｜MECE：分类与论证关系

[原笔记](https://www.xiaohongshu.com/explore/69dad770000000002100794d)，木知思维。五张现已完整保存与查看。重点是分类维度、上下归属、观点与依据的关系；厚虚线框、竖排小字与水印不是当前 Skin 的设计要求。

### E1｜关系示例与方法旁注

正确与错误示例并置，旁边说明如何检查。

![MECE01](images/04-mece/01.webp)

### E2｜归属与分类口径

父子关系与分类方式被明确区分；布局关系需要先有语义依据。

![MECE02](images/04-mece/02.webp)

### E3｜观点与支撑

上层观点由下层理由支持；这是论证组织，不等于每页必须画金字塔。

![MECE03](images/04-mece/03.webp)

### E4｜过程与比较

连接线表达实际步骤，前后对照共享主题，解释在关系附近出现。

![MECE04](images/04-mece/04.webp)

### E5｜同维度对应与表达顺序

例子按行比较，表达框架附有解释。教学框架中的重复结论不自动变成每页重复页尾的要求。

![MECE05](images/04-mece/05.webp)

## F｜最新 AI 样板：从贴表格到显露重点

[原笔记](https://www.xiaohongshu.com/explore/6a13bdff000000003802032a)，FIinn。用户明确喜欢的样板。三张均已实际查看；第二、三张为原图，第一张原资源导出失败，保存了浏览器中已显示画面的完整截图。第二张是作者称的改后，第三张是改前。

### F1｜整套总览

分析页使用短解释、图表、图片或结构的共同组合，重点蓝色贯穿。封面与分析页承担不同任务。

![AI样板总览截图](images/05-ai-sample/01-overview-screen.png)

### F2｜改后：一个主分析带出辅助分析

上页左侧短发现与右侧趋势对应。下页用主构成图、右侧差距强调和底部分解，共同回答一个经济性问题。核心方法是选择视图与视觉重点，不是加一个大结构。

![AI样板改后](images/05-ai-sample/02.webp)

### F3｜改前：原始信息尚未完成视觉组织

原始表格提供数据，但重点需读者自行寻找。风格迭代要把数据中的关系变成可见比较，同时保留必要口径。

![AI样板改前](images/05-ai-sample/03.webp)

## 下一轮提示词如何使用这份笔记

先从 A1、F2 取整页主线，再用 B 的聚焦与统一收边界；C 为复杂组合补例，D/E 只在相应关系需要表达时调用。不要把所有图片的装饰和密度平均混合。

父任务读取图片后写提示词，Luna 只读取提示词、稿件与必要接口。试做稿同时包含定量证据、定性解释与真实结构关系；不固定逐页坐标或强制每页调用结构。评审首先比较整页的论证与视觉主次，再查原生对象及几何。旧样品即使接口通过也不计风格通过。
