# 科研／咨询式排版：复用入口

当前指南：[科研咨询式排版 v7](科研咨询式排版-v7.md)。视觉依据与原图保存在[风格参考笔记](麦肯锡风格参考/风格参考笔记.md)，生成任务不需要重新登录网页，也不必接收图片。实际通过状态见[验证记录](../../experiments/university-skin-pilot/README.md)。

## 输入

Skin 选择一个 Theme 和一个 LayoutGuide。Theme 提供主色、字体及组织身份，LayoutGuide 提供判断与证据的组织方法、文字角色和视觉边界。大学可以共享本指南，更换主题。结构库提供局部关系的参考与可选直接实现，不为每页预先指定一个满幅结构。

生成任务需要：实际稿件、选定指南、Theme 文件和明确输出目录。正文不需要文字模板。需要逻辑结构时读取 `.codex/skills/ppagent-structure/SKILL.md`，按真实目录检索；参考重组读取 `reference`，直接执行读取 `inspect` 与调用契约。

## 可直接使用的任务提示

根据所附稿件生成原生可编辑 PPTX。先读取指定 LayoutGuide 和 Theme，再确定每页有依据的判断及证据表达。自行决定页数、区域、图文分工与结构参考；如任务明确页数则遵守。让结构与解释共同组成整页，保留原稿的关系、条件和事实边界。不要继承旧大学 Shell 的固定正文槽位，除非任务明确要求套用旧模板。

需要结构时真实检索 ppagent-structure，选择直接执行或参考重组，并记录实际方式。参考可改变源几何、方向、尺寸和图内外文字分工；其关系表达必须正确。使用 Theme 文件生成色阶，不复制另一套固定色号。生成过程只使用文本、工具和几何信息；不要自行打开图片。

导出后检查实际字体角色、文本行宽与行高、文本相交、文本与细线关系、共同对象排序、数值尺度、连接起终点以及所有关键条件。修正后重新生成 PPTX，再重新渲染，记录最终文件哈希和检查结果。父任务审核最终渲染，给出具体文本反馈时继续修订。报告区分客观检查、未检查事项和父任务视觉验收，不能自行宣称风格已通过。

## 执行与审查

本轮有效的组织方法有两类。数据分析把同一对象的指标保持同序，门槛与差值放入证据视图，紧邻的短句解释选择依据；不要把图上每个数字重新讲一遍。流程方案先给紧凑关系骨架，职责和局部异常沿所属阶段展开，跨阶段记录和验收独立成区；不要先让职责铺满上半页，再把结构与所有剩余内容挤到下方。两者都是图文分工方法，不规定逐页坐标。

节点只保留关系所需的短对象名与必要条件，完整记录、权限及异常细节在对应的开放文字里展开。已经在图旁说明的职责不再在页底重复成一组卡片或栏目。组内标题、责任、正文共享左边线；图内标签需要以图元为锚点时，核对实际文本对齐方式，不能只比较文本框中心。

当前确定性工具是 `experiments/university-skin-pilot/audit-text-overlaps.mjs`，输入实际导出 layout JSON，输出文字框相交、横竖细线相交和不足8px净距候选。它不完整检测曲线、字形轮廓或审美；节点内部居中标签等候选要根据实际结构核对，不能一律忽略或一律删除。

父任务从最终 PPTX 独立重渲染，再与参考比较；每次修改都使旧预览失效。首轮与反馈修订分别记账。当前实现是本地 Codex/Luna 的生成—检查—修订闭环，尚未证明一次生成稳定，也未将本指南迁移到 DeepSeek/Harness。后续迁移应复用同一指南、Theme、结构 Skill 与客观反馈格式，而不是把某份样稿的坐标固定成模板。
