# PPagenT 产品叙事

PPagenT 的目标是：用户给一篇稿件，系统可靠地产出内容忠实、逻辑清楚、风格合适、原生可编辑的 PPT。

它不追求每次随机生成一个惊艳页面，而是把可复用的设计经验前置沉淀为规则、Skin、布局、结构和程序，让生产结果稳定跨过可用线。

生产只有两大阶段：

1. 稿件到灰稿：语义理解稿件，形成页面表达共同契约，并编译为可直观看的灰稿。
2. 灰稿到成品：读取同一契约，有限选择已建设的能力，由程序生成最终 PPT。

建设阶段由用户与 Codex coworker 设计、实现和看图。Codex 的视觉能力只服务建设，不进入产品。投入使用阶段只调用语义理解模型和 JEV；模型选择受限，程序负责确定性计算和执行。

这条路线的价值不是固定模板，而是把固定要求资产化、可复用设计组件化、内容变化参数化、确定计算程序化，把临场生成转成理解、选择、填充和求解。

当前项目追求 MVP。两段均未完成整体验收；现行状态见[产品定义](产品定义.md)、[页面表达共同契约](架构/页面构成与布局规范.md)和[项目进度](方向讨论/页面编排能力计划.md)。
