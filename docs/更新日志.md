# 更新日志

本文只记录 PPagenT 生成能力版本及其真实输出，不重复产品定义或技术设计。

## 版本规则

- 生成文件统一命名为 `稿件名-v主版本.次版本.修订版本.pptx`。
- 新增生成能力、版式家族或规则能力时，至少增加次版本号。
- 不改变能力边界的错误修复增加修订版本号。
- 不兼容的输入、契约或运行链路变更增加主版本号。
- 一个版本正式交付后不得覆盖；再次生成必须使用新版本号并保留旧文件。
- 仓库 `package.json`、生成文件名和本日志中的生成能力版本保持一致。

## v0.1.0 — 2026-08-09

第一个可辨认的真实稿件版本。

### 新增

- 建立《为什么做 PPagenT》项目缘起文档。
- 首次把完整中文稿件拆成 10 页演示，形成可编辑 PowerPoint。
- 建立真实稿件实验目录，保存稿件来源、页面规划、资产对应关系和生成入口。
- 首次在一套演示中实际调用顺序流程、双向对比、中心辐射和分层架构候选资产。
- 建立真实稿件输出命名与版本约定。

### 本次发现并修复

- 顺序流程的两位编号因文本内边距发生换行。
- 中心辐射六节点布局过于贴近统一页脚。

相关案例已写入失败案例库，不因修复完成而删除。

### 当前限制

- 这次的整套讲述规划和内容到参数的映射仍由人工完成，尚不是自动化 DeckPlan 闭环。
- 使用的结构资产仍处于备选状态，本次生成不代表已晋升核心资产。
- 原模板中的组合校标还不是独立品牌资产；为避免错误裁切，本版使用普通文字标注学校名称。
- 文字预算和长短极不均衡内容仍缺少足够真实稿件验证。
