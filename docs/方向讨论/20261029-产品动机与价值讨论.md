# 动机、痛点与商业机会

2026-11-16 更新。本文记录用户洞察与商业假设；阶段、交付要求见[目标与路径](../产品目标与路径.md)，技术取舍见[技术选型与决策](../技术选型与决策.md)。需求强度、付费意愿与商业规模尚未验证。

## 动机：不折腾

**用户希望得到好 PPT，但不希望自己承担设计判断，也不希望学习怎样持续指挥 Agent 做设计。**

成本包括模型费用，也包括学习、配置、提示、调试与返工时间。希望售卖的是可重复交付的设计能力，让已有内容更省事地成为能用的 PPT。

## 服务谁，解决什么

**反复需要完成日常演示，要求清楚得体、稳定可靠，愿意沿用熟悉设计，希望少操心的人。** 重点面向中国市场：学生组会有论文或研究材料，老师讲课有讲稿或教材，企事业单位员工汇报有工作材料和数据。

用户提供的评论观察与自身体验提示：材料和主要观点已经具备时，可靠排版与美化可能比继续生成内容更有用。这是第一阶段的需求假设，尚无“大多数用户如此”的比例证据。

国内已有相关供给，参照 [WPS AI](https://x.wps.cn/pc)、[iSlide 企业版](https://www.islide.cc/enterprise)；功能说明不能证明实际交付质量。待确认的痛点是：

- 初稿之后仍需用户判断、核对和精修。
- Skill 即使免费，配置、学习和调试仍耗时。
- 大量模板增加选择负担，一套合适、稳定的设计可能更省事。

机会在于承担这些负担，设计与调试经验跨稿复用。例如长期沿用东北大学风格，每次制作节省的时间可能形成持续收益。

## 怎样形成价值

“做”是建设可复用的交付能力；“连接”是让用户发现、采用并持续使用，使能力产生价值与收益。只有技术积累，尚不能判断商业体量。

个人自助、团体采购／私有部署、第三方接入／API 都可服务上述人群，购买方式与用户画像分别讨论。保密机构的本地部署是候选交付方式，其需求、成本和收益仍需了解。

## 未来与护城河

当前认同但并不确定的趋势判断：

| 变化 | 对项目的影响 |
| --- | --- |
| 普通生成能力与 token 越来越便宜 | 单靠低价生成难以保持优势 |
| Agent 融入日常软件 | 现成产品也会越来越省心，用户无需先学习 Agent |
| 生成更容易 | 竞争更依赖交付质量、适合程度，以及核对和返工的总成本 |

国外 Agent 的使用门槛只可能提供进入机会。大厂可以复用相近技术，组件库、规则或私有部署本身尚不足以构成护城河。

可能形成积累的是：适用条件与选择判断、设计及失败修复经验、跨稿稳定交付，以及用户信任和触达渠道。这些仍是候选机制。若现成工具同样省心，优势就会缩小。

## 是否值得继续

- 有用户反复遇到同样负担，愿意持续使用或付费。
- 设计与调试经验可以跨稿复用，建设维护成本能被后续使用摊薄。
- 相比可获得的现成方案，交付质量、操作负担或总成本有明显收益。

若逐稿都需大量人工定制，或现成方案轻松满足同样要求，应收窄或重新判断投入。人群多、组件多、能够生成，都不能单独证明商业空间。
