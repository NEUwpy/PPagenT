原PPT中，视觉组织主要依赖：

**框 → 连线 → 框 → 文字**

例如左边三个问题通过连线汇聚到“变革落地阻力重重”，右边四点感悟基本是四段并列文字。

它很容易理解，但设计语言比较直接，属于典型商务PPT做法。

新版本则把信息组织成：

**编号 → 标题 → 解释 → 线性关系**

尤其右边的 01–04，被做成一个连续的竖向序列。

这就是最典型的差异：

> 不强调“这个东西是一个卡片”，而强调“它是整个逻辑体系中的第几个节点”。

因此视觉上会更冷静。


### 新版的“理性感”明显更强

原PPT更像是在说：

> “这里有两个问题，那里有四点经验。”

新版更像是在说：

> “这个页面包含两个分析单元，每个单元内部有明确编号和逻辑关系。”

这是一个很重要的变化。

比如新版右侧 01–04 的处理，让“四点感悟”不再只是四条文字，而具有一种**研究条目 / 论点编号**的感觉。

这会自然带来一种“高智感”。

高智感其实往往来源于：

**分类明确 + 层级稳定 + 格式一致 + 克制表达**

而不是华丽。

## 2026-09-20 实测总结

已完成1轮对照、6轮正文试验；当前看图选用第6轮，待你审阅。[可编辑PPT](../../experiments/home-mckinsey-style-20260920/gray-to-mckinsey-refined.pptx) · [新旧对照](../../experiments/home-mckinsey-style-20260920/index.html)。Skin 保持原样，汇聚结构继续实际调用结构库；参考图新增的解释没有加入原文。

- **先有执行能力，再谈提示词。** 旧工具只调列宽；追加风格描述后，图片哈希完全不变。需开放通用视觉控制，不能把改代码伪称为提示词成功。
- **用组织动作替代气质词。** 共用起线、编号索引、标题—解释、同口径短项，比“冷静、高级、克制”更有效；不写本页的专有名词、固定条数或专用坐标。
- **浅底承接阅读，编号负责定位。** 轻浅色面比硬标题条柔和；编号和无箭头细线形成连续阅读，不额外制造步骤关系。
- **均衡的是间隙，不是文字高度。** 保持自然行高，把组尾余量还给条目间距，避免上密下空。
- **修改候选，别反复推倒。** 重开生成出现过有效特征回退；保留第4轮有效选择，只修正余白，第6轮更接近参考的秩序感。
- **错误反馈要具体。** 对象与状态须为互不重复的原文片段；一次字段错误不能被模型解释成“原文不适合这样表达”。
