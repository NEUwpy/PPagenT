# 外部项目学习

本目录记录 PPagenT 从外部项目中发现、验证和吸收的可用方法。

## 不变的主航道

PPagenT 不追求让 AI 自由适配所有稿件，而是先把一个固定场景做好：

- 主题固定字体、字号、颜色、版心、间距、Logo 和基础版型。
- 内容导演与视觉导演负责理解、拆页、编排和选择。
- 代码调用已经固化的文字、结构图和图片版式，生成原生可编辑 PPT。
- 前期建设较重，建成后重复生成应当稳定、便宜。

外部项目是创意和方法来源，不是新的产品方向。自由 HTML、自由绘图或通用演示生成可以研究，但不会未经验证进入正式生产线。

## 学习方法

1. 在[清单](清单.md)中登记项目及可能有用的能力。
2. 初步研究后建立一份项目记录，只写差异、可吸收点和边界。
3. 候选做法默认只做 `现有方案 1 页 + 优化方案 1 页`；成本很低时可多给 1–2 个方案。
4. 用户逐页判断。效果没有明显改善就停止；确认有效才决定落入主题、视觉导演提示词、资产或入库流程。
5. 项目记录补充实验结果和最终决定，避免同一想法反复研究。

不整段复制外部提示词，也不因为外部项目功能更多就增加 PPagenT 的野心。

## 状态

- `待研究`：只登记了来源。
- `已研究`：已形成判断，尚未实验。
- `待验证`：已有一个可控的小实验。
- `已吸收`：用户确认有效，并已落到本项目。
- `不采用`：已明确不符合当前路线。
