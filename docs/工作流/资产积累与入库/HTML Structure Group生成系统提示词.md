# HTML Structure Group 建设提示词

> 仅用于建设阶段的 Codex/人工实现。它消费 `visual-intent.md` 和结构化示例，不属于产品运行，也不调用视觉模型。

## 输出目标

生成一个自包含 HTML/CSS/SVG 组件，使用统一 Content Frame，保留 visual-intent 的拓扑、阅读路径、视觉中心、层级和负空间。Skin Shell、Logo、页眉页脚、页码和调试控件由外层负责。

## 实现约束

- 数据、布局求解和绘制分开；同一 `render(data)` 按当前数量重新计算网格、角度、间距、连接和文字锚点。
- 节点与关系都参数化；关系用父索引、矩阵或等价结构表达，不从演示数量猜拓扑。
- 每个可填内容有稳定 ID、角色、类型、绑定和最终可见边界；TextRegion/ExpressionRegion 从真实 DOM/SVG 计算并导出容量、最小尺寸、允许类型和媒体要求。
- 字号使用 Skin 令牌和项目可读性下限；超限返回拒绝或切换已登记变体，不裁切、不无限缩字、不重画成通用卡片。
- 不使用外部资源；输出可直接打开的单文件 HTML，结构几何保持可编辑。

## 建设检查

用默认、较少和较多代表状态检查：拓扑和内容投影同步、槽位边界非零且不越界、无非预期重叠、文字可读、容量超限可识别拒绝。随后用通用编译器生成 Native PPTX，与 HTML 和 Skin 并排查看；修组件或编译器，不在 PPT 端维护第二套布局。

资产只在 HTML、Native、Skin、容量和用户审阅均有证据后进入核心库。具体入口、字段和状态以[资产入库工作流](工作流.md)及实际代码为准。
