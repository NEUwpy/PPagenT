# 视觉意图提炼（建设阶段）

> 这是资产建设的人工/Codex 工作表，不是产品运行提示。Codex 可查看来源截图；产品运行不调用视觉模型。

输入来源页、对象摘要、参考角色和一句话逻辑需求，输出该 Structure Group 的 `visual-intent.md`。只提炼可复用的逻辑与审美，不逐坐标复刻。

## 必须回答

1. 参考页各自贡献什么；最终采用哪一个逻辑骨架和审美方向；舍弃哪些冲突做法。
2. 内容关系和阅读路径：并列、层级、过程、因果、循环、对比或组合；先看哪里、后看哪里。
3. 结构语法：单元如何对齐、连接、包围、遮挡、分支或汇聚；哪些线/边界是逻辑而非装饰。
4. 审美规则：主次、体量、留白、比例、颜色和层级的相对关系；哪些改变会破坏身份。
5. 内容/媒体绑定：标题、正文、指标、图标、图片的角色；缺图时是否仍可用。
6. 不变量、可变量、数量/密度边界、换变体条件和失败判据。
7. 相对现有资产的覆盖增量；若只是换皮肤，停止新增。

不写固定坐标表，不要求单稿专属字段；无法从来源确认的内容标记“待确认”。最终结果必须能指导同一组件的参数化实现和容量拒绝。
