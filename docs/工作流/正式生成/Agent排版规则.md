# 建设阶段排版规则

本文只服务建设阶段的 Codex/coworker 探索，不是产品运行提示，也不授予使用阶段模型自由绘制权限。

建设目标是：给定页面表达共同契约，使用 Skin、风格、布局、结构和原生程序做出可编辑成品预览。Codex 可以看图并提出修订；后段改变页面关系、主次或分页时必须写回共同契约。

2026-10-29 边界：main 编排实文与蓝区，不制作成品结构图或放入图片；本页服务 home 对蓝区的图形/媒体填充。建设中的人工反馈不成为产品流程节点；产品从 Markdown 图文稿件到 PPT 自动完成，完整口径见[产品需求](../../archive/20261030重新讨论前/docs/产品需求.md)。

使用阶段由语义理解模型与 JEV 选择合法能力，程序负责测量、参数、槽位、几何和构建。产品不调用视觉模型。

每次建设保留输入契约、规则/资产版本、PPTX、PNG、日志、问题和验收状态。模拟成品只证明后段，不能证明前段自动规划或跨稿稳定。
