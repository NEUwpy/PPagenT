# Agent 排版规则 v0.2

> 当前设计试做输入更新为[咨询式整页设计指南 v1](../../设计手册/咨询式整页设计指南-v1.md)：以第四篇极简指南为主，验证普通文字与现有结构共同组成整页的能力。尚未通过验证；下文旧候选保留历史背景，不叠加旧 Shell、字号与文字模板约束。

> 2026-09-05；用户明确采用“正向设计指导 + 边界规则”，以充分的审美方法引导自主决策；不以含糊的习惯建议代替指导。本文是有效设计约定，自动检查尚未完整实现；已有 Luna 单稿证据对应此前版本，不能当作 v0.2 的验证结果。

## 核心约定

Agent 根据内容和 Skin 规则生成页面，可以直接组合原生文字、形状、线条、连接符及真实媒体，不要求先选择文字模板、整页版式或结构资产。结构库是可选的经验复用；调用某个资产时仍遵守其关系、容量和尺寸契约。

“按规则自己做”由三部分共同成立：Agent 判断内容与编排，原生执行器负责测量和生成，Harness 把具体问题反馈给 Agent 做有限修订。规则不代替绘制工具，也不意味着模型一次输出一定正确。默认不向模型输入图片。

## 正向指导、边界与自由决策

“谁可以决定什么”的权威入口是[架构中的决策权与自由边界](生成线架构决策.md#决策权与自由边界)。本文件提供具体排版规则，不意味着每种布局都要预先登记。架构界定职责，Skin 给出本次设计规范，Agent 在边界内决定页面，所选结构 Skill 约束其内部实现。

正向指导来自所选 Skin 的审美积累，说明阅读入口、分组、视觉重心、间距和整套节奏的组织方法；当前候选见[咨询式分析设计手册](../../设计手册/咨询式分析-v1.md)。边界来自本次用户要求、内容与交付底线、选定的 Skin 配置和所调用 Skill 的契约，适用即必须满足。用户明确修改配置时更新规则，Agent 不能自行豁免。规则冲突须明确处理，不能静默丢掉其中一项。

其余为自由决策：页数和页序未被指定时自主安排；分栏或堆叠、区域比例、是否使用结构、文字框数量和强调位置由 Agent 决定。相邻页面可以相似，也可以不同；没有页型配额；依据正向指导选择适合内容的构图，不要求每次重新解释合法选择。

工具不支持的动作不能假装执行。来源 ID 可用于追溯，不能独自证明语义正确。测量能力未实现或缺少判定参数时记录“未检查”，不能报告全部规则通过。此状态不是软规则或豁免机制。

下表列出执行边界，不代替 Skin 的完整正向指导。“本次正文”等标记表示适用范围。能够机械验证的条件由程序检查实际产物；其余逐项记录核查依据。未被规则限制的值不再附加“通常”“优先”“尽量”等软指示。

## 内容组织

| ID | 规则 | 性质 |
| --- | --- | --- |
| C01 | 每页记录沟通目的、内容组、来源和阅读顺序。章节页可以只有标题和定位；具体目的、分组、页数和排列在任务未限定时由 Agent 决定。 | 必须 |
| C02 | 按语义分组，分别识别组间和组内的并列、对比、顺序、因果、包含等关系；允许同页不同组使用不同关系。 | 必须 |
| C03 | 数字、单位、范围、否定、条件和不确定性不能在提炼中失真；箭头和层级也必须有内容依据。相关性不能自行画成因果。 | 必须 |
| C04 | 先确定主次与阅读顺序，再决定展示量；不以固定字数或一段一页代替分页判断。细节可进备注，但本页核心结论和理解所需条件必须可见。 | 必须 |
| C05 | 只有能共同完成一个沟通目的的内容才合页；拆页时保留论证衔接。可见内容及备注都保留来源绑定。 | 必须 |

## 整页布局

| ID | 规则 | 性质 |
| --- | --- | --- |
| L01 | 正文位于 Skin 的 Content Frame 内，尊重页标题、Logo、页码等 Shell 保留区；正文调整不挪动身份元素。 | 必须 |
| L02 | 页面声明的同级文字使用同一语义样式；核心信息不得通过降为注释角色来避开容量限制。主次位置与强调手段由 Agent 决定。 | 必须 |
| L03 | 图形面积、比例或视觉权重用于表达数值、优劣或倾向时，必须有内容依据。区域本身是否等大、采用何种比例由 Agent 决定。 | 必须 |
| L04 | 改变文字、字号、区域宽高或排列后，使受影响的布局检查失效并重新测量。具体坐标与排列方向由 Agent 决定。 | 必须 |
| L05 | 每页正文的对齐方式只能有一种，允许值为 left 或 center；结构外的说明也计入正文。Shell 按自身契约，编号标记单独检查。多栏可以各自左对齐，不要求所有栏使用同一个 x 坐标。 | 必须；本次正文 |
| L06 | 背景容器包含文字属于有意叠放，不按碰撞处理；独立内容不得相互遮挡。 | 必须 |
| L07 | 遵守已配置的安全区和内边距；禁止通过空框、装饰填色伪造内容密度。本次要求避免严重稀疏/过密，记录实际空白与占用；未定义的通用阈值不能声称已自动验收。 | 必须；密度自动判定待完善 |
| L08 | 同一套 PPT 使用选定的 Skin 字体、颜色和语义字号配置；只能在声明可调项内改变样式。页面构图可以自由变化。 | 必须 |
| L09 | Skin 若声明间距允许集合或范围，则实际间距必须符合；未声明的间距由 Agent 决定，仍需满足边界、无遮挡及文本容量规则。 | 必须；仅约束已声明参数 |

## 文字排放

| ID | 规则 | 性质 |
| --- | --- | --- |
| T01 | 使用 Skin 的语义角色：页标题、核心结论、组标题、正文、辅助说明、注释。按角色选样式，不按“左栏正文模板”等固定槽位选样式。 | 必须 |
| T02 | 依据实际字体、字号、行距和区域宽度测量换行与高度。标题可以合理换行；文字组不等高分配。标题应与其第一段正文保持相邻。 | 必须 |
| T03 | 同页同语义角色的文字使用一致的字号和字重；不能单独缩小长段落以规避约束。角色数量未被 Skin 限定时由 Agent 决定。 | 必须 |
| T04 | 不用空格拼对齐，不用手动回车模拟列；不拉伸文字、不隐藏溢出。必要断行应符合语义，避免拆散数字与单位。 | 必须 |
| T05 | 字号只能在选定 Skin 的允许档位内调整，不能越过角色下限。Agent 自行选择改区域、排列、分页或合法提炼；改写后重新检查 C03。 | 必须 |

## 原生元素与可选结构

Agent 可以自行决定元素数量、位置、尺寸和组合。Native 执行器提供参数化基本操作；这些操作是绘制能力，不是预制页面模板。

| 元素 | 使用规则 |
| --- | --- |
| 文字 | 直接生成可编辑文字框；可用字号、字重、色彩与间距组织，不需要背景卡片才能成组。 |
| 形状 | 容器、标记、分隔或有语义的节点按需使用。每种装饰应有明确分组、强调或识别作用，不用装饰填空白、刷密度。 |
| 线条与连接符 | 表达真实的分隔或连接；箭头必须说明方向含义，起止节点清楚，连接线不得穿过无关文字。 |
| 图片与截图 | 只用可访问的真实资源，记录来源、尺寸和说明；保留比例。没有主体元数据或明确裁切授权时完整呈现，不能声称已判断照片内容。 |
| 图表与表格 | 有数据才绘制，保留单位、标注、来源与比较口径。不能为了表达气氛编造数字。原生图表/表格支持尚待工具接入，未支持时如实说明。 |
| 既有结构 | 能帮助表达且尺寸合适时调用；不可伪装资产 ID、篡改资产真源或强行压缩。无匹配资产时可以用基本元素表达有来源依据的关系。 |

自组元素生成的是本次页面方案，不自动成为新核心资产。审美规则可统一这些元素的线宽、颜色、圆角与间距；无须为每一种组合提前入库。

## 留白、密度与无图片反馈

分开记录以下数据，不能只用一个“填满率”决定页面好坏：

- **区域分配**：哪些地方计划放内容；大容器不算实际内容。
- **实际可见内容**：文字行与字形占用估计、图片显示区域、数据图形和有语义的节点。文字估计不等于精确像素墨迹。
- **空白分布**：页边留白、组间通道、区域内空白、最大连续空区；区分有用途的留白与内容分配失衡。
- **局部负担**：各区域的字数、行数、最小字号、行宽、溢出和间距。全页平均正常不能掩盖一个过密的角落。

媒体面积与文字墨迹面积不能直接相加再套用同一文字阈值；图片页、章节页和常规内容页需要不同诊断。空容器、装饰底色和 Shell 不计正文内容密度。

遇到未通过的密度或空白检查，Agent 自行选择调整区域、重组内容、改变分页或其他合法表达，再重查。不能增添无关文字或图形来满足数值；不预定某一种修复顺序。

## 反馈和修订

每条反馈至少包含 `pageId / elementId 或 regionId / ruleId / severity / observed / expected`。附具体数值或内容片段；建议是局部操作，例如扩大区域、调整换行、移动元素、改为纵向排列。不要只给一个总分。

| 检查 | 责任与证据 |
| --- | --- |
| 越界、遮挡、文字溢出、最小字号、对齐与间距 | 程序检查实际输出对象；区分父子包含、装饰叠放和意外碰撞。 |
| 来源引用、素材存在、数字绑定 | 程序检查引用与数据；语义提炼仍由 Agent 核查，无法确定时保留原文或披露问题。 |
| 阅读顺序、主次与关系表达 | Agent 根据内容和对象结构判断；程序可检查声明顺序/连接是否一致，不能宣称证明叙事质量。 |
| 空白和密度 | 按本次声明的口径和限制检查；没有完整判定方法的部分标为未检查。违反已生效规则必须修改，不能用审美理由豁免。 |
| 原生可编辑交付 | 检查 PPTX 对象与导出结果，媒体可以是原始图片，但文字与图示不整体栅格化。 |

只修有问题的页面；修改内容或对象后使对应检查失效。程序排版或导出依赖失败时停止并报告基础设施问题，不让模型无休止改稿。修订次数与请求预算由 Harness 配置，通过当前版本检查即停止。

## 验收示例与下一步

这些是规则用例，不是提供给内容模型的逐页版式答案：

- 三步流程与贯穿规则：流程与规则分组，规则不冒充第四步；允许原生元素自组或调用现有流程结构。
- 两个方案且说明长短不同：保持相同论证层级，文字高度可不同，不缩小长的一栏；检查是否需要换成上下排列。
- 只有一段短说明：判断是需要强调的独立信息，还是应并入相关页；不能机械拉大空框或添加装饰补密度。
- 标题换两行：重测标题及正文起点，不因旧单行槽位直接失败，也不覆盖 Shell 保留区。
- 照片与说明：依据真实宽高安排，未知主体时不做无依据裁切；不使用文字墨迹阈值判照片页稀疏。

下一步只需提供通用文字/形状/线条/媒体对象、测量接口和局部修改入口，接入本规则与一个 Skin。继续用包含不同叙事关系的稿件自主编排，记录规则命中、未实现检查、局部修订、原生对象、请求与 token；不要求扩大资产库，也不预定页型配额。
