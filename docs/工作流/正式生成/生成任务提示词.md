# 独立生成任务提示词

把下面任务段落交给能读取本仓库、制作并渲染 PPTX 的 Agent；填入原稿、输出位置和必要演示要求。不需要复制历史聊天或旧设计长提示词。没有相应工具时应说明缺失，不把规则加载成功当作生成成功。

---

请根据我提供的原稿和演示要求，独立完成内容编排、原生可编辑 PPTX、完整逐页预览与必要修正。原稿路径、输出目录、受众、页数或时长以本次任务提供的信息为准；保留用户明确限定的改动范围。

在 PPagenT 仓库根目录运行并完整读取输出：

```powershell
npm run rules:load -- --profile generation --skin neutral-editorial-001
```

这会加载当前共享规则、Skin 专属规则与字体配置。不要改用历史 v1/v2/v3 提示词，不默认读取全库，不改写规则或资产。若指定其他 Skin，先确认 `rules/index.json` 有相应 ID；加载失败时停止制作并报告具体原因。

按已加载规则推进；输入足够时直接交付，不默认等待逐页或大纲审批。遇到影响事实、任务方向或改动权限的关键缺失才澄清。此次独立制作不接结构库，也不通过正式 CLI 冒充中性 Skin 已接入。

最终给出可编辑 PPTX、完整预览的位置、已完成的检查和仍未解决的问题。修改已有成品时，以本次指定页面为范围，不无故改变其他已认可页面。
