# 灰稿交接与成品

灰稿与页面表达是一体两面。灰稿由共同契约编译而来；成品继续读取同一契约，不从灰稿图片反推内容，也不另维护正文。

建设阶段可用模拟灰稿先建设 Skin、风格、布局、结构和程序。后段可以由 home 等建设角色推进，完成后以同一契约、输入和预览合并验证。建设时 Codex 可检查图片；产品运行不调用视觉模型。

前段改变页序、内容归属、关系或主次，必须写回共同契约。后段只在契约范围内选择能力和参数；发现表达需要改变语义时退回前段。交接至少保留契约版本、稳定 ID、来源、能力版本、PPTX、PNG 和审阅状态。

当前灰稿交接与受限成稿仍是局部实现。固定计划回放和人工美化不证明自动生产；缺口如实记录。
