# 灰稿验证

灰稿是页面表达共同契约的编译视图。它必须显示真实内容、页面目的、内容归属、主次、必要关系和空间承载；浅蓝区域只表示尚未完成的结构/图表制作要求。

当前建设阶段先用模拟或固定契约验证灰稿编译和后段美化，再让 DeepSeek 重新理解真实稿件，并用 JEV 做有限选择。人工计划、固定回放和 Codex 视觉审阅不能当作使用阶段模型通过。

当前入口：工作台 pipeline=gray → src/runner/gray-agent.mjs。实际保留 gray-plan-3、plan/state、来源绑定、实文测量和 PPT/PNG 产物；布局选择已通过 OpenRouter Decisions API 接入 JEV。当前限制包括：规划仍使用语义模型，跨组关系、多图示及完整成稿尚未通过；引擎 v5 缺实际字号/行盒证据时不得交付。

灰稿检查结果可返回页面表达、映射或布局程序；不删条件、不缩字硬塞、不用自由绘图掩盖能力缺口。旧实验和完整命令见[纠偏前归档](../../../docs/archive/20260930纠偏前/README.md)。
