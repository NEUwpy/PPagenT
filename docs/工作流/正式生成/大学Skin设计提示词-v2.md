# 东北大学 Skin：咨询式学术汇报设计提示词 v2

你负责把稿件编排为一套原生可编辑 PPTX。设计方向采用用户提供的麦肯锡风格参考，经大学场景适配，形成结论清楚、论证有序、视觉克制的咨询式学术汇报：学校身份稳定，正文让问题、依据、条件和判断容易阅读。正向指导提供设计方向与组织方法；边界约束防止内容和版面失真。根据内容作设计判断，不把每页填进同一种文字版式。

## 结论引领，依据展开

通读稿件，先明确受众要理解或决定什么。正文页标题用一句准确的判断、问题或行动建议交代本页要点，让读者只看标题也能把握论证走向；原稿只有假设时保留假设语气，不写成确定结论。为每页形成沟通任务、核心信息、支持内容、限定条件和阅读顺序；根据这些关系组织区域。文字页本身是一种完整表达，不是找不到结构图时的降级页面。

先组织整页的信息关系，再决定局部用文字、图表、真实媒体或结构 Skill。这里的“先”是决策顺序，不要求把版式冻结后硬塞组件。正文可以只有一个完整内容组，也可以有主次分区、对应比较、连续条目和附属解释。区域比例取决于内容角色与自然尺寸。需要结构时再检索真实契约，组件尺寸不合适时回调区域安排。

同层分组使用同一个分类维度，避免重复覆盖；论证需要的内容不得遗漏。互斥与完整性服务于问题界定，不强行把现实中交叉的关系伪装成互斥，也不为追求穷尽编造未知内容。稿件确有选择时，以相同维度呈现方案和取舍；不凭空增加第二方案。建议配合范围、责任和下一步，事实与建议用措辞区分。

## 大学 Skin 的视觉语言

- 保留现有东北大学 Shell 的校名、Logo、页眉、蓝色标题带、底部分隔线及主题。正文在 1280 × 720 画布的 x=55、y=166、宽=1170、高=492 区域内编排。封面与结尾沿用源模板的身份布局。
- 白色正文背景、蓝色强调与深灰文字形成学术汇报的清晰层次。蓝色用于导航、组标题或真正需要强调的信息；深灰承担连续阅读；浅蓝只承载有分组职责的局部区域。正文配色固定为蓝色主题、深灰正文、灰蓝辅助与白底；可使用既有浅蓝承载色。颜色是信息组织工具，不使用第二种强调色。
- 页眉和蓝色标题带已经建立页面身份与主题。把正文空间留给论证，不再在正文顶部重复一遍同义大标题。核心判断可以通过位置、字重、局部蓝色和周围留白建立重心。
- 用稳定的文字角色贯穿整套稿件。正文的识别秩序来自字重、大小、位置和间距的配合，不能仅靠给每组加边框来区分内容。
- 学术表达保留条件、反例与不确定性。结论与依据相邻，适用边界依附于它限制的判断；让读者知道什么是事实、什么是方案、什么尚待验证。

本版实验采用以下语义样式。数值均为项目设计单位；本项目画布以 96 dpi 映射到 PPT，设计字号 × 0.75 为文件 pt，不能混用单位。用角色函数统一配置，不使用 singleBody、dualBody 等旧版式槽位。

| 角色 | 字体 | 字号 / 字重 | 用途 |
| --- | --- | --- | --- |
| Shell 标题 | HYWenRunSongYun U | 保留模板 32 档 | 蓝色带中的本页主题 |
| 正文核心判断 | Microsoft YaHei | 28 / bold | 本页确有独立核心判断时使用，不要求每页出现 |
| 内容组标题 | Microsoft YaHei | 24 / bold | 内容组入口，可用 #2F5EA8 或 #404040 |
| 正文 | Microsoft YaHei | 22 / regular | 解释、依据、条件和主要条目，颜色 #404040 |
| 辅助说明 | Microsoft YaHei | 18 / regular | 不影响主要理解的补充，颜色 #6F7D91 |
| 来源注释 | Microsoft YaHei | 16 / regular | 来源或短注释，不能承载核心事实 |

同页同角色的字号和字重一致，整套角色定义一致。强调词可以加粗，不能为每个文本框创造近似字号。字体缺失须记录替代并重新测量。当前角色参数是本次实验配置，不代表已改造正式 Skin 契约。

## 让文字页有设计

**建立阅读入口。** 让最先需要理解的内容占据清楚的位置。其他内容通过接近、对齐、分隔与层级接续它。一个短判断配完整解释，与一串同等字号的句子，应产生不同的视觉组织。

**把内容组织成组。** 标题、正文和补充构成可整体移动的自然内容组。先沿从左到右、从上到下的阅读路径建立入口，再通过列与基线保持秩序；需要跳读时，用明确的分组标识说明关系。先根据实际换行求高度，再安排行距、组内间隔和组间通道。组内距离小于组间距离；独立段落组之间的净距至少为本页正文一个实际行高的 1.5 倍，标题和它的正文不属于两个独立段落组。让读者从空间关系看出归属。标题与第一段解释相邻，补充不漂在另一端。

**让自然高度决定摆放。** 全部主要内容在正文区域内作为完整构图安排；单一条目组或同级列表按自然高度整体定位，多区页面按信息重量互相平衡。留白形成阅读停顿、组间分隔和重心周围的空间，不把内容全贴顶后留下无解释的大空区，也不拉长空框伪造充实。

**用对齐建立秩序。** 每页选择一个正文对齐系统，允许 left 或 center，普通说明也服从该页选择；各栏可以有各自的对齐轴。列表编号、文字入口、说明起点形成稳定纵向轴；同级区域的入口对齐。正文不能左右居中混用。Shell 和独立编号标记按自己的职责检查；不能把普通句子伪装成标记来绕过规则。

**按关系分配空间。** 问题与解释形成主次，方案比较按共同维度对应，条件与动作靠近，短结论与长依据保留不同的自然高度。对应比较不要求把两个文本框做成同样高的空盒子。没有等级差异的项目保持等权，不为变化随意挑一项加深。

**让空白和细线承担组织。** 通过位置和距离形成第一层分组，细线帮助读者辨认边界。只有确实需要围合或强调的组才使用浅底或边框。不给每段文字套圆角卡片，不用阴影、渐变或无意义图标填空；既有 Shell 的渐变属于模板身份，不扩散到正文容器。

**让证据直接支持判断。** 数据图表与来源有实际输入才使用；突出本页判断所依赖的值或对应关系，保留单位、范围、时间和必要坐标。删除没有信息职责的图例、网格线和重复标签。文字也可以承担证据，不能为了看起来像咨询报告而造数据图、商业指标或装饰图标。

**维持可读的文字节奏。** 正文按完整意思换行，长段落可提炼成短判断与解释。固定角色字号后，以真实文本测量选择行距，整套同角色使用一致设置；行距允许 1.25–1.45 倍。标题不与下一行挤靠，末行与承载框保持真实净距。中文短词、数字与单位、否定与条件不被断行拆散；孤字和孤立标点须调整区域或语义断行。

**让整套页面随任务变化。** 同样的字体与颜色下，内容任务可以形成不同的区域比例、阅读方向、内容组数量和视觉重心。连续页面一起检查：如果不同任务全变成三列短句，回到内容关系重新组织。无需用页型配额制造变化，也无需给每页加一条底部总结。总结只在它推进论证时出现。

## 按需使用结构 Skill

本段在任务允许结构库时生效；文字基线任务不调用结构，也不另画复杂结构来替代调用。

当局部的顺序、因果、层级、比较等关系通过结构比普通文字更容易理解时，读取 `.codex/skills/ppagent-structure/SKILL.md`，按逻辑查询候选，选择后读取真实参数、容量、自然尺寸和内部排版。记录具体关系以及采用它的理由，不以调用次数或每页一图为目标。

结构是整页中的表达元素。它可以占一个区域，也可以在关系本身就是全页重点时占满正文区域。结构外的依据、适用条件、例外或判断按本 Skin 的文字规范编排。组件内部遵守真实契约，不能缩成不可读的装饰，也不能因资产存在而把并列条件画成步骤。没有合适结构时，保留原意直接排版。成功调用只证明执行完成，整页仍需检查。

## 内容与执行边界

- 原稿事实、数字、否定、前提、来源和不确定性保持准确。未验证方案不能写成已取得成效。不能为了对称、填空或套结构编造内容。
- 页标题、Logo、标题带及底部保留区不得被正文覆盖。独立文字不得相互遮挡，分隔线和连接线不能穿字。文本与所属背景的包含属于有意叠放，单独记录。
- 文字、图示、线条保持原生可编辑；不以整页图片替代。保留源模板主题文件，检查实际输出而非只检查输入参数。
- 不通过连续缩字解决容量问题。调整区域、分组、冗余表达或分页，保持必要信息；改后重测。
- 无图稿件不添加装饰照片。有真实媒体时保留比例与证据标注，不能为填满区域裁掉关键信息。

## 无图片编排与真实核查

本实验的执行模型不读取页面 PNG、截图、montage 或图片型工具输出；可以生成这些文件供父任务和用户查看。使用文本、布局 JSON、字体角色、实际文本行、对象框与线段信息自检。该限制覆盖生成与修订，不能以视觉技能默认流程为由开启图片输入。

导出后检查实际文字角色、换行、对象边界、标题完整性、最小字号、每页正文对齐，以及组内包含和相邻组净距。文字变长或区域变动后，相关旧检查失效。分开记录页面未越界与组内没有碰撞，不能把两者混同。源模板继承的特殊对象单列，不能因此放过新正文的问题。

为每页记录沟通任务、阅读顺序、各组的角色与实际范围、内容占用及空白用途。几何数值帮助判断组织是否合理，不能把“密度过线”当作审美合格。若检查没有实现，明确列出未检查项。自行修正有证据的问题并重新导出；完成后交付 PPTX、逐页 PNG 与布局数据、构建脚本和简洁报告，说明实际检查及限制。制作过程和自检术语不进入观众看到的正文。
