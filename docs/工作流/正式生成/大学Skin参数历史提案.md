# 大学 Skin 参数历史提案

以下是 v0.1 的设计起点，仅保留用于追溯。运行任务读取指定版本的大学 Skin 设计提示词，不同时加载旧候选值。

## 当前大学 Skin 的第一版参数

下表是当前东北大学 Skin 的实验起点，不代表所有大学 Skin。身份、字体与主题色取自现有 Skin；新的语义字号分组和间距为候选，尚未写入正式 Skin 契约。

坐标基于现有 1280×720 设计画布；字号沿用项目设计单位，不能当作 PPT 文件中的 pt 原样写入，转换由执行器统一处理。

| 项目 | 起点 | 状态 |
| --- | --- | --- |
| 正文区 | x=55，y=166，宽=1170，高=492 | 现有 Shell |
| 字体 | 标题 HYWenRunSongYun U；正文 Microsoft YaHei | 现有 Skin；缺字体须披露并重新测量 |
| 颜色 | 白底；强调 #2F5EA8；正文 #404040；辅助 #6F7D91；浅色 #DCE9FA | 现有主题；低对比辅助色不用于长正文 |
| 页标题 | 32，保留 Shell 规则 | 现有 Skin |
| 核心结论 | 默认 30，可选 27–32 | 候选角色 |
| 组标题 | 默认 24，可选 22–27 | 候选角色 |
| 正文 | 默认 20，可选 18–22 | 候选角色；同页同角色一致 |
| 辅助说明 | 默认 18，可选 16–18 | 候选角色 |
| 注释 | 默认 14，可选 14–16 | 候选角色；不得承载正文核心事实 |
| 行距 | 标题约 1.15；正文约 1.3 倍 | 候选；执行器按其行距语义转换并实测 |
| 间距尺度 | 8、12、16、24、32；组内优先 8–12，组间优先 24–32 | 候选；按可读性和空间调整 |
| 对齐 | 常规内容页默认左对齐；本次每页正文统一 left 或 center | 任务要求；不擅自改现有组件内部对齐 |
| 网格 | 沿用 24×12 描述区域；元素位置可以细化 | 现有区域网格，元素细化待实现 |

旧实验的文字稀疏 0.12、过密 0.65、最大空矩形 0.44 是特定文字占用算法下的试验值；本规则不将它们升级为跨页型、跨 Skin 通用阈值。新诊断需要保留旧计算口径用于对照，单独校准新规则。
