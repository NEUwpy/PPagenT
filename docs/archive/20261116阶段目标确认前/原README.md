# PPagenT

当前目标是将 Markdown 稿件制作成清楚、得体、稳定可靠的可编辑 PPTX，服务日常演示任务。

**当前阶段：盘点既有流程与资源，统一整体架构，讨论清楚方案和技术路线后才开始实现。** 以原有设计为底稿，优先利用既有代码与资产。

## 既有资源

`assets/` 保存结构图、主题等设计资产；`src/`、`rules/`、`schemas/`、`tests/` 保存既有实现与规则；`稿件/`、`experiments/`、`outputs/` 等保存输入和验证证据。`harness/` 是既有执行包及生成镜像，是否继续采用由本轮讨论决定。

其他技术说明用于核查已有资源，不增加新的路线或计划入口。重新讨论前的说明和替换记录见[归档](docs/archive/20261030重新讨论前/README.md)。
