# 新任务入口

先声明这是建设任务还是投入使用任务。

目标按 2026-10-29 [产品需求](../docs/产品需求.md)：基础输入为 Markdown 文字与图片；main 自动完成稿件到实文与蓝区灰稿，home 在同一契约中填入图形/图片并生成成品。中途无需人工接力，Word、PDF 及转换以后扩展。

建设任务记录：main 的稿件到灰稿，或 home 的模拟灰稿到成品；保留输入契约、规则/代码、PPT/PNG、日志、失败和审阅。Codex 可看图；模拟输入只证明后段。

投入使用按两段生成线自动执行：语义理解模型形成页面表达共同契约，JEV 从程序给出的合法版式/结构候选中选择，程序完成绑定、容量、测量和灰稿/成品编译。缺能力时如实记失败并返回责任点，不用视觉模型、自由坐标或高级模型兜底，也不请用户中途补做。

当前建设先追求单稿自动跑通；不同稿件均能正常转换的通用目标另验。失败须回建设修规则、资产或程序，自动重跑与回归到问题不再复现，不能只登记缺口就结束建设。任务范围、进度和下一交付从[项目台账](../../docs/方向讨论/页面编排能力计划.md)读取，不从历史实验或旧 Agent 状态推断。

当前实际入口、模型标识、契约/规则版本、能力版本和产物必须留档；目标说明不替代代码和 Schema。
