# 契约文档

本目录保存跨阶段仍需稳定遵守的工程边界，不放阶段计划、讨论记录或一次性实验结论。

产品输入与验收以 2026-10-29 [产品需求](../产品需求.md)为准；页面表达、蓝区和媒体交接目标见[共同契约](../架构/页面构成与布局规范.md)。目标要求不等于已有 Schema 字段，不能借更新说明扩大运行权限或能力。

- [Shell、Content Frame 与视觉能力契约](Shell与Logic契约.md)：页面几何、Structure Group、HTML 单源、文字容量与正式选择边界。
- [运行配置信息](运行配置信息.md)：Provider、本地密钥、环境变量和运行入口。

候选架构只有经过实现和验证后，才能从方向或架构决策文档进入这里。现有契约不为未实现方案提前增加兼容字段。
