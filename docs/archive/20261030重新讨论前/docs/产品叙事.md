# PPagenT 产品叙事

PPagenT 的目标是：用户给一篇稿件，系统全自动产出内容忠实、逻辑清楚、风格合适、原生可编辑的 PPT，中途不需要人分析、分页或补做。

2026-10-29 明确基础输入先支持 Markdown 文字与图片；Word、PDF 及格式转换以后扩展。

它不追求每次随机生成一个惊艳页面，而是把可复用的设计经验前置沉淀为规则、Skin、布局、结构和程序，让生产结果稳定跨过可用线。

生产只有两大阶段：

1. main：稿件到灰稿。自动理解和分页，形成页面表达（PE）共同契约；灰稿呈现真实文字，结构图、图表及图片以蓝区预留位置和面积，并保留内容与资源来源。
2. home：灰稿到成品。读取同一契约，有限选择已建设的能力，填入图形与图片，由程序生成最终 PPT。

建设阶段由用户与 Codex coworker 设计、实现和看图。Codex 的视觉能力只服务建设，不进入产品。投入使用阶段只调用语义理解模型和 JEV；模型选择受限，程序负责确定性计算和执行。

这条路线的价值不是固定模板，而是把固定要求资产化、可复用设计组件化、内容变化参数化、确定计算程序化，把临场生成转成理解、选择、填充和求解。

当前先追求一份真实稿件自动跑通。单稿成功不能称为通用通过；失败回建设修复、自动重跑和回归。建设审阅用于改进能力，不成为产品中途接力。完整口径见[产品需求](产品需求.md)，状态唯一见[项目进度](方向讨论/页面编排能力计划.md)。
