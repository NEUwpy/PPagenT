# 灰稿到成品：建设说明

本文只描述建设阶段的后段探索。Codex 可用模拟灰稿和视觉能力检查美化原则、结构资产、Skin、参数和成品预览；这不是产品运行时的视觉模型方案。

后段目标是：给定共同页面表达，选择已登记能力，使用合法参数和程序生成原生可编辑 PPT。不能临场自由绘制、改写事实或另建正文。需要改变关系、分页或主次时写回共同契约。

按 2026-10-29 口径，main 已规划的实文与蓝区是后段输入：结构图、图表和图片尚未制作或放入，home 按蓝区位置、面积、内容关系与媒体引用完成填充。图片引用与资源沿同一契约传递；产品中途不等待人工编排或批准。

home 可按同一契约制作模拟成品；必须标记输入来源、程序/规则版本、PPTX/PNG 和未解决问题。完成后阶段性合并，不能把一次模拟通过扩展为跨稿能力。

当前先追求单稿自动闭环，通用通过另验。失败回所属能力建设，修复后自动重跑与回归；人工修好某页只能记建设干预。输入与验收见[产品需求](../../archive/20261030重新讨论前/docs/产品需求.md)。
