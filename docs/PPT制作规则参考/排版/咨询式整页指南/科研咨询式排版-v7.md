# 科研／咨询式论证排版 v7

独立 LayoutGuide，与 Theme 组合。目标是用户参考中的专业报告页：短判断统领整页，主体证据让比较或关系一目了然，紧邻的解释指出意义与条件。读者第一眼看到问题的答案，第二眼看懂答案如何成立。学校主题改变视觉身份，页面组织由论证决定。

## 从判断组织整页

标题写有依据的具体判断，含明确对象；主体给出支持判断的证据；解释补充意义、条件或行动。同一句判断只承担一次职责。已经显示的数据不在旁边再逐项抄写，旁侧只放对读者决策有用的差值、原因或限制。

数据页围绕一个分析问题组织主图与辅助视图。相同对象共享顺序，相同指标共享尺度。把真正决定判断的门槛、差值、构成或转折呈现在图中，例如门槛线、两值间的差值标注、共享轴线；标签锚定实际位置。辅助视图回答主图无法回答的部分。按问题决定上下或左右并置，不默认把图画在左边、把所有话塞进右边。

关系页用连续方向、推进条件和归属形成紧凑骨架。职责和说明沿对应对象的列或行展开；条件直接位于它控制的边或阶段附近。必要节点可以有形状，普通解释保持开放文字。关系图与解释共同完成页面，不让一个满幅隐喻吞掉其他内容。

## 专业感来自可见的秩序

顶部短判断与一道细线建立入口。主体用稳定的外边线、共同起点和比较轴建立秩序。局部标题直接写指标、对象或发现，不增加“解读”“定量证据”“两项指标”等制作层标题。只设页面标题、局部标题、支持内容三个语义层；口径和来源作次要信息。

让图表或关系骨架占连续空间，解释按对应依据就近排布。普通文字组用“短小标题＋正常字重支持句”，组内紧凑、组间停顿，文字自然行宽优先于图形尺寸。不要用同一个长侧栏收纳所有剩余内容。若解释过密，调整整页区域、合并重复句或把关键条件直接落到图中。

分析页采用白底、近黑正文、主题重点和灰色背景证据。主题色只强调主角、关键连接或被选对象，次要对象用浅色或中性灰。浅色填充属于真实数据区域或有归属的图中对象；正文、建议、边界说明用无底无框文字。禁止用圆角卡片、带边框侧栏、徽章或标题胶囊包装普通解释。局部标题加粗，支持句正常字重，不把整块分析文字加粗。

留白位于页边、组间、视线转换处；信息多的区域获得更多空间。图表标签、图题和解释形成连续阅读，避免多层同义标题、大片底部闲置或窄栏碎行。页面上的每句话都服务于受众理解问题；制作思路、配色说明、布局说明和自检记录只写报告，不能上屏。

## 结构作为可调用参考

需要逻辑结构时通过 ppagent-structure 检索真实资产，读取语义、视觉意图和必要实现。提取门禁与阶段、比较轴与对应、中心与支撑等表达方法，再按本页空间重建。节点位置、方向、大小、图内外文字分工可变；minimumFrame 与旧字符容量只限制直接执行原组件。

重组必须保留稿件的先后、归属、极性、条件和证据边界。记录参考 ID、吸收的方法和改变之处，生成原生可编辑对象；未执行原组件就不报告 invokeStructure 成功。库是关系表达资源，不是逐页套用的整页模板。

## 配置与硬边界

- 1280×720；左右55，顶部36，主体下沿658，来源和页码672–696。标题实际下沿与主体至少相隔24。
- Theme 文件提供字体、唯一 primaryColor 及派生色阶；实现读取该文件，不能复制一套固定蓝色常量。更换主色应只需改主题入口。
- 字号为设计 px：页面标题32加粗，局部标题22加粗，正文与节点说明20正常，图表刻度/数据标签及简短口径16正常，来源/页码14正常。不另增18、28等字号，不用超大数字。图表可用数据标签强调主角，长句保持正常字重。
- 标题、正文与节点句子左对齐；图表数值按数据位置排，编号与符号可按语义居中。正文行高1.25；组内净距8，独立组24，主区域32。正文含关键适用条件，不能缩成页脚小字。
- 禁止渐变、阴影、3D和无信息装饰。不虚构事实或因果，不把计划写成成效。图表方向、单位、刻度与数值相符。

## 输出前的文本与几何检查

生成前给每个文本对象声明上述角色，生成后从实际导出对象逐一验证字号和字重；不以代码中的预期值代替结果。核对自然换行和文字框容量，检查文字框相交候选，逐项消除非意图重叠。框在页内不代表文字能放下。

逐条核对连接的实际起点、终点和箭头尖端；条件位于对应边界，文字和连接互不穿越。读一遍最终上屏文案，删除制作语言和重复判断。空间不足先重组区域或缩短重复措辞，不能缩小关键内容字号。输出可编辑 PPTX、最终渲染、对象布局与自检结果。生成模型只用文本和几何数据；父任务对最终渲染与用户参考进行视觉验收。

本版吸收 v6 换稿暴露的长侧栏、制作语言上屏、字号自行扩散与门槛未入图问题。验证状态见 university-skin-pilot 实验记录；指南版本本身不代表已通过。
