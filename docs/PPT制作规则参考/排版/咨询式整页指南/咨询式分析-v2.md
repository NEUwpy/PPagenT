# 咨询式分析 Skin · 编排提示词 v2

> 未完成验证的中止草稿。用户再次明确第四篇极简指南为主要风格来源后，已暂停相应任务；没有生成输出。当前输入改为[极简咨询 v1](极简咨询-v1.md)，不再采用全稿压入三页的任务。

你制作的是可供读者检查依据、比较方案和作出判断的咨询式分析页面。页面呈现为紧凑、平直、层次清晰的分析版面：上方简短判断，主体展示足够的材料，条件在相关位置交代。以下设计方向和边界一起执行。内容决定构图，固定样式保证整套秩序。

## 1. 先编辑信息，再决定分区

通读稿件，找出主要判断及其依据、条件、行动和责任。把共同回答一个问题的材料放在同一页，完整呈现这个问题的分析。页数未指定时，由这样的分析单位决定页数，不按原稿段落逐段拆页。

每页内部先写三项，不展示给听众：本页判断；支持判断的独有材料；材料之间必须显现的关系。标题表达判断，正文承担展开，不能在侧栏、副标题和页底反复换词复述。删去重复后没有内容的区域直接取消。

一页可以包含多个相互支持的内容组。组内保留必要的具体事实、解释和限制，不把完整论证压成一个标签加一句口号。正文不足以构成一页分析时，与相关内容合并；不能靠大字、空框或拉开条目间距填满画布。信息量大时，先梳理组内层次，再按不同问题分页。

## 2. 构图从实际关系开始

以完整的分析单位组合版面，不以“两个区、三个卡片”开始。用相邻、共享轴、上下归属、局部标注和共同范围直接表达关系。普通文字也能形成结构；调用结构库不是让关系可见的前提。

### A. 多个判断与各自依据，共同支持一个结论

主体是一组紧密的论证行。每行以简短判断作为窄入口，宽区展开理由、具体材料及局部条件；宽区内部可以有小标题和多条相互关联的说明。多行共享扫描轴，不要求高度一样。若还有一个不同于页标题的共同结果，用跨越这些行的细括线或共同说明标明归属。

```text
页判断

短判断甲  │  具体依据甲 + 对它的解释
          │  适用条件或必要补充
          │
短判断乙  │  具体依据乙 + 对它的解释       } 共同影响（确有独有信息时）
          │  适用条件或必要补充
```

窄入口只给标签实际需要的宽度，完整解释获得主体面积。不要把判断单独包装成占据半页的大色卡。上述竖线与括号说明对应和归属，不是每页必画的形状。

### B. 主体材料与独立的支撑材料

一个宽主区承载主要分析；窄侧区交代具体假设、限制、观察或行动含义。侧区必须提供主区没有的信息。只重复主区名称的“核心判断”“记录单元”不能成立为一个侧区。

主区可以内部分成两个可比对象或若干论证行，侧区可以包含另一种内容组织。各区共同服务一个页判断，不能把所有材料拉平成同样大小的卡片。区域边界通过组标题、短横线、列通道建立，主体信息直接排在白底上。

### C. 同一口径下的对象比较

对象为列，共同维度为行，维度名称只出现一次；对应项在同一位置相遇。列标题下使用细线建立比较轴。行内可以容纳完整解释，按实际最长内容决定该行高度，再给组间间距。用局部浅底或关键词强调真正的差异，不给每格都加底色和边框。

只有内容可比时才使用这种组织。方案取舍与正常步骤、背景事实与判断，不能为了套表格而强行变成同一层级。

### D. 时间、行动与判断条件

真实先后沿共同方向展开，执行人、动作和产出贴近。共同条件横跨其实际作用范围；局部例外依附对应动作。例外不加入正常连续编号。时间安排与通过/停止判据可以位于同页的不同区域，通过分组表达职责，而不是各自拆成信息稀薄的一页。

上述组织是关系方法，可以组合。先保证材料各有职责，再决定占几列、用哪些原生元素；没有版式配额，也不要求每页都有侧栏、底部结论或完整外框。

## 3. 标题紧凑，分析成为主体

页面上方仅保留页判断和必要的对象/时间口径。副标题只在提供独有口径时出现；标题已明确表达的信息不再解释一次。正文紧接标题区开始，不能再插入一层空泛大字。

页判断是一句可直接说出的短句，允许有意义的两行标题。标题、正文组入口、证据文字形成递减层次。大部分可见文字为正常字重；只有页判断、组入口和局部关键词加粗。整段结论全部加粗会抹平层级，须通过位置和归属表达重要性。

从缩略图看，最大的连贯形体应是分析材料的组织，而不是标题、口号或空色块。每块区域的面积由它独有的信息与分析任务决定；区域标题本身不能成为占据大面积的理由。

## 4. 平直的形状语言与有节奏的间距

直接在白底组织正文，用平直矩形、细线、标签条和局部浅底标明关系。矩形底色包围的是一组需要被一起理解的内容，大小紧贴内容自然范围。普通分析区不使用圆角卡片、阴影、渐变、透视和装饰图标。

深蓝实心只承载短而关键的标签或明确的共同结果；浅底标明局部范围；细线建立比较轴、组界和归属。同一个范围不叠加外框、逐行底色和多重分隔。不为几句文字建立一个空旷的大容器。

组标题紧贴所属正文；判断与其依据靠近；不同分析组之间留清楚的通道。表格行按文字自然高度排，不能均匀拉到整页高度。对齐轴穿过多个区域，使页面成为整体；各区可以不等宽、不等高。

留白位于页边、组间通道及必要的阅读停顿处。文字行被拉散、同一组内部出现大空洞时，收紧该组。收紧后页面内容显著不足时，回到内容组织合并相关分析，不造数据和装饰填空。对信息充分的稿件，保留事实和细节，用组内层次消化密度。

## 5. 本轮 Skin 的确定样式

以下是这套候选 Skin 的明确设计选择，不是沿用旧大学模板，也不是声称从参考精确量出的官方数值。

画布 1280×720；左右外边距各 48，上边距 32，下方页脚保护区 32。采用 12 列隐形网格、24 的列间通道，区域可跨列。正文上边界随实际标题自然高度确定；顶部身份与标题的总区域高度不得超过 128。页判断可两行，但不能靠缩字满足此边界。

全套 Microsoft YaHei，字号使用项目设计单位：页判断 30，组标题 22，正文及主要标签 20，注释和页脚 16。写入 PPT pt 为设计值 × 0.75；使用设计单位的 API 直接传原值。正文行距 1.25 倍；组标题与正文净距 8，组内独立段落净距 8，组间通道 24。内容容器内边距 12。字号与角色统一，不自动缩字，不设额外正文大字档。封面只在任务要求时制作，可以使用 40 档标题。

页判断深蓝 #163E6C 加粗；组入口使用同一深蓝；正文 #252B33 常规；辅助 #65707D；强调蓝 #3677BD；细线 #CDD5DE；浅底 #EEF3F8；白底。线宽 1 个设计单位。短标签可以深蓝底白字，只有需要明确识别的标签使用；正文不整段染蓝。

每页正文统一左对齐，数量列可右对齐，独立页码单列。页脚只放必要来源、身份和页码，不能成为重复的声明栏。虚构、预测等边界清楚交代，仍将局部影响结论的条件放在对应正文内。

## 6. 内容与执行底线

保留事实、条件、责任、否定和不确定性。启动、继续、停止条件，以及改变结果解释的处理要求，必须在页面可见。图表使用真实给定数据，没有数据就用材料本身分析；不编造图表和成效。必要的线、括合、箭头或表格属于正常关系表达，不为了减少图形而破坏逻辑。

导出后核对实际文字、行、字体、角色与对象范围。检查局部对象是否位于所属区域，实际排字是否超出框；不能只检查整页边界。修复遮挡、断词、孤立标点和自动缩小。内容覆盖要能定位实际页码与可见表达，不以备注引用整篇原稿代替检查。

设计自检另问三件事：去掉重复判断后是否还有空区域；每块面积是否承载独有信息；读者是否能沿相邻材料直接完成比较或追溯。若仍是大标题加几个分散短句，回到内容分组和构图重新组织。技术检查通过不能代替风格评审。

## 7. 使用边界

这是一份独立设计输入，不读取旧学校模板来恢复其标题带、书法字体或正文框。学校身份在此设计语言成立后以边缘标识接入。

任务允许调用结构库时，先形成整页关系，再查找局部需要的真实结构 Skill；资产契约不能替代整页设计。文字小样任务不调用结构库，仍可使用原生文字、矩形、线、括合和简单箭头表达关系。

执行模型不读取页面图片；可生成逐页预览供父任务查看，通过实际文本和布局数据自检。交付原生可编辑 PPTX、生成代码、逐页 PNG/布局 JSON 及真实检查记录。
