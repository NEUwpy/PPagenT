# 科研／咨询式论证排版 v6

独立 LayoutGuide，与 Theme 组合。目标是用户参考中的专业报告页：短判断统领整页，连续的证据区呈现差异，解释沿共同轴线回应证据；通过清楚的阅读顺序、比较关系和克制的强调体现逻辑。学校主题只改变视觉身份，不改变这种组织方法。

## 一页怎样成立

先写出本页有依据的短判断作为标题，随后选择最能支持它的证据表达。主体先让读者看见变化或关系，再用短解释给出意义、机制、条件或下一步。每个区域完成一种职责；同一个结论不在标题、图下、旁侧反复展示。图内直接数值已经可读时，解释要告诉读者它为什么重要。

数据页先确定比较问题，再组织视图。相同口径共享尺度与行位，单位与对象名称清楚；主视图显示关键差异，必要的辅助视图解释构成或范围，两者共同支持一个判断。只有标题需要的关键对象使用主题重点；其余证据保留为较低权重。同组总量和分量可以共存，但不把普通数字单独做成巨大结论卡。

关系页先明确连接的含义。流程用连续方向和推进条件形成一个紧凑骨架，职责与说明沿对应步骤排列；比较用共同维度与对照行，层级用真实归属。图形负责关系，文字负责具体信息，二者通过相同列、行或临近位置配合。少量必要节点形状可以承载图中对象；普通职责、解释和条件直接排文字，不把它们都包装为卡片。

## 整页视觉组织

顶部用完整判断建立入口，标题下用一道细线划定边界。主体从共同起点展开，局部标题用具体对象或发现命名，例如指标名、阶段名、真实结论；不把“解读”“差异落点”“主流程”“第2步规则”“定量证据”等制作标签增加为一层标题。

建立稳定的外边线、比较轴和文本列。主要依据占连续空间，解释紧邻对应依据；也可让一条紧凑关系骨架横跨上部，具体信息沿其对象展开。每一层的对齐关系都要帮助阅读。标题和局部标题加粗，支持句正常字重；主题色只突出值得关注的对象，常规正文用近黑，灰色用于次要口径和来源。

普通说明使用无底、无边框的文字组；按“短判断＋支持句”自然聚合。同层级共享字体角色，组内紧凑，组间有停顿。浅底只用于主图中的数据区域、确有归属的对象或一块独立重要边界；不得用一排圆角框组织普通段落。不同内容的面积按实际信息量分配，不为对称凑组，不把全部说明加粗。

留白保留在页边、组间和视线转换处。先为所有必要说明安排自然行宽，再确定图形尺寸。一个区域过密而相邻区域过空时，重新组织空间；不要把超量文字压到页脚，也不要把小段文字均匀拉散来填满。来源是追溯信息，关键条件属于正文。

## 参考结构与自主设计

通过 ppagent-structure 检索真实结构，读取参考的语义、视觉意图及必要实现。吸收关系的可见表达：门禁与阶段边界、比较轴与对应关系、中心与支撑等。按本页区域重建节点和连接，可以改变源几何、朝向、大小和图内外文字分工；源 minimumFrame 与字符容量只限制直接执行原组件。

参考重组必须在成品中保留稿件的先后、归属、极性和条件。不要因为库里有大隐喻就让它吞掉全页，也不要把流程改为没有方向的平级框。记录参考 ID、吸收的方法与变化，生成原生可编辑对象；未执行原组件，不报告 invokeStructure 成功。

## 本次配置与边界

- 1280×720；左右页边55，顶部36，主体下沿658；来源和页码672–696。实际标题高度决定主体起点，至少留24间隔。
- Theme 提供字体、单主色及派生色阶。标题32加粗，局部标题22加粗，正文/节点说明20正常，图表刻度/数据标签16，来源/页码14；单位为设计px，不增加中间字号或超大数字。
- 标题、正文与节点句子左对齐。图表数值按实际数据锚点排，比较维度共享基线；编号与符号可以按语义居中。正文行高1.25，组内净距8，独立组24，独立主区域32。
- 仅使用主题派生色与黑灰白；分析页禁止渐变、阴影、3D与无信息装饰。
- 不虚构事实或因果，不把计划写成成效，不删会改变理解的条件。数字与单位保持自然阅读，条末标签锚定实际条末，避免孤立数字和碎行。

## 完成前

先从实际上屏文案复核“判断—依据—含义”是否连贯，解释有没有新增信息，条件是否仍可见。再读实际导出的字体、文字行、内边距和边界；不以框在页内代替文本能放下。空间不足先调整区域、分组或短句，不连续缩字。

逐条核对连接：哪一个对象是起点，哪一个是终点，箭头尖端实际朝向哪里；条件与对应边界相邻，不画反向箭头也不靠编号掩盖它。生成者无图片输入，使用文本与几何反馈；父任务对最终 PPTX 渲染进行视觉验收。此文仍是待验证的可复用指南。
