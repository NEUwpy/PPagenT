# 中性编辑排版：无聊天上下文复现

日期：2026-09-05。目标：在新的 Codex 任务里，仅凭原稿与可复制设计提示词，生成接近用户认可稿件的视觉质量。

## 输入与隔离范围

- 可复制提示词：[v1](提示词-v1.md)、[v2](提示词-v2.md)、[v3](提示词-v3.md)。包含设计语言、编排判断、输出检查，不包含原成品逐页坐标或专稿代码。
- 内容：原始《为什么做 PPagenT》稿件，独立副本放在实验输入目录。
- 本轮固定 13 页（含封面、目录、收束），以便比较；具体分章、正文页编排由执行任务独立决定。
- 执行者使用新建 projectless 任务，不 fork 原聊天，不提供基线 PPTX、图片或生成代码。
- 执行者可以使用 Codex 自带工具、通用演示文稿技能与运行依赖。这是无本任务聊天上下文的验证，不是无系统提示词、无技能或无模型先验的实验。
- 评审者保留原成品作对照。执行者自检属于生成流程，评审者的后续反馈不计入首次独立生成。

## 验收标准

1. 全稿重要内容完整，概念与事实区分准确，关系图正确。
2. 纸感、宋黑搭配、砖红强调、编号、细线与符号语言与目标一致。
3. 页标题角色统一，正文清楚，无溢出、明显碰撞或非预期断行。
4. 主要内容自然编排，组内归属清楚，纵向重心合理。
5. 普通文字、对比和关系页适配内容，全稿不存在明显机械重复。
6. 交付原生可编辑 PPTX，并有全部页面渲染供核查。

先判断是否达到可交付与近似设计质量，不要求像素级复制。若有缺陷，将原因写成可泛化的提示词修订；更新版本后另开新任务复测，避免把同一会话逐页修图误记为冷启动成功。

## 怎样在新任务里使用

将所选版本的提示词全文作为任务说明，同时提供原始稿件、要求的总页数和输出位置。例如：

> 请根据随附稿件生成 13 页中文、原生可编辑 PPTX，使用下方中性编辑排版提示词。独立完成内容编排、生成、逐页渲染与修正，交付 PPTX 和完整预览。

随后粘贴提示词全文。不需要附带本聊天、旧成品或专稿脚本。通用 PPT 技能与工具是本次环境提供的执行基础；复制到其他工具环境时需要另外提供对应的生成与渲染能力。

当前建议复制 [v3 完整提示词](提示词-v3.md)。正式使用时页数由任务决定；13 页只是本次同稿对照条件。各版本的验证结果分别见复现记录，不能仅因版本号更高就视为已通过。
