# PPT 制作规则参考

本目录收集视频、文章和课程中可供 PPagenT 借鉴的 PPT 表达方法。这里记录的是外部观点与候选规则，不等同于已经进入正式生成线的项目规则。

现行生成规则唯一入口是 [rules/](../../rules/README.md)。参考资料只用于学习、判断适用条件和留来源；提炼后修改对应规则，不在笔记与提示词中继续维护另一份规范。

与 `docs/外部项目学习/` 的分工：

- `外部项目学习/` 研究其他软件、框架和生成系统。
- 本目录研究 PPT 的信息组织、阅读路径、视觉层级和表达方法。

## 状态说明

- `候选规则`：已从来源中提炼，但尚未通过 PPagenT 页面实验。
- `待验证`：已有明确实验方向，尚未得到用户确认。
- `已吸收`：经过实验和用户确认，已落实到提示词、契约、资产或程序门禁。
- `不采用`：经验证不适合 PPagenT 当前路线。

## 文件夹分类

- `内容提取/`：提炼原稿、组织分支与要点。
- `风格/`：视觉风格与参考样板。
- `排版/`：信息位置、阅读层级、对齐与留白。
- `制作验证/`：实际制作、复现与验证记录。
