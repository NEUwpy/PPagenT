# 方向校正：稿件驱动的页面编排

> 2026-09-05；当前分支目标，以[架构决策](工作流/正式生成/生成线架构决策.md)为准。

已有 Skin、核心结构库和 Native 编译继续复用。正式线仍以内容编译、预筛候选、视觉选择和渲染为主。实验已能增量写页并把 Text 与 Structure 同级选择，通用区域组合与无图片反馈闭环需逐项验证。

## 已确认方向

- 一个 PPT Agent，内容与视觉两个独立上下文，持久化 Deck Project；程序管理预算和反馈。
- 模型无图片输入，按网格、文字占用、对齐、间距和留白数据修正；人工仍可以看预览。
- PageBrief 保存语义；区域内 PageView 保存上屏内容及来源。内容不为固定结构槽位预先裁掉。
- Skin 提供身份、边界与排版规则；Agent 依内容直接组合原生文字、形状、线条和媒体，Structure 按需复用。固定版式和文字模板不是前置条件。网格解决空间，不替代结构语义。
- 正文统一一种对齐，保持合理间距与密度。规则需要实测与配置，不用单一数值保证美观。
- 本分支先以有限能力跑通稿件驱动闭环；另一台电脑的 main 丰富版式、结构与规则。

## 本轮验证

先写需要不同表达的稿件，交给内容阶段自主分页；视觉阶段自主编排，程序返回可定位的文字/几何反馈，局部修订后原生导出。不预写逐页答案，不用人工补丁伪装 Agent 成功。记录内容覆盖、排版问题、修订、调用、token 与耗时。

无图片区域闭环已有实验结果；下一步先按 [Agent 排版规则初稿](工作流/正式生成/Agent排版规则.md)接入语义字号角色、通用原生元素和测量驱动排放。暂不全面扩库、不增加自主 Agent 层级、不提前替换正式工作台。
