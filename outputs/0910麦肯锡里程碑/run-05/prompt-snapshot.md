# 内容与整页编排初模
用户要求先看页面初模时，使用下面任务，不执行后面的完整视觉美化流程。初模已经确定整页布局和媒介，尚未做品牌与审美润色；不是提炼文字的展示容器。

> 根据未经页面化的原稿，独立生成一个可编辑PPT前后对照：前部连续放置完整原文，后部为已填入真实内容的整页初模。内容提炼、媒介选择和整页布局共同完成：根据页面要说明的判断决定哪些内容重要、分别放在哪个区域、彼此怎样对应，再据此调整措辞、容量和分页；不要先定一份文字摘要再把它纵向堆进幻灯片。原文能清晰放一页时不人为拆页，初模页数由论证需要决定。

> 为每页选择适合本页关系的宏观骨架，例如同口径比较、主证据配解读、过程或条件分支、多个依据共同支持判断；这些是参考，不是必须凑齐的页型。确定标题、主表达、解释及约束各自的位置、面积和阅读顺序，使用真实内容填满该骨架。适合比较的数据可成为原生表格或简单图表，关系可用基本形状与连接表达；采用何种媒介由内容决定，不设图表配额。初模中的表、图、关系和文字必须已经可读、可编辑，不用“此处放图表”或空框代替，不添加方法论说明页代替实际稿件。

> 使用白底、黑灰文字和最少的功能性线条或形状，保证文字层级与必要净距。允许承载关系的分区、表格线、节点和连接；不加无语义装饰色条、品牌外壳或装饰图标。后续美化可改变视觉语言，不能等到美化阶段才决定这页哪个地方放什么。

自主多轮审查原稿与实际PPT。语义审查主动用原稿反证提炼后的标题，核对统计口径、判断范围、信息角色及条件逻辑；整页审查判断读者能否从空间布局看出主要信息、依据归属及关系，而不是只能逐段读完文字才理解。逐页查看实际渲染，发现问题后自己选择重组、换媒介、精简或调整容量，再渲染复核；不等待外部逐页修法。保留首版与自主修订、来源映射和简短审查证据，最终交付前后对照PPT和全页预览。无越界、文字覆盖完整或计划写有关系，都不能代替初模成立。

**基础硬门槛：禁止非预期重叠和遮挡。** 布局时为文字真实换行、表格行高、图表标签、节点和连接线留足空间。导出后逐页检查整页与组内：文字不能互盖，图表/形状不能侵入相邻内容区，边线/连线不能穿字，内容不能被裁切或挤出页面；有意的背景承载文字不属于错误。不能以容器不相交、代码坐标合法或自动检查无报错代替实际渲染核验。发现冲突必须调整组合、区域容量、连接路径或必要分页，不能靠压小到难读的字号隐藏；修订后重渲染全部受影响页。任何未解决遮挡都只能标为失败候选，不能作为通过版本。

图形也是论证：自审时把图表、连接、顺序和分区表达的含义还原成一句话，与原稿核对。坐标轴与表头须保留统计对象、时间窗口、单位和聚合层级；不能把汇总量当个体过程、把并列备选画成顺序、把未知关系画成因果。主标题也不能扩大证据范围。若一种骨架需要额外假设才能成立，换骨架，不用文末注释抵消主图造成的误读。
