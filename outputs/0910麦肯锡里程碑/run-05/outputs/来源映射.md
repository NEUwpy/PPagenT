# 原稿—初模来源映射

## 前部原稿

- 第 1 页：原稿标题，以及原稿第 1、2 段完整正文。
- 第 2 页：原稿第 3、4、5 段完整正文。

## 后部初模

| 初模页 | 对应原稿 | 页面命题与媒介 |
|---|---|---|
| 第 3 页｜整体信号 | 第 1、2 段 | 用两个可读指标块呈现 200→300 单、4→7 小时；右侧区分“现场需要立即干预”和“长期增员尚未证实”。 |
| 第 4 页｜分层证据 | 第 3 段 | 原生可编辑表格保留两类请求数量与分类中位数；占比条呈现复杂申请 20%→40%，右侧解释整体变化不能直接读成所有请求都变慢。标题保持为“结构变化、整体中位数仍需分解”，不把结构变化写成已证实因果。 |
| 第 5 页｜测量缺口 | 第 4、5 段 | 用三个并列的可能组成项表达队列、外部审批与值班处理，使用“＋”而非顺序箭头，避免把原稿未确认的时间顺序画成固定流程；同时把“补记”与“现有数据回答不了的问题”分区。 |
| 第 6 页｜决策边界 | 第 2、4、5 段 | 左侧放临时支持及其权限边界，右上放“主要等审批→改善审批协作”，右下放正式增员所需的联合证据，底部保留指标纪律。 |

所有数字、条件和限制均来自 `inputs/原稿.md`，未补造逐单分布、审批时长或处理饱和度等原稿未提供的事实。
