# 适配与多参考组合

先读 guide 的关系与视觉意图，再查看需要借鉴的造型源码或代表样例。目录摘要只用于检索，不等于已经理解设计。

把结构的表达特征与样例实现分开。例如折角便签的纸面、底影、独立卷页和通栏标题形成辨识度；不要只剩普通矩形卡片。原来的数量、蓝色主题和连续 TextRegion 属于样例实现，本次原生构建按内容重新决定。

提取对本页有用的方法：阶段门禁如何表示推进条件、对称对象如何围绕共享比较轴组织、折页如何形成纸面层次。可改变宽高、间距、朝向、节点位置及图内外文字分工；保持实际采用的识别特征、关系与条件可读。

多个参考各自贡献局部方法，不拼接互相矛盾的拓扑。不要求完整复制某个结构，也不设参考数量配额。参考不合适时说明原因，按技能选择顺序转用其他表达。

通过 invokeStructure 执行本次 build，记录 references 中的 assetId、preservedFeatures、changes，以及最终检查结果。执行成功与视觉通过分别记录；新表达不自动改写核心设计样例。

## 原生连接

当前 artifact-tool 的 slide.shapes.connect 使用 fromSide / toSide 选择连接点；已验证目标端箭头使用 tail: { type: 'triangle' }。导出后仍核对实际 fromElementId、toElementId、连接点和箭头端，避免线条穿过文字。

图内保留关系对象与必要条件，说明文字可在图旁按对应关系排放。每次最终修改后重新渲染实际 PPTX，对照特征与整页效果检查。
