# 比较结构

查询 `node .codex/skills/ppagent-structure/scripts/catalog.mjs list --logic comparison`；直接调用用 inspect，参考重组用 reference 选中的 ID。

先区分两个对象的对比、同一方案的收益风险权衡、同一对象的前后变化。不能因都叫比较就互换；尤其有正负极性的资产不能拿来放两个中性方案。

逐项对比需共享比较口径；天平倾向必须有稿件结论，不能自行推断。直接调用检查实际字段、数量和自然尺寸再绑定；参考重组可改变造型与空间，但须保留比较口径及极性。一般两段文字比较不强制使用结构图。
