# 比较结构

查询 `node .codex/skills/ppagent-structure/scripts/catalog.mjs list --logic comparison`，再 inspect 选中的 ID。

先区分两个对象的对比、同一方案的收益风险权衡、同一对象的前后变化。不能因都叫比较就互换；尤其有正负极性的资产不能拿来放两个中性方案。

逐项对比需共享比较口径；天平倾向必须有稿件结论，不能自行推断。查看实际字段、数量和自然尺寸，再绑定内容。一般两段文字比较不强制使用结构图。
