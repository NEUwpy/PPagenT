- 来源承担的角色：教学结构、字体层级、网格节奏、颜色克制、细线与留白。

## 从来源确认的视觉意图

1. **编辑式层级**：大标题承担视觉中心，正文退后；标题与正文通过字体类别、字重、字号和颜色共同分层。正文页标题使用 25 pt 语义档位，不得小于正文或依靠位置假装层级。
2. **严格网格**：页面依赖列、基线、编号和细分隔线形成秩序，不依赖投影卡片或装饰插画。
3. **纸感中性色**：暖灰背景、炭黑正文、中灰辅助信息；低饱和砖红只用于编号或极少量重点。
4. **呼吸感**：模块之间保留明显空白，信息密集但不拥挤；每一组内容拥有清晰边界与阅读入口。
5. **教学阅读路径**：先给结论，再给原则；用连续编号展开方法；通过正反对比降低理解成本；最后用一句话收束。
6. **克制组件**：圆形符号、细横线、细边框、小标签均只服务导航和分组；无厚重阴影、胶囊堆叠或高饱和渐变。
7. **符号索引**：`A / ≈ / ◐ / □ / T / ↔ / ●` 等单字符符号是模块分类、快速扫描与重复节奏的一部分，属于设计系统亮点；不得把它们与无意义英文句子混为一类删除。

- 展示字体：`Noto Serif SC`
- 正文字体：`Noto Sans SC`
- 网格：1280×720，左右边距 56，12 列；页面元素只使用左对齐、共享基线和细线分割。
- 标题系统：HTML 评审稿使用 58 / 25 / 21 / 17 / 15 五档字号令牌；展示标题为思源宋体 58 / 700，正文页标题为思源宋体 25 / 700，内容标题为思源宋体 21 / 600，正文为思源黑体 17 / 400，辅助说明为思源黑体 15。Native/PPT 的 pt 映射待用户确认 HTML 后再固化。
- 正文页标题：固定采用“低饱和两位编号＋25 档短标题＋向右延伸的细线”，例如 `01  核心美学原则`；不使用大号页标题占据正文空间。
- 英文边界：默认不显示英文眉题、英文页脚或重复性英文注释；单字符语义符号不受此限制。只有稿件本身包含必要英文术语时才作为真实内容呈现。
- 线条边界：只保留标题引导、列表分组和对比边界三类有明确结构作用的细线，不添加装饰线。
- 纵向编排：正文页在页标题与页脚之间建立统一内容带；目录、原则、步骤和对比模块保持各自自然高度，作为一个完整视觉组在内容带中垂直居中。不得通过拉长卡片或边框填满高度来伪造居中，也不允许全部贴顶后在页面下方留下无解释的大块空白。

## 页面族

1. `cover`：大标题、强调副标题、短说明与侧栏引语。
2. `agenda`：连续编号目录；无卡片，以横线和对齐轴组织。
3. `principles`：3 个同级原则，圆形符号＋标题＋短解释。
4. `method`：3–5 个连续步骤，左侧编号、中心符号、右侧标题与正文。
5. `comparison`：左右对比，同一内容展示不同组织方式。
6. `closing`：一句核心结论＋少量关键词，可兼任章节过渡页。

## 不变量、变量与边界

- 不变量：字体搭配、纸感背景、单一强调色、细线、编号系统、对齐网格、无阴影。
- 可变量：标题、正文、步骤数量、比较项、页码、强调色、页眉微型标签。
- 程序生成：连续编号、页码、分隔线位置。
- 不开放：Logo 占位、装饰性图片、多个品牌色、渐变卡片、圆角卡片堆叠。
- 内容过多时：先拆页或减少说明文字；正文最低 15 pt，不通过连续缩字硬塞。
