# 中性 Skin：来源与审批

状态以 [asset.json](asset.json) 为准：HTML 已获用户确认，Native/PPT 仍在审批，资产保持 candidate，尚未接入正式 renderer。

## 规则唯一入口

当前身份与颜色体系维护在 [中性 Skin 规则](../../../rules/skins/中性编辑排版.md)，字号与页面表达维护在其绑定的[杂志风排版体系](../../../rules/排版体系/杂志风.md)，通过根目录索引一起加载。字体名称只维护在本目录 `asset.json#fonts`。本文件不再复制设计数值或通用排版规则；历史资产 ID 和目录名保持不变。

独立制作使用根目录规则加载入口；资产规则可被独立任务使用，不改变其审批状态。现有 `review.html`、`generate.mjs` 与 `native-review/` 是候选实现和审批证据，规则改动不会自动重建这些产物。
