# 核心资产索引

`assets/` 只保存已经由用户确认、可以进入正式生成线的资产包。正式生成线直接扫描各资产目录的 `asset.json`，不维护第二份中央登记表。

当前保留：

- 东北大学主题：封面、目录、正文、尾页；
- 循环闭环：首个按新流程完成的 Logic，支持 3–6 步 State，并由同一 HTML 组件编译为原生可编辑 PPTX。

其他旧核心资产已作废并移除。新资产必须先进入 `备选资产/`，依次完成视觉意图、HTML 黄金状态、State 扩散、Slot Contract、Native 编译和用户确认，之后才能整体移入核心库。用户确认同时覆盖画面效果与看板自动读取出的字段、尺寸、字数／行数和必填媒体能力。
