# 核心资产索引

`assets/` 保存正式资产、待审批资产以及已退出正式调用的历史资产。每个资产目录中的 `asset.json` 是该资产状态和运行入口的唯一登记真源；正式生成线只发现满足审批、运行契约和可达性要求的 `core` 资产。

- 正式资产：39 个，其中东北大学封面、目录、正文、尾页 4 个，Structure Group 35 个；
- 待审批：31 个；

- 已撤回：7 个。

Structure Group 的正式 Logic 映射以 `catalog/logic-map.json` 为真源，当前 35 个正式结构资产全部已映射，覆盖 20 类 Logic 中的 18 类。逐项 ID 与空缺见[资产覆盖清单](../docs/工作流/资产积累与入库/资产覆盖清单.md)。

新资产直接写入 `assets/<分类>/<资产>/`，在同一目录内完成视觉意图、HTML 黄金状态、State 扩散、Slot Contract、Native 编译和两轮用户确认。最终统一通过 `npm run assets:intake:finalize -- --asset <assetId>` 检查并进入正式调用；不得只修改状态或 Logic 映射来绕过收尾检查。
