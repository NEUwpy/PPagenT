# 多集合共同交集｜视觉意图

## 逻辑骨架

- 2–5 个圆形场域表示同级集合；集合数量变化时，圆形围绕同一中心重新编排。
- 中心只表示“所有集合共同成立”的部分，不表示某个额外并列对象。
- 圆内只放集合名称；可选说明与分点放入外围灰色文字区，灰色区可以整体关闭。
- 3 集合状态沿用参考页的上下关系：顶部集合嵌入一整块横贯画面的灰色上框，灰色从上方和左右包裹顶部半圆；下方两个集合分别对应上提、加厚的左／右说明区。上框中的左右文字区域不连续，因此仍分别声明 TextRegion。
- 若需要分别解释任意两个集合之间的交集，应换用更完整的集合关系结构。

## 审美语言

- 主参考第 125 页提供“多个集合围绕共同核心”的逻辑骨架，以及深蓝、亮蓝、白色核心形成的主次关系。
- 辅助参考第 61 页提供圆形体量差、同色系层次和稳定中轴；舍弃其数据看板、箭头与图表。
- 2–5 项均保持中心稳定、圆形等权、左右视觉重量平衡；数量变化通过重新排布解决，不拉伸圆形。
- 外围灰色文字区沿用循环闭环的设计语言：主图保持纯净，支持信息退居第二层。
- 灰色承载面与所有集合圆之间统一保留随形白边；任何 State 都不得为形成包裹感而跳过这条轮廓语言。

## 变量与边界

- 可变：2–5 个集合、集合名称、各集合的可选说明／分点、共同部分文字、灰色说明区开关。
- 每个灰色连续文字承载面只有一个 TextRegion，其内部排版由文字排版系统选择。
- 固定：所有集合等权、共同核心、中心阅读顺序和圆形视觉语言。
- 不支持六个及以上集合、完全包含、普通并列以及需要逐一解释两两交集的内容。
