# 目标策略举措任务级联：视觉意图

- 来源：【蓝色版】150页逻辑框架汇报PPT模板.pptx 第 79 页；仅吸收结构表达和视觉节奏，不复制来源 Shell。
- 覆盖增量：现有层级结构最多承担三层树或单概念层级，缺少从战略目标一直拆解到执行任务的四级级联。
- 语义职责：一个总目标逐级分解为策略、举措和具体任务，层级越低越接近执行。
- 审美原则：四级内容沿统一中轴逐层展宽，形成连续的级联带；每一级的文字嵌入带内留白，不再表现为独立表格行。
- 响应范围：固定四级：目标 → 2–4 策略 → 3–5 举措 → 4–6 任务。
- 失败边界：只有两三层、分支需要汇合、同一任务归属多个举措或关系是时间过程。
