# 行星环：视觉意图

- 覆盖增量：外圈为 0 时表达“核心—直接能力”的单圈辐射；存在外圈时表达“核心—直接能力—共同结果”的两级生态。外圈结果由能力组合共同形成，不声明某一结果专属于某一能力。
- 结构语法：整个关系是一套共享透视的行星系统。中心是唯一核心；3–4 个直接能力落在近轨，4–8 个共同结果落在远轨。节点、轨道和前后关系由同一投影函数计算，不允许每个节点各自倾斜。
- 深度表达：轨道后半段较浅且虚化，前半段较实；节点随同一深度参数做轻微尺度变化和遮挡排序。球体只用同色阶圆、轻微偏移底盘与克制高光构成，不使用厚重投影或材质效果。
- 文字承载：核心和近轨能力使用球内短标题；远轨成果使用球外短标题，避免为了塞字放大外围球体。文字保持正立，不跟随透视旋转。
- 审美原则：低饱和蓝色阶、简单圆与椭圆、重复阵列和统一数学关系形成构成主义秩序；透视只服务于空间层级，不追求拟真。
- 响应范围：1 个核心、3–5 个直接能力、0 或 3–8 个共同结果；外圈为 0 时不绘制空轨道和外圈图例，数量变化时仍共享同一中心和投影。
- 失败边界：外圈结果必须明确归属于某一个能力，或内外两层没有语义差异时换用其他组。
