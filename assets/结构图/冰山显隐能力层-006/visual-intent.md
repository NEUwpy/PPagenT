# 冰山显隐能力层：视觉意图

- 来源：【蓝色版】150页逻辑框架汇报PPT模板.pptx 第 109 页；仅吸收结构表达和视觉节奏，不复制来源 Shell。
- 覆盖增量：现有分层资产按技术层、业务域或包裹关系组织，缺少“表面结果由多层隐性能力支撑”的显隐深度表达。
- 语义职责：少量可见成果位于表层，其下存在更深、更基础且通常不可见的能力或条件层。
- 视觉语言：用一个可辨识但不写实的冰山剪影承载关系；冰山由少量 SVG 多边形切面拼合，形成生成式几何艺术感。禁止把若干梯形卡片简单堆叠成“冰山”。
- 配色约束：沿用项目的低饱和蓝色体系，只使用相同或相近色相的明度阶梯；以留白、细水线和轻阴影建立层次，不引入高饱和撞色或多色装饰。
- 版式气质：简约、克制、几何完整。水上成果贴近冰山顶部，水下支撑文字落在连续冰体切面中；不使用卡片墙、徽章或复杂插画。
- 响应范围：1–5 个水上结果、2–5 个水下支撑层；水上成果数变化时，冰山峰脊数量、肩部宽度和文字安全区同步重算，不在固定山形上硬塞文字。
- 失败边界：所有层都同等可见、需要表达相邻接口、只是普通上下堆叠或不存在显隐含义。
