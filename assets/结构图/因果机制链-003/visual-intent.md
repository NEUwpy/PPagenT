# 因果机制链：视觉意图

- 覆盖增量：鱼骨负责并列归因，本组负责解释一个条件怎样经过若干可说明的中介机制，最终导致一个结果；中间只是一串事件时改用顺序流程。
- 主要来源：逻辑框架模板第 123 页。吸收一条连续上升的主路径、节点嵌入同一传导带以及末端明确收束；舍弃原页的大段说明卡和业务装饰。
- 辅助来源：同模板第 145 页只用于核对阶段与说明同步对齐；审美身份以第 123 页为主，不平均混合两页。
- 阅读路径：箭带近端隐式起势 → 2–4 个中介机制 → 箭头收束。所有节点必须落在同一条连续因果脊线上，不能退化为若干互不相干的卡片加箭头。
- 视觉骨架：页面保持正视，箭带自身沿约 52° 的斜向纵深轴从左下近景直行到右上远景。近端横截面宽、远端横截面窄，两条长边持续收束；近端截面与箭身—箭头的远端折线保持水平且相互平行，远端折线同时作为箭头共边。整条主路径没有折点，也不是沿画面中心展开的跑道。机制节点以底部椭圆作为箭带接触锚点：先连接梯形近端与远端横截面的中点形成透视中轴，再让每个椭圆中心落在该轴上；直立圆盘与椭圆共享同一竖直中心线，圆盘中心按自身直径向上抬升。圆盘、图标安全区与椭圆托底按锚点所在截面的局部带宽由近到远显著收缩。
- 体量与层级：宽箭带是最大连续色块，并以左下宽、右上窄的透视收缩建立纵深；浅蓝近端向深蓝远端过渡，箭头进一步加深。圆盘节点次之，说明块再次之；节点使用统一的缓和投影强度，让远端圆盘仍可辨认，节点间距和圆盘缩放必须共享同一有效透视比，不能分别手调。圆盘通过白色主体、蓝色环线和浅蓝椭圆托底形成来源页的轻空间感。避免厚阴影和普通卡片阵列。
- 内容绑定：近端不显示独立起点卡，由箭带起势表达输入；每个机制的图标与标题进入圆盘，说明进入与来源页一致的中性灰框。所有机制灰框同宽同高、使用较小正文和左侧深色短线，并以固定横向步距和“框高＋固定间隙”计算纵向步距，组成整齐且留白明确的阶梯；连接线从灰框右缘水平引出，再沿同一斜向方向族精确落到圆周。右下不设置独立结果文字或附加标线，终点由箭头本身表达。
- 数量扩散：机制节点数量变化时，以等距世界坐标生成节点，再用一维射影函数投到箭带中轴；有效透视比由近远横截面的宽度比经过统一缓和得到，并同时驱动画面间距和圆盘尺寸，使二者都向远端连续递减但不过度收缩。随后统一计算椭圆锚点、圆盘抬升量和图标安全区。机制灰框尺寸保持不变，各数量状态只调整整组起点；纵向步距恒等于框高加 6px 间隙，横向步距保持不变。
- 失败边界：缺少可解释中介、只有相关性、原因彼此并列或需要反馈回路时不得使用。
