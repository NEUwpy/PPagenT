# 情景假设扇面：视觉意图

- 来源：06-【柏林蓝】定制级学术型灵感手册-宽屏.pptx 第 121 页；只吸收结构表达，不复制来源 Shell。
- 覆盖增量：补齐决策树依赖是/否判断、路径组依赖路线选择，而不能表达围绕同一不确定假设并列展开多种未来情景的缺口。
- 语义职责：在同一关键假设下并列推演多个可能情景，每个情景包含触发条件与预期结果。
- 审美原则：共同假设通过由深到浅的扇形路径自然展开，路径角度与间距构成主要视觉美感，情景卡保持轻量。
- 响应范围：1 个共同假设 → 3–5 个情景，每个含触发与结果。
- 失败边界：分支由明确决策问题驱动、情景之间有顺序或需要计算概率树。
