# 单链反馈控制环：视觉意图

- 归属 Logic：循环与闭环。
- 覆盖增量：补齐“主流程总体向前推进，但结果会返回某个上游节点进行校准”的表达需求。它不是所有阶段首尾相接的圆环，也不是两个主体之间反复往返。
- 逻辑语法：上方为 3–6 个有序前向阶段；末端通过下方反馈通道回到上游控制点。反馈区只承载校准原则或返回信息，不再复制一遍全部阶段。
- 阅读路径：从左到右读取主链，随后沿末端向下、向左的反馈路径回到指定上游节点，再进入下一轮。
- 视觉语言：柔和蓝灰主链、白色呼吸边、克制的虚线反馈轨道和同色系编号节点；几何对称、留白充分，不使用高饱和撞色或卡片拼盘。
- 响应范围：3–6 个前向阶段；阶段位置和文字区域按数量重新求解。反馈目标默认返回首个阶段，可由运行参数指定为更靠后的上游节点。
- 固定部分：前向主链、末端回流、方向箭头、反馈校准区。
- 可变部分：阶段数量、阶段标题与说明、反馈标题与说明、反馈返回目标。
- 失败边界：所有阶段本身构成完整圆环、两个主体等权往返、存在内外双速循环、每轮都显著抬升成熟度，或内容没有任何反馈返回时不使用。
