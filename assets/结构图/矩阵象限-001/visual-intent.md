# 二维定位象限 · 视觉意图

## 要表达的逻辑

这组不是“四块并列卡片”，而是两个独立判断维度交叉形成的四个象限。对象必须能沿横轴与纵轴同时被判断，并唯一落入一个象限；象限名称进一步把位置转成分类、优先级或行动建议。

## 参考组怎样参与

- 主参考 `logic150-p152` 提供真实横纵轴、对象气泡和象限定位的基本语法。
- `yearendblue-p118` 提供轴端含义和四个象限行动命名的清晰度。
- `yearendblue-p119` 提供对象作为可落点气泡的表达，避免把矩阵退化为四组卡片。
- `logic150-p130` 只用于核对维度、阶段判断和对象信息之间的层级，不采用其密集表格外观。

## 视觉原则

- 横纵轴必须成为画面主骨架，交点、方向和两端标签都清晰可见。
- 坐标轴只覆盖主要定位区域，不延伸到画布边缘；左右、上下端点以交点为中心对称收短。
- 四个象限只用很轻的底色区分，不做四张厚重卡片。
- 对象使用半透明气泡；气泡大小只服务排版，不表达未提供的第三维数据。
- 左侧气泡组向纵轴内收，右侧气泡组以纵轴为镜像向内收；先保证组中心对齐，再做大小差、轻微重叠和纵向错落。
- 左侧上下定义区参考主参考页的窄色块语法，可按页面需要关闭；两块色条分别与对应的上下象限等高，只放定义标题和一个渐隐图标，不承载长正文。
- 四个象限外围各保留一个与来源页对应的说明区：标题与简述在上、虚线分隔、两项关键指标在下；说明区保持平面排版，不做成厚重卡片。
- 气泡内部只保留一层对象文字，不再叠放“标题 + 小标签”。
- 重点象限通过场域底色、边线和标题共同增强，不能只改某一个气泡颜色。
- 整体沿用当前结构资产的浅蓝灰、细线、轻阴影和充足留白。

## State 扩散

- 固定四象限，不制造三象限或五象限 State。
- 四个象限分别独立支持 1–3 个对象；任一象限数量变化时只重算该象限的气泡落点与大小，不要求其他象限数量相同，也不保留空占位。
- 重点象限可在左上、右上或关闭；重点只表达本页明确给出的行动偏好。

## 边界

- 若内容只有四类并列主题、没有两个判断维度，应使用并列或中心辐射。
- 若对象需要精确连续坐标、第三维数值或统计关系，应改用数据图表，不用本 Structure Group 伪造精度。
- 若对象可能同时属于多个象限，应改用包含、交集或网络关系。
