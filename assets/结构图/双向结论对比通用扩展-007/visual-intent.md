# 二对象概括对比：视觉意图

- 语义职责：承载两个对象各自一段概括说明，强调“二者不同”，但不预设正负、推荐方向或共同对比维度。
- 存在必要性：现有“双向结论对比”要求正负语义和 3–5 组对应要点；“双列维度对照表”要求共享维度。本组覆盖两者都无法承载的低密度二对象概括对比。
- 逻辑骨架：两个等宽文字区域位于同一个对照平台内，由中央关系节点明确分隔和关联；观众先识别两侧对象，再读取各自概括。
- 视觉语言：只保留共同平台、左右色阶、中央分隔和关系节点；使用比例、留白、对齐与克制蓝灰建立秩序，不增加没有表达职责的编号、折面、短线或装饰节点。
- 文字区域：左右各一个连续 TextRegion，内部允许仅标题、仅正文或标题加正文；文字组合由排版库决定，不为三种内容形式分别建立 Structure State。
- 固定边界：对象数固定为 2；需要逐项比较、明确优劣、前后变化或 3 项以上对象时改用其他 Structure Group。
