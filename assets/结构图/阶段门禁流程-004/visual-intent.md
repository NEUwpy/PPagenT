# 阶段门禁流程：视觉意图

- 来源：【蓝色版】150页逻辑框架汇报PPT模板.pptx 第 127 页。来源页提供连续推进和阶段层次的启发；门禁语义与河道式表达来自本项目的覆盖缺口，不机械复刻来源表格。
- 逻辑表达：流程是一条由近及远、逐渐收窄并最终形成箭头的蜿蜒河道；相邻阶段边界上设置横跨河道的抽象门闸，表示只有满足检查或决策条件才能继续向前。
- 共同几何：河道中心线、宽度变化、阶段分段、箭头和门闸都由同一条曲线及其局部法线求解。门闸随纵深缩放并始终横跨当前河宽，不能与流程各自模拟方向或透视。
- 设计语言：低饱和蓝灰色阶、白色分段留缝、俯视抽象闸板与轻量条件标牌；用曲线、收窄、横跨和穿越形成关系，不堆叠卡片，不用艳色节点。
- 文字区域：阶段文字位于对应河道分段内；门禁条件位于门闸附近并由细线关联。每个区域仍是连续 TextRegion，由文字排版库选择标题、正文或分点的合法排法。
- 响应范围：3–5 个阶段；门禁数固定为阶段数减一。数量变化时按同一曲线重新切分阶段、重算门闸位置和文字区域。
- 覆盖增量：补齐普通顺序流程不能表达“阶段必须通过验收或决策门槛才能继续”的缺口。
- 失败边界：只是连续动作、没有门槛，或时间日期才是核心信息。
