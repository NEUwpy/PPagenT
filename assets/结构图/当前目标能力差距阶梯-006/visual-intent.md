# 当前目标能力差距阶梯：视觉意图

> 已并入“成熟度能力阶梯”的差距开关。本目录只保留历史候选证据，不再进入审批或正式调用。

- 来源：【蓝色版】150页逻辑框架汇报PPT模板.pptx 第 109 页；仅吸收结构表达和视觉节奏，不复制来源 Shell。
- 覆盖增量：成熟度阶梯只展示全部等级，现状目标差距桥又不表达等级；当前缺少在同一能力阶梯上标出当前位置、目标位置和跨级差距。
- 语义职责：对象处于一个明确成熟度等级，并需要跨越若干等级到达目标状态。
- 响应范围：4–6 个能力等级，并明确当前与目标位置。
- 失败边界：没有统一等级定义、只是连续趋势、当前与目标不在同一能力轴或需要两条并行轨道。
