# 放入稿件说明

`稿件/` 是 PPagenT 项目内统一的原始稿件目录，与 `PPT源/` 的原始 PPT 来源目录相互独立。

使用规则：

- 新稿件统一放在 `稿件/<文件名>`，正式运行和文档示例不再引用 `workbench/manuscripts/`。
- 当前正式入口优先支持 UTF-8 Markdown（`.md`）。稿件保留原始叙事和事实，不预先手工拆成逐页 JSON。
- `稿件/` 只保存输入原文；`DeckPlan`、`PageContent`、导演输出、渲染证据和 PPTX 继续进入指定的运行目录或实验目录。
- 文件名建议使用稳定的主题名和版本号，例如 `主题-v1.md`；修改原稿后递增版本，便于回放和比较。
- `workbench/manuscripts/` 中的旧文件暂时保留为历史回放快照，不再作为新任务的规范入口。

DeepSeek 正式入口示例：

```powershell
npm run agent:run:deepseek -- --input "稿件/为什么做PPagenT-v1.md" --output "outputs/为什么做PPagenT.pptx" --run-dir "workbench/runs/为什么做PPagenT"
```
