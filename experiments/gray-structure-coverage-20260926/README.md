“大／中／小”是后续套用结构的参考；灰稿制作说明的文字占地不必等于最终图形占地。最终应根据认可的内容与局部空间调整。灰区呈现实文，浅蓝区显示四项制作说明，不绘制内部图形节点；正文 22px、分区标题 26px、主题 28px。
