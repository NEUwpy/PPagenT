# P3 内容分组说明

本实验只读取 `experiments/visual-balance-cold-run/manuscript.md` 的 P3 完整稿件，覆盖“页面判断”、三条证据、综合判断以及“证据边界与验证办法”。页面判断单独保存在 `topic.sourceText`，不计入 `groups`。

分组先把三条证据各拆成“事实”和紧随其后的“解读/限制”，保留原稿中的统计事实、行动含义与不可推出的结论。随后单独保留综合判断、证据边界、验证办法和条件行动，形成“事实 → 解读/限制 → 综合判断 → 边界 → 验证 → 条件行动”的可查逻辑链。

每个 `sourceText` 都是稿件中的完整连续原文，按句拆分时没有改写或遗漏。`relations` 只表达原稿已有的支持、限定、校准、验证和触发关系；本阶段不选择结构库、不写 PPT，也不设计坐标。
