# PPagenT Layout Routing

Skin is supplied by the task and defines identity and Content Frame. Layout decides page type, regions, rhythm, and whitespace inside that frame. Do not treat a Structure Group as the whole page by default.

For each page, first decide whether the information is text-led, media-led, topology-led, or a small composition of these. Load a concrete capability only after the page purpose and region are known. Keep the page brief as the content source; reference it by stable IDs rather than duplicating prose.
