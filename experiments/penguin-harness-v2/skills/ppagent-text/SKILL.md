# PPagenT Text

Use this capability for ordinary pages and for regions accompanying a structure or image. Preserve source wording and hierarchy. Shorten repetition before reducing type. Choose a declared layout whose capacity fits the actual text; if it does not fit, request a content split or switch composition rather than hiding overflow.
