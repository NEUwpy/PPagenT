# 结构大中小适配检查

本检查复用看板和正式调用共用的 `preserved-design` 入口，对核心结构逐个生成 `large`、`medium`、`small`。中版目标约半页，小版目标约三分之一页；检查包含实际浏览器文字度量、允许字号档位、结构边界和预览接口。

- `check.mjs --golden`：东北大学 Skin 下的默认完整样例。
- `dashboard-check.mjs`：从 PPA 看板 API 逐个请求 35 个核心结构的小版预览。
- `dashboard-report.json`：最近一次看板入口检查，35 个结构均返回 200，均使用小版入口和实际测量布局。
- `golden-report.json`：默认 Skin 的结构检查记录；少数内容密度超过小区域的样例保留为失败，作为调用时的容量边界，不通过压缩字体或裁剪掩盖。

该检查证明结构入口和候选预览可用，不替代整页 PPT 的人工视觉验收。
