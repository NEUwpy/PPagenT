# 数据集试用讨论记录

这是模拟讨论。项目组准备将一批研究数据提供给六名合作研究者试用，并希望之后能公开下载。有同事说内部质检已经通过，所以可以直接把六人试用链接改成公开链接。

目前五个数据来源中四个已有书面授权，剩余一个只得到口头同意。书面授权覆盖指定合作研究，不包含公开再分发。内部质检检查了字段缺失和格式，没有复核组合字段是否可能识别个人。数据已删除姓名，但精确日期、地点和少见诊断的组合仍需检查。

合作方要求下周开始复现分析。拟议做法是先使用书面授权覆盖的四个来源，完成去标识风险复核后，向六名指定研究者提供受控访问；口头同意的来源暂不纳入。试用时保留访问记录，由版本负责人接收错误报告，发现授权争议或识别风险时撤回相关版本。

版本负责人已经指定，但撤回流程还没演练，公开再分发授权也没有补齐。公开发布需要另行确认授权覆盖公开用途、去标识风险可接受、版本反馈与撤回流程可运行。六人试用的访问控制不能作为公开发布后的风险控制证明。

团队希望试用阶段收集可复现性、字段错误和文档理解问题。试用反馈好不代表公开权限齐全；若任一公开发布条件不满足，继续受控试用或暂停相关数据，不开放公开下载。来源授权有争议时应暂停相关来源的使用，不能仅删除争议记录后继续分发。
