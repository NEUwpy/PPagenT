# 档案平台采购讨论

以下均为模拟报价和需求。团队有300名使用者，拟选择下一年度的档案管理平台。供应商A报价每年12万元，迁移一次性收费8万元；B每年18万元，迁移一次性收费2万元。两家报价均覆盖同样的300名使用者，均不含本团队整理历史档案的人力。有人因A年费较低而建议立即签三年。

最晚六周后需要完成首批上线，延期会影响归档交接。A估计迁移需要八周，可完整批量导出文件，但审计日志目前只能人工逐次下载；B估计四周，可批量导出文件与审计日志。迁移工期均为供应商估计，还没有实际样本迁移。合同能否约定分批上线尚未确认。

管理要求是归档记录和审计日志都必须可批量导出，不接受只有界面可查询。报价均未承诺数据退出时的协助费用，也没有约定导出耗时。已有一批20份脱敏档案可用于验证，包括附件、版本记录和不同权限设置。

如果只看第一年，费用要同时算迁移和年费；看三年时则按报价不涨价、迁移只付一次计算，不做折现，也不能算入未知的人力与退出成本。业务负责人愿意用这20份档案先验证权限、版本及两类导出，之后再谈签约。若B验证失败而A也不能满足导出与上线要求，应保留现平台过渡，而不是强行从两家中选一家。
