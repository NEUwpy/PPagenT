- 边界检查：slides_test.py 输出“Test passed. No overflow detected.”
- 自定义布局检查：4 个最终 layout JSON 中 slide-scope 对象越界 0；排除模板章节号与章节名这一组有意相邻对象后，自建文本对象两两相交 0。

工具失败与自主重试记录

首次运行 build.mjs 在模板成功导入后失败：artifact-tool 报 `TypeError: t.split is not a function`。定位为少数 addText 调用漏传对象名，导致数字被写入文本 setter；已保留该失败事实，补齐对象名后重试成功。随后发现实际 PNG 中中位时间标签在窄框换行、原因页长编号句换行、方案页底部决策条与脚注空间过近、推荐标签与直接作用行相交；在首轮自主范围内修正并重新导出、重渲染和复核。最后一次导出与渲染成功，未遗留严重裁剪、越界或非预期文本碰撞。
