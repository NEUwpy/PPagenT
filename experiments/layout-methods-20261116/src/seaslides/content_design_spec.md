# Content Design Specification

## Project Settings
- 一页，1280×720，中文，受众为人力资源与业务管理人员。
- Theme: mckinsey-minimal，源 commit dcde5bf6c6875b300e2999fc7766f369a13a67ac。
- 风格：白底、东北大学蓝 #3361AE；Microsoft YaHei；正文21—22px。
- 原图仅用原校标。无新图像，无模型调用。

## Narrative
两点不足与四点感悟各自成组，不增加逐一因果。

## Per-slide Plan
1. 标题“存在的不足与感悟”；左侧 .insight-card 垂直两项，右侧 .insight-card 纵向四项；纵向顺序为阅读顺序，非工作步骤。
- 模板已有 insight-card、card-nb、card-title、card-desc；新增 pp-two-groups 等容量组合类。
- 组件选择与比例由本次作者决定，编译器不自动决定布局。

## Excluded Assets
原生旧稿、生图参照只进对照 gallery，不进入当前内容或充当事实。

## Diagram Capacity Update
implementation 按灰稿要求显示已完成设计、三项障碍和向落地阻力汇聚的关系。为容纳图示，问题区47%，感悟区四行卡片；不建立两组之间的解决或因果关系。
