# 让每周问题进入下一轮改进

这是虚构的实验室日常协作方案，受众为课题组成员。请制作一页说明四个阶段反复运行的改进闭环，不是一次做完即结束的线性任务。

每周先收集问题：记录本周操作中重复遇到的困难。然后选择一项：结合影响和可处理范围，选定本周只改的一件事。接着小范围试行：由自愿成员在约定场景尝试新做法。最后复盘结果：记录哪些做法有效、哪些增加了负担。

复盘得到的问题和未解决事项回到下一周的“收集问题”，作为下一轮输入。四个阶段依次运行，最后明确返回第一阶段。这里的有效与负担是试点要观察的内容，尚未有实测结果。

本页中心主题可表述为“每周小改进”。每轮只选择一项，试行可停止，不能把尚未验证的新做法强制推广。请保留这一范围限制作为整页说明。
