执行模型无页面图片输入，父任务看最终预览并核对原稿与实际对象。首轮完成前不提供逐页设计反馈、不手改执行者文件。评审内容包括：内容完整与限定、文字角色与换行、分组和阅读入口、自然高度与空白、整套节奏、Shell 和原生交付。首次审查列出全部主要问题，不在后续任意提高标准。

若存在实质缺陷，先提炼成通用指导并保存新版本，再用新的空白任务独立验证；原任务接受具体反馈后的修订另行标记。文字基线成立后，再以同一套设计指导验证按需调用真实结构 Skill，检查是否改善关系表达且未使其他页面退化。有限样本通过只支持当前环境的初步可用性，不证明跨模型稳定、无审查产品质量或 DeepSeek 成本。

本轮属于设计实现迭代，不是科学比较实验。Git 由父任务统一提交和同步；新任务只写分配的实验产物目录。历史输出与评审一起保留，执行者自检声明不等于父任务验收结论。
