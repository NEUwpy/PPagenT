# 整页设计方法的观察依据

本记录供父任务研究和评审，不作为 Luna 的额外输入。用户目标是设计指南，已有结构库负责可复用的局部关系。主要风格仍以[极简指南](https://www.xiaohongshu.com/explore/68031002000000001c012584)为准；以下分析[第一篇图集](https://www.xiaohongshu.com/explore/6a6e91540000000022030d8d)已经查看过的画面，帮助解释整页怎样组合。新第五篇图片仍未完成查看。

本轮重新查看图集第 2、4 张：

- 第 4 张上方的电话营销页：短判断与较长依据处在对应行中，右侧共同结果具有明确归属。它提示空间可以编码论证职责；不必照抄梯形边、气泡框或英文内容。
- 第 2 张下方的产品偏好页：文字发现与两组对齐的横条图共同组成分析，图中局部说明指向具体差异。文字承担解释而非再次命名整张图。
- 第 2 张中部的经营页：行动概括、解释和指标承担不同职责，区域宽度随职责改变。它提供对应与分工的参考；其较多框线不是本项目的必要风格条件。

本轮项目推导：写指南时同时交代信息职责、相对位置与视觉待遇，而不是只列“简洁、专业、逻辑清楚”，也不是给整页指定固定卡片数量。主题、对齐、字号是稳定配置，区域比例与组合由实际内容和资产自然尺寸决定。

新增的执行现实：`sequence-flow-001` 三步状态声明最小 930×382。若主体宽度 1168，把它强塞进半页是不合法的；图文混合可以是上下协同，不等同于强制左右各半。是否存在其他更合适资产，由执行者查询决定。

审查时把以下原因分开：

1. 指南不足：读者仍找不到主次，图文分工不清或构图缺乏组织。
2. 执行偏差：已有明确规则，却出现重复文案、样式冲突、隐藏关键条件或错误关系。
3. 资产限制：实际尺寸、可变主题或字段契约阻碍必要组合，须给具体资产与参数证据。

这不是三类自动免责。最终页面都需接受相同的内容和设计审查，原因分类用于决定下一步改哪一层。
