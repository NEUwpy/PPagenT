## 要验证什么

- 先查项目库，再判断是否需要 Archify，而非按题目强配技能。
- 对可适配项目结构实际调用，留下真实事件；相关但不适配的候选留下契约原因。
- 选用外部技能时保留语义并真实执行，不以工具名称或安装记录作为调用证据。
- 交付格式正确：A 要求原生可编辑 PPT；B 允许技术图 HTML，不把 HTML/SVG 冒充 PPT。

本次只验证小样例下的选择与执行，不证明任意稿件稳定，不代表正式 Harness 已接入。

接续说明：首次执行者停止后，run/ 仅留下空目录，没有可核验的选型或成品。接续由新的 Luna High 执行，允许参考既有实验的运行方法；主任务还提示了消息时序可能适合 Archify，但明确要求按实际查库结果判断。因此本轮属于带运行辅助的定向试验，不是无提示首轮盲测。
