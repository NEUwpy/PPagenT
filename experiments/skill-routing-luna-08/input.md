# 技能选择试验稿

以下均为模拟稿件，不代表真实业务成效。制作两项关系图示并保留选择证据，使用中性 Skin + 杂志风作为 PPT 基础视觉。按当前项目技能规则自行查找适合能力，不指定资产或强制外部调用。不要读取既有实验成品代码作为答案。

## A：三路资料汇入维修交接单

现场记录：故障现象与发生时间。检测记录：测量读数与测试条件。备件记录：替换型号与领用数量。
三路资料同级、独立准备，不经筛选，共同汇入一份维修交接单。交接单让接班人员追溯处理过程；材料缺失标为待补，交接双方确认。

交付要求：一页原生可编辑 PPTX 与渲染预览，不接受整图图片替代。

## B：异步导出任务的消息时序

参与者：用户端、导出 API、任务队列、导出 Worker。
用户端向 API 提交导出请求；API 将任务入队；API 立即向用户端返回任务编号，并不表示导出完成。Worker 从队列领取任务后生成文件；用户端稍后根据任务编号向 API 查询；API 向 Worker 查询状态；Worker 返回已完成和文件地址；API 最后把文件地址返回用户端。

需要保留参与者归属、消息先后、请求与返回的区别。它是消息时序，不是无角色的一条普通流程。
交付要求：可单独审阅的技术图 HTML；不要求把 HTML 冒充可编辑 PPT。未来若嵌入 PPT，需说明转换边界。

## 证据

每项保存候选检索、至少一个相关项目候选的实际 inspect（若无相关候选则保留目录结果）、适配判断、最终技能、实际执行日志与输出类型。不要为了测试凑齐指定技能；最终选择依据稿件和当前真实库能力。检查失败保留诊断，不删除稿件事实迎合检查。
