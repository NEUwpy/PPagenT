# 独立生成任务提示词

把下面任务段落交给能读取本仓库、制作并渲染 PPTX 的 Agent；填入原稿、输出位置和必要演示要求。不需要复制历史聊天或旧设计长提示词。没有相应工具时应说明缺失，不把规则加载成功当作生成成功。

当前复现验收由主任务实际启动 `gpt-5.6-luna`、`high` 的无历史上下文新对话执行；主任务负责提示词／规则维护与验收，不代做成品。该模型设置不是下方提示词能自行切换的。完整分工、输入隔离与失败后再验证流程见[工作流](工作流.md#luna-high-复现验收)。

---

请根据我提供的原稿和演示要求，独立完成内容编排、原生可编辑 PPTX、完整逐页预览与必要修正。原稿路径、输出目录、受众、页数或时长以本次任务提供的信息为准；保留用户明确限定的改动范围。

在 PPagenT 仓库根目录运行并完整读取输出：

```powershell
npm run rules:load -- --profile generation --skin neutral-editorial-001
```

这会加载当前共享规则、中性 Skin 的颜色／字体配置，以及它唯一绑定的「杂志风」排版体系；具体颜色按 Skin 用途取值，文字角色和布局按排版体系执行。不要改用历史 v1/v2/v3 提示词，不默认读取全库，不改写规则或资产。若指定其他 Skin，先确认 `rules/index.json` 有相应 ID；排版体系由 Skin 自动选择，不能单独覆盖。加载失败时停止制作并报告具体原因。

按已加载规则推进；输入足够时直接交付，不默认等待逐页或大纲审批。遇到影响事实、任务方向或改动权限的关键缺失才澄清。局部关系需要结构时，按共享排版规则读取结构 Skill，可直接调用通用组件，也可浅约束、多参考重组；不设调用或参考数量配额。此次为独立制作，不通过正式 CLI 冒充中性 Skin 已接入。

将已加载的文字角色落实为共享样式，再开始绘制；不要凭整体印象另配字号或套用默认模板。交付前实际执行所加载质量规则要求的角色核对、几何检查和逐页视觉复核，保留检查记录；发现问题由你修正后重新渲染，不把通用文件校验通过当成这些检查已经完成。只有当前最终文件通过所需检查后才交付；确有阻塞则明确候选状态和未解决项。

最终给出可编辑 PPTX、完整预览的位置、已完成的检查和仍未解决的问题。修改已有成品时，以本次指定页面为范围，不无故改变其他已认可页面。
