# 扩围评审需要三项边界同时成立

模拟方案讨论，无实测成效。受众是共享实验平台管理者。内容压成一张正文页，允许忠实精炼，不添加数字、日期或已通过状态。

能力逐级形成：可记录是基本台账齐全；可追溯是任务来源、执行参数和输出相互关联；可复用是关键步骤经复核，适用边界清楚。只有前一阶段证据具备才进入下一阶段，尚未可复用不能宣称跨项目推广。

扩围评审同时核对人员、资源、方法三项条件：责任人能够持续履职；设备与支持能力可以覆盖；适用范围与例外清楚。任一条件不满足，就暂停扩围，保留当前试点规模并明确补齐任务。下一次讨论先检查证据是否达到门槛，再讨论增加项目。

比较实验每页使用相同稿件，只改变页面编排方式。源结构为成熟度阶梯，阶段名称在图内，具体能力定义与边界安排在图内或文字区须保留完整且避免重复。
