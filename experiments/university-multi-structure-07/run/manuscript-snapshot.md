# 共享实验平台试点决策

以下为虚构的方案讨论稿，全部为拟议安排，无实测成效。受众为平台管理者与课题负责人。汇报目的：讨论一个先验证记录能力、再扩大开放范围的试点方案。

## 先筛出可追溯项目，再小步扩大开放

建议先启动小范围试点，不按申请先后直接开放。申请可来自课题自荐、平台推荐与合作项目，依次核对资格、责任人与记录准备，缺一项则暂缓。资格核对明确设备使用条件；责任确认要求一位明确负责人；记录准备要求能保存任务来源、执行参数和输出。通过筛选不等于立即全面开放，还应按“可记录—可追溯—可复用”逐级发展：先留台账，再关联来源参数输出，最后在复核后沉淀复用方法。只有前一阶段的证据具备，才进入下一阶段。筛选解决谁能进入，阶梯解决进入后如何推进，两者共同服务稳妥扩围。

## 完整记录与分级处置共同防止异常失去责任归属

记录应覆盖四类并列信息：申请来源（申请人与任务）、审批依据（责任人与时间）、执行结果（参数与输出）、异常处置（原因与结论）。这四类不是先后步骤，不能互相替代。异常处理则按另一组真实筛选条件逐层收敛：先核对记录是否完整，再确认责任是否明确，最后检查复核是否通过；任一条件不满足则补齐后再提交，不直接关闭异常。记录内容保证有据可查，处理关口保证有据才关闭。课题负责人确认事实，平台管理者复核处理结论；当两者意见不一致时保留异常状态，提交协调，不把“已记录”当成“已解决”。

## 扩围应以能力达标为门槛，并保留明确的暂停条件

能力分三阶：可记录要求基本台账齐全；可追溯要求来源、参数、输出相互关联；可复用要求关键步骤经复核且适用边界明确。达到可复用前不宣称跨项目可推广。扩围评审同时核对三项并列边界：人员条件（责任人可持续履职）、资源条件（设备与支持能力可覆盖）、方法条件（适用范围与例外清楚）。阶梯描述能力变化，边界项描述同时应具备的条件。任何边界无法满足则暂停扩围，保留当前试点规模并明确补齐任务。下次讨论应先检查证据是否达到门槛，再讨论增加多少项目；本稿不预设项目数量、时间或收益指标。
