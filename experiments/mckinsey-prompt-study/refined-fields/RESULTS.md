# v3 字段消融结果

本轮为三组独立 Luna High 执行，各两页同稿：A 六字段完整版，B 删除分析表达，C 删除视觉层级。父任务逐页检查全部六张最终 PPT 重渲染图，并核查 B 条形几何实现。成品保持冻结，未由父任务美化。

## 逐页证据

|组别|定量比较页|定性权衡页|
|---|---|---|
|A 完整|八值共起点、同比例，结论标题具体；右侧两个大底色块重复较多数值，背景轨道增加视觉负担，另有违规橙色|相同维度横向对齐，但重复两套行标题、全边框与大建议条使版面偏重|
|B 删分析表达|八值长度按相同系数计算，但两组起点不同，仅一套底部刻度，形成含混的坐标表达；正文出现句号孤行|共同维度的表格仍成立，说明删字段并不必然损失定性对照；整列底色和标题/副标题/建议重复使信息显重|
|C 删视觉层级|共同起点与0–80刻度，八值可直接比较；图文较清楚；标题“障碍决定先后”强于材料支持的讨论优先级|单一维度列、横向细线使横读更轻；底部限制说明紧贴建议色条，间距不足，尚需正常视觉QA|

## 当前决策

保留字段载体。它便于独立维护、删除与比较；本轮不再试图证明 YAML 天然优于段落。

保留“分析表达”：本轮定量页给出了具体支持，重点是让位置承担比较意义。不要把 B 的错误再写成新的“禁止错位条形”审美规则；数值轴正确性属于通用技术验收。

暂用 C 的五字段作为下一轮基线，即 `no-hierarchy.yaml`。本轮未观察到独立“视觉层级”字段的稳定额外收益，C 仍自行形成标题、图题和正文层级，定性页比 A 更轻。共同条件已经指定字号层级，因此这只是其在当前共同条件下的增量无明显优势，不能推论任何场景都不需要字体层级。

不增加新禁令，不把 C 宣称为完成版。下一轮若继续，应原样复测五字段与六字段、加入顺序/因果类新稿；在看结果前冻结比较条件。本轮没有覆盖完整大学 Skin 生产链，也没有证明三类局部 Skill 的调用质量。

## 证据边界与验收差异

- 每组一次、两种页面，审阅者知道组别；不能归因到单个字段或声称稳定复刻。
- A 使用额外橙色，不符合冻结配色；保留失败样本，不悄悄修正。PNG 导出尺寸有1280×720与1600×900差异，预览按相同比例归一显示，不能按屏幕绝对字号比较。
- 三组执行报告均记录 `slides_test.py` 通过。B 的轴语义含混、C 的标题强度与局部间距问题说明溢出测试不等于内容/审美通过。
- 实际交付采用 Presentations 与原生对象；未见三组完成结构、Archify、Lieflat 的实际调用证据。B 以整页需承载说明为由跳过局部图表模板的理由不足，不能将本轮结果用来评估这些 Skill。
- 参考依据与取舍见 `STUDY.md`。参考用于凝练主张—依据对应、共同维度和整页分析组织，不将个别图片的装饰当作普遍规范。

交付：`compare.html`；三组目录各含 PPTX、构建脚本、两张最终 PNG 与执行记录。
