## 页面与关系核验

1. **预约量与等待**：保留 2023/2024/2025 预约完成量 1200/1560/1920 单、中位等待 8/7/6 天；柱形与折线使用不同量纲并列呈现，标题明确“不构成因果证据”，右侧写出高峰及分设备等待的拟议观察。
2. **预约障碍比较**：保留校内/校外各 100 人及四项比例：62/48/28/44% 与 45/65/58/32%；两组横向条形严格共享四个维度，页内注明多选比例不相加为 100% 及不可推广。
3. **分阶段试点**：用三段连续箭形轨道表达阶段先后，用两条横跨轨道的深色门闸表达“记录完整”“责任明确”后再推进；保留每阶段交付与观察指标，并保留新访问授权时暂停共享的条件。
4. **设备支持优先级**：用真实横轴“预约频次”和纵轴“操作支持需求”及 50 分界定位四个设备；坐标为显微成像(85,80)、基础检测(80,25)、材料制备(35,75)、常规加工(30,30)，气泡仅作可编辑落点，不表达第三维数据；右侧给出对应行动建议。

## 结构选择记录

- 第 1 页：数值趋势需要连续数据轴；项目结构不适合精确趋势，采用自主原生编排（可编辑柱形、折线与点）。
- 第 2 页：采用 `matrix-cross-grid-003` 的行列共享与严格对齐思想，重建为双组横向比较条形，保持四个障碍维度的逐行对应；未调用外部图表技能。
- 第 3 页：采用 `sequence-phase-gates-004` 的蜿蜒/收窄箭形轨道与阶段门闸识别特征，按本页 3 阶段内容重算几何并用原生形状重建。
- 第 4 页：采用 `matrix-quadrant-priority-001` 的真实双轴、轻象限底色与气泡定位特征，按本页 4 个对象重算坐标并用原生形状重建。
