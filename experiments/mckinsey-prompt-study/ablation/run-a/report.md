## 页面与关系核验

1. **使用增长与等待**：2023/2024/2025 的预约完成量为 1,200/1,560/1,920 单；中位等待为 8/7/6 天。柱体与折线共享年份，标题与侧栏明确“同时观察，不证明因果”，并保留继续观察高峰时段及分设备等待的建议。
2. **预约障碍对照**：校内/校外两组各 100 人，四个共享维度和 62/45、48/65、28/58、44/32 的选择比例均保留；图例和同一 0—100% 轴支持行对行比较，侧栏给出两类用户的不同优先项，并标注多选不相加为 100%。
3. **分阶段试点**：三个阶段按统一入口 → 明确审批责任 → 发布费用与培训说明排列，每阶段的交付和观察指标一一对齐；底部门槛保留记录完整、责任明确、平台负责人确认，授权处理暂停/恢复规则单独呈现；未绘制不存在的量化改善曲线。
4. **设备支持优先级**：二维图保留频次与支持需求 0—100 轴、50 分界和四个点位；右侧四种动作与四个象限直接对应，并明确分界无外部行业含义、点位不代表成本或真实利用率。

## 字体、主题与适配限制

- 标题使用大学 Skin 契约指定的 `HYWenRunSongYun U`；正文、图表标签、脚注使用 `Microsoft YaHei`。
- 主题使用白底、近黑判断标题、`#315F91` 主蓝及其浅色层级，辅以橙色 `#D9822B` 表示第二类用户、等待序列或授权提醒；细线为浅灰。
- 本轮按 Skin 契约从零构建分析页，没有调用大学模板母版或校徽图片；页眉使用“东北大学｜大学共享仪器服务”文字标识，因此不能宣称与正式校方模板或完整品牌资产像素级一致。
- `HYWenRunSongYun U` 在目标机器或其他 PowerPoint 环境缺失时可能发生字体替换，标题字形和行宽会随替换字体变化；本轮 PNG 由当前运行环境实际渲染，未对其他机器字体回退做额外验证。
