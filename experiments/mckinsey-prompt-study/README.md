# 大学 Skin＋麦肯锡排版提示词研究

状态：学习与提示词候选阶段；未执行本轮 Luna 试验，未通过风格验收。分支 codex/mckinsey-prompt-study。

## 目标与依据

目标是用可复用的文字提示驱动 Luna High 制作接近用户所选麦肯锡参考的原生 PPTX。中性 Skin＋杂志风继续保持原搭配；本试验不修改正式规则入口。

本轮直接查看了 docs/设计手册/麦肯锡风格参考/微信图片_20260906004635_183_5.png；它是用户选定的视觉样板，不当作机构官方规范。对照阅读杂志风现行规则、历史 v3 提示词与复现记录，以及 consulting-positive-ab-01 的 REVIEW.md 和 positive-guide-next.md。

## 当前学习判断

- 杂志风把稳定身份、文字角色、元素相邻关系、可选成页方法、真实输出检查连在一起。应借鉴这种写法，不迁移砖红、章节符号等杂志风身份。
- 参考四页共同出现判断标题、细分隔、图题与单位、宽证据区域、较窄解释区域及来源。第三页用上下两个视图共同解释技术变化，第二页两组数据并排；这说明统一可以来自共同的文字与图文组织语言，而不是每页同一个图。
- 标题有分量，但主体仍由具体证据占据。解释栏的视觉重量低于证据，不把判断另外扩成一个大色块。
- 旧 B-r1 的评审仍指出放大说明表、大容器和分析视图协同不足。本轮候选将“高密度、专业、论证”展开为读者可直接比较或对应的排版动作。
- 参考含定量图表，旧对照主要用定性提案。两者内容条件不同；应分别测试定量复刻和定性迁移，不能凭缺少数字就给定性稿虚构数据，也不能把这种差异全部归因于提示词。

## 验证设计

1. 固定一份有明确来源或明确标为模拟的四页材料，覆盖趋势、同维度比较、阶段与影响、二维定位。先核实数据是否足以支持各图型；不从参考图臆造业务事实。
2. 同稿比较旧 positive-guide-next 与本目录 prompt-v1；同一 Luna High、同一工具、大学 Skin、三技能选择规则和输出要求。制作任务不读取旧 builder 或父审逐页意见。冻结输入与首轮产物。
3. 先独立查看首轮 PPT 渲染是否接近选定参考，分别记录视觉风格、内容准确性、原生编辑对象；不把文件能打开作为风格通过。主审看参考图，执行者先用文字提示，以检验提示是否传达了视觉方法。
4. 若首轮失败，先判断是提示欠明确、执行未遵循、工具出错还是材料不匹配，再改对应层。反馈后修订稿与独立首轮分开记录。
5. 风格达到目标后，用一份定性新稿测试迁移。按真实材料组织比较与对应，不要求凑图表或三技能调用配额。

评审重点：标题与主体的比例；证据是否占据有效主体空间；图题、单位、标签、解释是否各有层级；多个视图是否共同支持判断；图文是否直接对应；色彩是否有稳定含义；与参考的相似性是否超越白底蓝色。
