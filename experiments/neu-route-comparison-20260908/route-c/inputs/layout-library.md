# Semantic layout library

Choose layouts by communication job, not by decoration. The content plan must record
one layout ID and a short reason for every slide.

## Orientation and synthesis

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C01 | Signature cover | Establish theme and one semantic metaphor | One title, optional subtitle, 2–4 metadata items, one metaphor |
| C02 | Minimal cover | Formal board or client setting | One title, subtitle, date, author/client; no framework |
| C03 | Section threshold | Mark a real narrative transition | One short conclusion or question; do not repeat the agenda |
| C04 | Executive summary | State governing thought and 3–5 conclusions | One lead conclusion, 3–5 support points, up to 3 actions |
| C05 | Closing synthesis | Restate decision and next move | One final assertion, 2–3 implications, optional decision request |

## Assertions and comparisons

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C06 | Hero assertion | Make one decisive claim memorable | One claim, one number or short proof, minimal supporting copy |
| C07 | Three arguments | Present three mutually exclusive supports | Exactly 3 columns or bands; 1 headline + 1 proof each |
| C08 | Two-way comparison | Compare current/future, segment A/B, or options | Two balanced fields, 3–5 comparable dimensions |
| C09 | Multi-option comparison | Compare 3–4 choices | Shared evaluation criteria; avoid free-form cards |
| C10 | Pros, cons, and choice | Make a trade-off explicit | 2–4 pros, 2–4 cons, one recommendation |
| C11 | 2×2 matrix | Position options by two meaningful variables | 4 quadrants, up to 12 points, named axes and implication |
| C12 | Heatmap | Compare many entities across criteria | 4–12 rows, 3–8 columns; direct legend and highlighted pattern |

## Quantitative evidence

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C13 | Hero metric + proof | Lead with one critical number | One hero metric plus one small supporting chart or decomposition |
| C14 | Trend | Explain change over time | 1–4 series, direct labels, highlighted inflection or gap |
| C15 | Ranked comparison | Compare categories | 4–12 horizontal bars; sort unless order is inherently fixed |
| C16 | Composition | Show mix or allocation | Stacked bar/area; normally 3–6 categories |
| C17 | Waterfall / bridge | Explain movement from start to end | 3–10 drivers; label start, end, and material deltas |
| C18 | Scatter / portfolio | Compare scale, performance, and cluster | Two axes, optional size; annotate only decisive points |
| C19 | Data table with takeaway | Present exact values | 4–12 rows, 3–8 columns; highlight conclusion, not every cell |

## Mechanisms and systems

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C20 | Issue or hypothesis tree | Decompose a question | 2–4 branches, maximum 3 levels, MECE where practical |
| C21 | Process / journey | Show sequential work or experience | 3–7 stages; include owner, friction, or output only when useful |
| C22 | Value chain | Show roles and value migration | 4–9 stages or layers; distinguish flow from ownership |
| C23 | Operating model | Explain interacting capabilities | 3–6 components around a clear core or flow |
| C24 | Layered architecture | Explain stack or organizational layers | 3–5 layers; show dependencies and interfaces |
| C25 | Flywheel / loop | Explain a reinforcing mechanism | 3–6 causal steps; use only when the loop is genuinely circular |
| C26 | Funnel / conversion | Show attrition or qualification | 3–6 stages; values must reconcile where possible |
| C27 | Ecosystem / network | Show actors and relationships | 5–12 nodes; encode relationship types and avoid spaghetti |

## Decisions and mobilization

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C28 | Prioritization | Rank initiatives against criteria | 5–12 initiatives; show criteria, score, and decision rule |
| C29 | Strategic choice | Frame a small number of choices | 2–4 choices, trade-offs, and explicit recommendation |
| C30 | Roadmap | Sequence actions over time | 3–5 workstreams, 3–6 periods, milestones and dependencies |
| C31 | Initiative portfolio | Show work packages and value | 4–10 initiatives grouped by strategic theme |
| C32 | Risk and mitigation | Link risks to controls and owners | 4–8 risks; probability/impact plus concrete mitigation |
| C33 | Governance / RACI | Clarify decision rights | 4–10 activities, 3–7 roles; simplify before using a full RACI |
| C34 | Decision page | Close a meeting with a clear ask | 1–3 decisions, rationale, owner, and deadline |

## Reference layouts

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C35 | Methodology | Explain sample, method, assumptions, limitations | Keep detail concise; move technical depth to appendix |
| C36 | Source appendix | Make evidence traceable | Group sources by slide or topic; keep readable locators |

## Research exhibit layouts

| ID | Layout | Use | Capacity and constraints |
| --- | --- | --- | --- |
| C38 | Exhibit + implication | One dominant source exhibit with a concise management implication | Exhibit 60–75% of canvas; one annotation rail; full source and sample note |
| C39 | Trend + maturity stack | Pair an adoption or performance trend with a current-state distribution | One 1–3 series trend and one 100% stack; shared conclusion |
| C40 | Aligned stacked responses | Compare survey distributions across 5–12 rows | 3–7 response categories; preserve scale order and show sample |
| C41 | Chart + exact table | Show visual pattern and exact comparison values | One chart plus 4–15 row table; selective emphasis only |
| C42 | Dual aligned exhibits | Two related charts that answer one question | Shared baseline, unit, or categories; one combined implication |
| C43 | Small multiples | Compare 3–6 related trends or segment views | Shared scale where possible; highlight only decisive panels |
| C44 | Dot plot / distribution | Compare two groups across many practices or functions | 5–15 rows; direct labels and highlighted gaps |
| C45 | Exhibit sequence | Show a source-derived mechanism with quantified stages | 3–7 stages; every number sourced or reconciled |

## Selection rules

1. Choose the communication job before the layout.
2. Use the smallest layout that can carry the conclusion and evidence.
3. Split content when it exceeds capacity. Do not create miniature text.
4. Use `C06` sparingly; repeated hero statements weaken the deck.
5. Use `C11`, `C25`, and `C26` only when the analytical structure is real.
6. Use native PowerPoint charts and shapes for the core evidence.
7. Keep the title, main structure, annotation, and source bands aligned to the same
   grid.
8. In Research Analytical mode, prefer C38–C45 and C14–C19 for evidence-led pages.

## Variety rules

- A 7–9 slide deck should use at least 5 distinct layout IDs.
- A 10–15 slide deck should use at least 7 distinct layout IDs.
- Do not use the same silhouette on three consecutive slides.
- Alternate dense proof pages with lighter synthesis or transition pages when the
  narrative permits.
- Do not vary layout merely for novelty; preserve visual grammar and shared axes.

## Mapping examples

| Content shape | Prefer | Avoid |
| --- | --- | --- |
| One record profit number with caveat | C13 | A four-card dashboard |
| AI adoption across functions | C12 or C15 | A decorative ecosystem map |
| Business model value migration | C22 or C24 | A generic arrow collage |
| Current vs future customer behavior | C08 | Two unrelated images |
| Recommended transformation moves | C28 or C31 | A list of nine equal cards |
| Implementation over four quarters | C30 | A paragraph with calendar icons |
