# 新规则独立生成：重心与文字留白

本轮由无历史上下文的 gpt-5.6-luna high 执行。五页输入为原 P2、原 P3 与新稿 N1/N2/N3。原稿从既有模拟稿中提取，去除旧组合、坐标与容量建议；P3 的内容和数据口径仍保留。

## 输入隔离

- 模型只读取本实验稿件、现行 rules、公共源码/API 和技能文档。
- 不读取其他 experiments 下的旧脚本、图片、PPTX、组合计划或逐页反馈。
- P2/P3旧稿只供主任务做最终对照，不能作为生成模型的视觉模板。
- 新增规则通用于整页有效占用、主辅关系、实际行距段距、留白与重组，不写 P2/P3 的局部坐标处方。

## 执行与验收

模型按现行规则独立规划并构建五页，保存 first 首版计划、PPTX 与 PNG；自行看图、修订，保存 final 和逐页 review。主任务在最终产物完成前不提供逐页布局修复指令；仅可处理工具或输入错误，并记录干预。

主任务最终独立比较原 P2/P3 与新结果，检查新稿的内容、逻辑、共同对齐轴、视觉重心、实际文字间距与可读性。判断可能为通过、部分通过或未通过，不能因为文件可导入或无越界就宣布新规则有效。

这是一轮新规则生成评估，包含模型自主审查与修订；不是单次模型采样，也没有旧规则的独立同条件对照，因而不能把前后变化全部归因于新增规则，更不能以五页推断所有稿件稳定。
