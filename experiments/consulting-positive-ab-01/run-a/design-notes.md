# Design notes

## Communication job

面向课题组讨论者，帮助其在四个问题上形成可执行且证据边界清楚的共同理解：记录单元如何定义、历史与新增如何取范围、复核如何推进、四周试点如何决定去留。叙事按原稿四问顺序展开，四页分别承担一个分析问题，没有封面、目录或额外收束页。

## Visual route

采用 presentations Skill 的自定义视觉路线。用户指定主题蓝 `#315F91`、Microsoft YaHei、1280×720，并明确允许卡片、色块、多栏和结构图，因此使用浅灰背景、深蓝标题、蓝色强调、青绿色可行区、琥珀色边界和红色异常状态。所有视觉均由原生 PowerPoint 形状、文本框和连接线组成，保持可编辑。

## Page silhouettes

- Page 1 用深蓝总带 + 五列信息槽 + 下方“记录原则 / 开放边界”双栏，突出五类信息的并列共同解释关系。
- Page 2 用建议带 + 两条路径对照，右侧高亮推荐路径，底部单独放置“范围选择、未证明效率提升”的证据边界。
- Page 3 用四阶段横向流程和下方授权异常分支；连接线先于节点写入，减少线条穿过文字的风险。
- Page 4 用试点范围带 + 四周时间轴 + 第 1 周 / 第 2–3 周 / 第 4 周三块行动区，并在底部并列评估依据与调整触发。

## Typography and content handling

标题 35px，主要分区标题 21–24px，正文 15–18px，页眉与页脚使用较小辅助字号。长句被拆成短行或并列要点，保留原稿的限制条件和“不代表已证明”的证据边界；没有通过缩小正文来塞入额外事实。所有正文文本框使用 `autoFit: shrinkText` 作为工具级容量保护。
