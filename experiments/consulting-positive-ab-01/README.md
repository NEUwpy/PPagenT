# 正向设计提示对照

用户指出过去把局部失败堆成风格禁令，要求恢复正向、普适的设计指导。本轮 A 是用户粘贴提示词的可读整理版（原文字残缺，非逐字原文）；B 是论证、多栏、密度、视觉意义的正向指南。

两组使用同一份四页归档提案、同一蓝色主题、同一 Luna High 和共同执行条件。原稿取自 codex/penguin-harness-v2 已保存的四页测试输入。生成者无视觉与旧稿反馈。旧式卡片禁令、面板审计、固定字角色表均不纳入。只修改本实验目录，避免影响当前结构尺寸适配分支的其他工作。

父审比较：内容关系是否准确、整页主次是否清楚、材料是否充分展开、图文是否相互解释、第一眼是否接近用户参考的专业分析页。分别记录首轮与反馈轮；两次生成只能提供案例对照，不能建立稳定成功率。
