# 第二轮修订提示

## 原 prompt-b.md

请把稿件制作成四页中文科研咨询分析报告，保留原稿的层级、核心内容与专业口径。成品应具有成熟战略咨询报告的分析深度、充实感和精确编排：第一眼辨认本页最重要的判断，随后通过组织清楚的证据读懂判断如何成立。

以论证组织页面。先理解本页要回答的问题，再把材料编辑为彼此支持的分析视图。让短主张、具体依据、局部关系与适用条件共同展开一个问题。每个视图有自己的信息贡献；这些贡献通过共享维度、相邻位置、编号对应或连线组成一个完整推理。标题提炼判断，分析区展开细节，说明把观察转成含义。

以信息职责安排多栏。为主要证据提供连续的阅读空间，让旁边的解释回应其中的对象；比较材料共享维度与基线，阶段材料共享时间或动作方向，组成材料共享所属结果。由内容之间的关系决定栏宽、行高和组合方式。一个分析区可以容纳相互支持的多个视图，局部结构图与文字共同讲清楚关系。让读者通过位置直接看懂对应关系，而不必把所有段落读完才建立联系。

以层级组织高信息密度。用简练的短标签建立扫描路径，用完整而紧凑的说明保留依据、条件和代价。把更多空间分给需要分析的差异；重要发现有明确视觉重心，细节仍然易读。组内靠近，组间留出清楚停顿，使页面充实而从容。为标题、分析组名称、正文、注释建立稳定的文字层级，利用字重和局部强调帮助阅读。

以视觉表达意义。主题蓝、深浅色阶、黑灰文字和留白形成统一风格。色块可以聚合相关材料、区分分析职责、突出关键差异或承载含义；线条可以建立比较基线、区域边界或推理方向。卡片、多栏、表格和结构都由内容关系选择。让形状与颜色共同加强读者对逻辑的理解，整套页面因主题和分析语言一致而统一，并随材料的不同自然变化。

保留每个事实的原始性质、角色、取舍与限制，确保文字清楚可读、图形关系准确、PPTX 原生可编辑。

## 反馈后的正向方法

把内容编排成读者能逐项检查的分析展板。每个分区拥有具体的分析工作，例如同一行回答同一个比较维度，证据项旁配对应解释/意义，操作环节对应执行人/交付物/完成条件。共享行列基线使这些关系可以直接扫读；不同列的宽度随解释长度分配。标题直接给判断，主体用具体内容证明它。色块把同一论证层级或适用条件归成整体；较深的色阶落在真正的关键结论。用足主体区域展示原稿已经有的实质关系，保留完整事实和限制。结构从全页分析需要出发选择局部合适形式。以上是普适方向，布局自由、卡片/表格/图均可。不要增加虚构数据或证据。
