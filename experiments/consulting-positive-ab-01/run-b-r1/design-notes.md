# 第二轮设计记录

## 修订目标

本轮按 `revised-prompt.md` 把页面改造成读者可逐项检查的分析展板：比较共享行基线，流程共享角色—交付物—完成条件基线，关键结论使用深蓝，条件和限制使用浅色块承载。

## 关键改动

- 第 1 页：将“访问边界”降为次级条件区，把“五类材料共同解释一个结果”置于深蓝主判断；五条连接改为 `slide.shapes.connect`，从五个节点的真实侧锚点连接到中心记录单元。
- 第 2 页：从两张长段卡片改为四行共享维度表。每行同时回答短期产出、主要代价、证据风险和适用动作，左列为集中补历史，右列为先记新增；底部深色条给出范围选择结论。
- 第 3 页：用满主体区域的四列展板展开角色、交付物和完成条件；四列顶部有真实位置相邻的流程箭头，下方全宽授权门禁保留暂停与继续条件，页底保留复核范围边界。
- 第 4 页：保留首轮四周时间轴和评估/停止区，确保拟定范围、无统一分数和无实测效率/完成率限制完整出现。

## 统一样式

画布 1280×720；主题蓝 `#315F91`、深蓝 `#17324D`、浅蓝 `#EAF2F9`、中性灰线 `#B8C9D9`；字体 Microsoft YaHei。所有对象均为 artifact-tool 原生可编辑形状和文字，没有图片或不可编辑视觉资产。

## 检查边界

按要求不查看最终渲染图片。layout export、inspect、authoring ledger 和 `slides_test.py` 用于文字、连接、画布与溢出检查；最终视觉主次、字形观感和细微遮挡由父任务查看 `render/` 独立验收。
