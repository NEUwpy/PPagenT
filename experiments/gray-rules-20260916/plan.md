目标：基于八类模拟稿的历史首轮，比较精简的通用规则表述，交付逐条规则修改、前后结果、真实页面及退步证据。不给模型案例答案，不以放宽校验获得成功。

基线：main c790a45f；outputs/gray-diverse-20260916；8稿仅long-deck导出6页。历史首轮不能当作稳定成功率。

实验边界：仅在实验 provider 包装层替换四阶段 system 契约，保留共享规则、核心代码、原稿、模型配置、字号、尺寸和 maxRevisions=0。实际发送的 messages 单独归档；运行器原 prompt 文件仍是原版，不能误作变体的实际提示证据。

步骤：
1. 原版 repeat、positive、guarded 各运行全部8稿，交错调度，冻结代码与配置。
2. 对照逐阶段失败、语义、实际预览；相同输入的审稿反例验证不能被放行。
3. 若形成候选，使用未参与调试的新稿及重复运行验证迁移与退步。没有足够证据时不声称改好。
4. 保存比较HTML、Markdown报告、所有prompt精确全文及长度、模型响应/usage、状态、PPT与预览。核心规则的采纳取决于实验，不能只凭导出数量。

共性假设：
- 输出契约应提供互斥合法形状和复制标识的操作，而不是含所有可选字段的单个示例。
- 语义审稿应按本轮实际显示内容核对，蓝区的承载内容属于可见内容，图示成品不属于本轮。
- 内容提炼应以读者问题与内容归属组织，限定就近附着，概括覆盖整页；压缩冗余而不是压缩事实。
- 保真程序暂按字面检查数字，因此保持数字原写法是本轮约束；不宣称这是长期最佳实现。
